\begin{cumcmabstract}
啤酒风味由化合物组成与酵母代谢共同决定。本文在含真实缺失与噪声的 250 个商用啤酒样本上，构建“化学到感官判别预测 → 可解释归因 → 风格条件生成”的贯通流水线，三问共享同一化学到感官模型。

针对问题一，采用\textbf{原生缺失感知的梯度提升}对 50 个感官维逐维回归，再按训练折内分位点映射为 0-6 等级，按风格分层 5 折验证且分箱参数全程折内估计。平均 QWK 达 \textbf{0.3830}，折外 Spearman 0.4109，$\pm$1 级准确率 57.3\%，严格一致率 22.1\%、MAE 1.50 级、RMSE 1.93，优于随机森林 0.328、ElasticNet 0.276 与 KNN 插补 0.3652；2000 次配对重采样的 95\% 区间对三类基线均不跨零；另以 split-conformal 给出 90\% 预测区间，实测覆盖率 90.2\%（目标 90\%），平均宽度 1.55 个标准化单位。特征增广对照显示，加入 43 个阈值超限列、8 个模块 PC1 后 QWK 反而降至 0.3760、0.3747，故未采用。风味组 QWK 0.400 高于香气组 0.322，酒精、苦味等强信号维超 0.77，花香酯类弱信号维接近噪声。

针对问题二，剔除 16 个理化参数与 4 个汇总列，仅在 \textbf{211 个单一化合物}上建共表达图，得 211 节点、564 边、55 社区，模块度 \textbf{0.625}；融合 SHAP、交叉相关与模块代表三路证据选出 Top-3 并去共线冗余。Top-1 的 bootstrap 入选频率均值 \textbf{0.992}（按风格分层重采样），跨方法 Jaccard \textbf{0.200} 为随机基线 0.0086 的 \textbf{23.3 倍}。50 维联合检验显示 QWK 与 Top-1 稳定性的相关仅 $r=0.101$，二者是相互独立的两个维度；随可预测性下降而失稳的是第 3 名。按 8.xlsx 标注的来源逐维判定，一致 6 维、部分一致 17 维，麦芽维多落于酵母酯醇，如实反映发酵后风味载体的真实结构。

针对问题三，用\textbf{条件变分自编码器}以风格为条件生成化学谱，在隐空间做质心平移实现跨风格迁移。三个代表风格的 KS 为 0.351–0.411，偏离集中于稀疏检出列，KS 与未检出率相关 $r=0.66$；5 个随机种子下 KS 的标准差不超过 0.015，能量距离 0.329–0.437，风格 Top-3 识别率恒为 100\%（随机 13.6\%），50 维画像 Spearman 0.65–0.92、画像 MAE 均值为 0.49 级。Pils/Lager 到 Tripel 的缺陷采用逐样本 min 投影，迁移后 \textbf{0/44 次升高}，而同批不做投影的纯平移有 32/44 次升高。

三问结论均经交叉验证、bootstrap 与分布距离检验，框架可推广到其他成分谱与感官建模场景。

\section{问题重述}

啤酒以麦芽水为原料、加酒花并经酵母发酵而成，其风味高度依赖酵母代谢与化合物成分的协同作用。要定量刻画化学成分如何决定一款啤酒喝起来是什么味道，需要把实验室测得的数百种风味化合物与品评小组给出的感官强度联系起来。近年来，机器学习方法已被用于从化学成分预测啤酒及其他发酵饮品的风味特征\cite{b1,b2,b3}，为本文提供了方法论基础。本文使用一套商用啤酒风味代谢物实测数据集：对 250 个啤酒样本测量了酒精、异 $\alpha$-酸、pH、糖浓度等酿造参数，以及 200 余种风味化合物的丰度，涵盖酒花萜类、酵母代谢酯醇、麦芽与野生菌群化合物及陈化类，并由品评小组给出约 50 个感官维度的评分。数据来自真实测量，含噪声、真实缺失值与异常值。围绕化学成分、感官风味与啤酒风格这条链条，本文研究三个递进的问题。

问题一：在化学数据存在真实缺失的条件下，以化合物与理化丰度为自变量，预测品评卡定义的香气 Aroma 与风味 Flavour 两套、合计约 40 个感官维度在 0-6 分制上的分级评分。任务对象是每一款啤酒样本，待求量是各感官维度的离散等级，关键边界是自变量含缺失而不能简单删除样本，评价目标是在缺失干扰下给出稳定可信的分级。本问为后两问提供化学如何映射到感官的基础模型。

问题二：利用化合物相关数据构建化合物共表达图，结合化学特征，给出每一个感官维度的 Top-3 关键因素化合物，并对所得结果做稳定性与化学合理性论证。稳定性按题面指定的两种口径量化——bootstrap 重采样下化合物进入 Top-3 的入选频率，以及不同建模方法间 Top-3 集合的 Jaccard 系数。本问依赖问题一的预测模型做可解释归因，其产出的关键化合物清单又为问题三识别风格判别成分提供先验。

问题三：以风格标签 \texttt{tasting\_\allowbreak{}category\_\allowbreak{}fine} 为条件学习一个风格条件生成模型，在给定风格时，例如 Tripel、Kriek、Lambic，生成合理的化合物谱并给出对应感官画像；同时完成跨风格迁移，即把 Pils/Lager 的化合物谱迁移为 Tripel 风格，并保持 DMS、Diacetyl、4VG、trans-2-nonenal、Stale hops 等缺陷化合物不恶化。该问反向利用问题一的感官画像与问题二的关键化合物，是三问的综合应用。

三个问题沿数据预处理、化学到感官的判别式预测、可解释归因、风格到化学的条件生成与迁移逐级推进，构成一条从理解到生成的完整流水线，其整体求解思路与依赖关系概括如下。

\section{问题分析}

\subsection{问题一的分析}

问题一本质是一个带缺失数据的多输出有序预测任务，核心难点集中在三处。其一，化学特征高维，共 231 列，且含真实缺失，其中 63 个样本、合计 73 个缺失值集中在少数几列，直接删除含缺失的样本会损失四分之一的数据并引入选择偏差，因此必须在缺失条件下建模。其二，品评小组提供的感官标签是经过标准化、中心化的连续值而非原始 0-6 整数，要交付题面要求的 0-6 分级，需要建立连续值到 7 级离散刻度的单调映射。其三，约 40 个感官维度彼此相关性强，宜共享同一套化学特征表示以提升稳健性。据此，本文选择原生支持缺失的梯度提升树\cite{b5,b6,b7}作为主模型，对每个维度做回归后再分箱映射回 0-6 整数，并用分层交叉验证逐维评估二次加权 Kappa、平均绝对误差与决定系数。相较先插补再建模的常规路线，原生缺失处理避免了插补偏差，其输出的特征重要性又可直接服务于问题二的归因。

\subsection{问题二的分析}

问题二是一个在共线性干扰下仍要既准、又稳、还有化学道理的可解释归因任务。许多化合物在相关矩阵里高度相关、成簇出现，单一重要性指标容易把同一化学模块里可以互相替代的化合物反复选入，造成 Top-3 虚假冗余。因此本文先用化合物共表达图揭示模块结构，再在模块意识下融合三类证据做归因：问题一模型给出的 SHAP 预测贡献、化学与感官的交叉相关，以及共表达模块的去冗余加权。稳定性严格按题面两法量化，bootstrap 入选频率刻画单方法内部的稳健性，跨方法 Jaccard 刻画不同证据之间的一致性。化学合理性则逐条对照已知酿造机理加以论证。需要强调，强信号维度的 Top-3 应当稳定、弱信号维度不稳定，这是数据本身的真实现象，本文如实报告而不强行制造稳定。

\subsection{问题三的分析}

问题三是条件生成加可控迁移任务，难点在于小样本条件下，部分风格仅有 3 至 11 个样本，既要保证生成谱的化学合理性与风格可区分性，又要在迁移时守住缺陷不恶化这一硬约束。本文用条件变分自编码器把化合物谱编码进低维隐空间、以风格标签为条件解码，兼顾生成多样性与风格可控；对极小样本风格辅以按风格的分布采样作为对照与兜底。生成谱的感官画像直接复用问题一的化学到感官模型，形成生成化学谱再预测感官的闭环。迁移通过在隐空间做源风格到目标风格的方向平移实现，并对缺陷化合物施加阈值与源值的双重投影，一旦超限即拉回安全区，确保迁移后缺陷不劣化。生成质量用真实谱与生成谱的分布距离及降维重叠度评估。

\section{模型假设}

为聚焦核心建模，本文做出以下假设。

（1）以标准化连续感官值为问题一的训练目标，再按训练折内分位点单调映射回 0-6 等级。原始品评卡汇总表为全 0 模板、不可用，标准化连续值是唯一完整可用的全样本标签。

（2）题面的"约 40 个感官维度"对应 Aroma 与 Flavour 两套共 30 维，本文另输出口感、缺陷与总体评价共 20 维，合计 50 维以覆盖任一解读。

（3）化学特征的数值尺度经 8.xlsx 校准浓度逐列核实为混合尺度：70 个可校准列中 37 列为常用对数、33 列为原值，无自然对数列；其余 161 列按列分布归类。建模在原生数值空间内进行而不做反变换，树模型对单调变换不敏感，该选择不影响分裂结果。

（4）缺陷不恶化取严口径：迁移后缺陷须同时不高于源款原值 $x^{def}_{k,before}$ 与目标风格典型值 $m^t_k$，即上界为 $\min\!\big(x^{def}_{k,before},m^t_k\big)$。该口径保证相对不升高；绝对达标情况另按 8.xlsx 真实阈值审计（见 8.3 节）。

（5）各样本近似独立同分布，风格标签为问题三唯一的条件变量。附件为截面数据、无时间序列结构，故交叉验证采用按风格分层的随机折。

题面文字与附件实测存在若干出入，本文一律以实测为准，差异核对见附录 A（表 A.2）。

附件之间如何对齐同样需要核对，这里有一处容易被静默忽略的陷阱。1.csv 与 4.csv 都带有 \texttt{beer\_id}，直觉上应以它作为关联键；但从 4.csv 读出的 \texttt{beer\_id} 已被转成浮点并丢掉了尾部精度，例如 \texttt{5410230000000.0}，两表按 \texttt{beer\_id} 取交集只剩 \textbf{37/250} 行。若按该键做 inner join，四分之三的样本会被无声丢弃，而程序不会报错。改用 \texttt{beer} 名称关联可恢复 250 行，且本文进一步核验了两表的 \texttt{beer} 列逐行完全相同、行序一致，因此四份数据在对齐上不存在歧义。

本文的实现在这一点上采用按行序对齐并显式校验：读入后立即断言 1.csv 与 4.csv 均为 250 行，且两者的 \texttt{beer} 列逐行相同；任何一步不符都会直接中断而不是静默继续。此外，2.csv 与 1.csv 的 231 个特征按位置一一对应、并已用重算的 Spearman 逐元素核对；6.csv 的 44 个化学行按名称映射回 231 列位置，未覆盖的化合物记为 0 而不参与排序。这些校验写在 \texttt{code/data\_check.py} 中，可独立运行复核。

在 231 个化学特征中，本文按化学含义把它们分为三类：\textbf{理化/过程参数} 16 列，如酒精度、色度、pH、苦度、二氧化碳压力、蛋白、甘油、未发酵糖等；\textbf{多化合物汇总列} 4 列，分别为总酯 esters\_sum、酒花香气总量 aroma\_hops\_sum、总酸 acids\_sum、含硫总量 sulfur\_sum，均为多个化合物的加总；\textbf{单一化合物集 $C$} 211 列，即 $231-16-4$。问题一以全部 231 个特征为自变量，理化指标对预测感官同样有用，不应删除；问题二为严格回应找出关键化合物的题意，仅在 211 个单一化合物构成的集合 $C$ 内建图与归因，避免把酒精度、苦度这类理化指标或总酯这类加总列误当作某个具体化合物。

三类数据的数值口径并不一致，必须先对齐认知再建模。感官标签列为中心化的标准化连续值，范围约 $-2.15$ 至 $6.17$、均值接近 0，并非原始 0–6 整数；化学特征的对数/原值尺度经 5.3 节核实为混合尺度。由于本文主模型为树模型、对单调变换不敏感，建模统一在该原生数值空间内进行而不做反变换，既规避了对数尺度换算的风险，又保证问题三生成与缺陷判定在同一空间内可比。

\subsection{对数底核实与尺度统一}

化合物丰度究竟取对数还是原值，直接影响浓度叙述。8.xlsx 的 Calibrated chemical dataset 提供了 70 个化合物的校准绝对浓度 $c_{ik}$，本文据此逐列反推 1.csv 取值 $x_{ik}$ 的尺度：对每个校准列，在 $c_{ik}>0$ 的样本上分别计算 $\mathrm{median}_i|x_{ik}-\log_{10}c_{ik}|$、$\mathrm{median}_i|x_{ik}-c_{ik}|$ 与 $\mathrm{median}_i|x_{ik}-\ln c_{ik}|$，若第一个小于 $10^{-6}$ 判为常用对数列、第二个小于 $10^{-6}$ 判为原值列，第三个用于排除自然对数。核实结果为：70 个校准列中 \textbf{37 列严格为常用对数、33 列严格为原值}，二者的中位残差均为 0、与对应尺度的相关系数均为 1.0，且不存在自然对数列；值得注意的是连 pH 也取常用对数，$0.625=\log_{10}4.21$。常用对数列包含全部 16 个理化指标与 21 个酵母酯、醇、硫化合物；原值列则以酒花萜烯、醛、酚类为主，如芳樟醇、香叶醇、香茅醇、丁香酚、糠醛、反式-2-壬烯醛、双乙酰。其余 161 列没有校准绝对浓度，本文按列分布与已知理化列归类，并对其尺度明确标注未经校准，不编造校准残差。

需要特别说明化学谱中的负值。231 个特征中有 \textbf{175 列出现负数，合计 10797 个负值单元格}，它们不是异常值或测量错误，而是浓度小于 1 的化合物取常用对数后的正常结果，例如 $\log_{10}0.1=-1$。按列核查，负值全部出现在已判定为常用对数的列上，原值列不含负值。因此本文不做任何剔除、截断或取绝对值，保留其原始对数取值；剔除这些行等于删掉近半数观测信息，还会使分布严重右偏。

\subsection{未检出、真实缺失与异常值}

化学谱里大量低值并非缺失，而是\textbf{未检出}，即浓度低于仪器检出限，它本身携带该化合物极少的信息，必须与真正的缺失严格区分。本文定义未检出为取值不超过本列下限 $\ell_k=\min_i x_{ik}$；真正缺失则是 1.csv 中确实为空的单元格，全表共 \textbf{73 个 NA、分布在 9 列、涉及 63 个样本}：乙酸戊酯 amyl.acetate 一列 27 个，占 10.8\%；酒花香气合计列 13 个（5.2\%）、甲基吡嗪 12 个（4.8\%）、双乙酰 9 个（3.6\%）、3-甲基丁醛 7 个（2.8\%），烟酸乙酯 2 个，苯乙醛、糠醛、异丁酸乙酯各 1 个。

三类特征的未检出比例差异极大：211 个单一化合物平均有 14.4\% 的单元格处于未检出，检出率 0.855；而 16 个理化列几乎全部检出，未检出仅 2.0\%、4 个汇总列未检出 0.4\%。这说明化合物丰度是稀疏的，未检出是主流信号而非异常。对未检出比例落在 5\%–95\% 之间的列，共 \textbf{102 列}，本文为每列定义二值指示 $\delta_{ik}=\mathbb{1}[x_{ik}\le\ell_k]$ 显式标记未检出事件。由于 LightGBM 对缺失与常量列有原生处理，且下限值本身作为一个独立档位已携带“接近零”的信息，指示变量的信息被该档位吸收，故最终特征矩阵仍为 231 列、未额外展开 102 个指示列；指示定义用于问题三的值域截断与附录的数据核对。

未检出并非简单的低值，它在统计上是\textbf{左删失}结构，这一点值得单独说明。本文对 231 个特征逐列统计取值为本列最小值的样本占比：\textbf{40 列有 30\% 以上的样本卡在同一最小值}，其中 12 列超过 60\%，limonene 与 6-methyl-5-hepten-2-one 达 84.8\%、CS2 为 83.6\%、4VG 为 67.2\%。同列大量样本取到完全相同的下限，不是自然测量的结果，而是仪器在该浓度以下无法分辨、统一记录为检出限的痕迹。若把这类下限值当作普通连续观测参与标准化与回归，分布的重心与尾部都会被压缩，均值的含义也随之改变。

本文据此把未检出保留为独立下限档位，并在问题三生成时按 $[\ell_k,u_k]$ 截断，避免解码器外推。

真正的缺失，即 73 个 NA，才需要插补，各列的缺失分布见表 2；本文采用 $K=5$ 的近邻插补，近邻距离在标准化后的特征上计算，并严格在训练折内拟合、再施加到验证折。主模型的特征矩阵为 231 列原生数值（含 NaN），未检出以“下限档位”的形式进入分裂；KNN 插补只用于基线对照。标准化统计量、近邻关系与分箱切点都只在训练折内学习，防止验证折信息泄漏。

\section{问题一：含缺失的多输出有序感官分级预测}

\subsection{缺失结构与建模策略选择}

问题一的第一道关卡是缺失数据。如 5.4 节所述，73 个真实缺失集中在 9 列、涉及 63 个样本，呈少数列集中、多数样本完好的模式；化合物集另有平均 14.4\% 的未检出值，携带的信息极少但不是缺失。删除这 63 行将损失四分之一样本并引入选择偏差，故本文不删行：真正缺失交给原生支持缺失的梯度提升树，未检出保留下限档位\cite{b5,b6,b7}，让树为含缺失的分裂学习默认方向。图 1 的流水线自左向右为缺失感知梯度提升、逐维回归与 0-6 分箱、分层交叉验证；其中分箱映射与评估口径是保证交付整数且不泄漏的两个要害，下面分别展开。

\subsection{标签构建与 0-6 分箱映射}

品评小组提供的标准化连续值无法直接作为 0-6 分级交付，需要一个单调映射把连续强度离散为 7 个等级。本文在训练折内对维度 $j$ 估计 6 个分位点 $\{q^{(j)}_1,\dots,q^{(j)}_6\}$，定义累计计数式的单调映射：

\begin{equation}
g_j(y)=\sum_{\ell=1}^{6}\mathbb{1}\!\left[y> q^{(j)}_\ell\right],\qquad \tilde y_{ij}=g_j(Y_{ij})\in\{0,\dots,6\}.
\end{equation}

预测阶段对回归输出 $r_{ij}$ 施加同一映射，并截断取整以严格落在 0-6 整数区间：

\begin{equation}
\hat y_{ij}=\min\!\Big(6,\ \max\!\big(0,\ \mathrm{round}(g_j(r_{ij}))\big)\Big).
\end{equation}

式 (1) 的分位点与标准化参数只由训练折估计、再套用到验证折，这是本题最易被忽视的泄漏点：若在全量数据上估计分箱阈值，等于让模型偷看了验证样本的标签分布。

50 个感官目标并非彼此独立。\texttt{5.csv} 的 50$\times$50 相关矩阵（对角为 1，范围 $-0.502$ 至 $0.966$，中位 $|r|=0.127$）如图 6。直觉预期“组内紧密、组间松散”，实测相反：香气组内中位 0.124、风味组内 0.152，而两组之间 0.151。真正强的是\textbf{同名维的跨通道配对}——香气·酯与风味·酯 0.836、酒花—酒花 0.828、麦芽—麦芽 0.825；15 对同名维中位 \textbf{0.692}，12 对超 0.6，而全体非对角中位仅 0.127。即“闻到的酯香”与“尝到的酯味”几乎是同一变量，共享同一化学来源。

这一结构对本文有三点直接含义。第一，50 维不是 50 个独立任务，组间共享信息主要沿“同名维”这条轴，而非沿香气/风味的分组边界，因此按通道分组共享表示未必能带来增益（第 9 章的分组多任务对照验证了这一点）。第二，全局最强的一对是陈酒花与畜栅味（0.966），二者几乎等价，提示这两维在化学上难以分离，也预示弱信号维的归因会互相混淆。第三，36 对 $|r|\ge 0.6$ 的目标若逐维独立建模，等于把同一信号重复学习多次，这是本文仍选择逐维建模的代价——换来的是每维可独立诊断与解释。

分位分箱并非唯一选择。本文对分位分箱与等距分箱做了灵敏度对照：等距分箱把连续值按极差等分为 7 段，在偏态的标准化连续值上，50 个维度合计产生 8 个空等级、最小等级平均仅占 0.9\% 的样本、各等级样本数的变异系数高达 1.155；分位分箱则没有空等级、每等级平均占 13.8\%，接近 1/7，变异系数仅 0.022。等距分箱把多数样本压到中段，平均 QWK 反而略高（0.4013 对 0.3830），但这一偶然优势以空等级与严重失衡的等级频次为代价，对偏态分布不稳健；分位分箱的等级频次跨维可比、无空等级，且只依赖秩、对单调变换稳健，故本文采用后者。两口径下 QWK 绝对量级的依赖关系在 9.3 节另作说明。

分位分箱有一个容易被忽略的前提：各维度的连续标签必须足够分散，否则 6 个分位点会挤在极窄的区间内，切出的 7 个等级在原始尺度上无法区分。本文对 50 个维度逐一做了这项诊断，以“前 5 个切点跨度占该维极差的比例”作为退化程度的度量。结果显示有 5 个维度显著退化：acetic 为 0.006、coriander 与 clove 为 0.008、lactic 为 0.011、orange 为 0.033，它们的等级虽然仍各占约 14\% 的样本，但这些等级对应的原始强度几乎重叠，等级之间的边界不具备实际含义。

对这一现象有两种应对思路。第一种是保留分位分箱，承认这些维度的等级划分在市场意义上只是“相对排序”。第二种是改用\textbf{有序回归}，直接学习“是否越过某一等级阈值”，不依赖分位点落在哪里。为判断第二种是否真的更好，本文在同一批样本、同一 5 折划分、同一 LightGBM 家族下做了对照：回归分支沿用现有流程，有序分支对每个内部阈值训练一个“标签高/低于该阈值”的二分类器，将各阈值的预测概率累加后取整得到 6 级等级。

表 3 的对照结果分界非常清晰：退化维上有序回归平均由 0.2052 升至 0.3715、提升 \textbf{0.166}；其中 lactic 由 0.315 升至 0.611、clove 由 0.127 升至 0.305、coriander 由 0.093 升至 0.228；而在其余 45 维上，统一换用有序回归不但没有提升，反而平均下降 0.0041，甜味、酯类等标签分布较散的维度降幅更明显（甜味由 0.600 降至 0.494）。这一分化说明，有序回归的优势并非普遍存在，它恰好补偿的是分箱在密集分布上的信息损失；当标签本身足够分散时，连续回归保留的强度信息反而更有价值。因此本文只在退化维上切换，而不是全部换用。

据此把判据接入主流水线：退化维改用\textbf{类加权有序回归}（6 个阈值各训一个二分类器、按两侧频率反比加权），其余维保持不变。自动识别的退化维为 orange、coriander、clove、lactic、acetic 共 5 个，折外 QWK 由 0.3663 升至 \textbf{0.3830}（+4.6\%），5 维全部改善。需如实说明：若铺到全部 50 维，QWK 0.4089、Spearman 0.4509、$\pm$1 58.7\% 三项更高；但该分支输出等级期望值而非连续强度，而问题二、三都依赖连续底座，故以 0.026 的 QWK 换取三问共用。

判据只依赖标签分布形态、在建模前即可确定，不接触验证信息；切换也是单侧的，只有退化维改用有序回归。作为对照，嵌套交叉验证下的逐维自适应选型无偏估计为 0.3856，但内层样本仅约 133 条、受抽样噪声驱动，反使 17 个原本良好的维度退化，未予采用。

\subsection{预测模型与求解过程}

对每个感官维度 $j$，本文训练一个独立的梯度提升回归器 $h_j$，以平方损失加正则求参：

\begin{equation}
\Theta_j=\arg\min_{\Theta}\ \sum_{i\in\mathcal{D}_{tr}}\big(Y_{ij}-h_j(x_i;\Theta)\big)^2+\Omega(\Theta),
\end{equation}

其中 $h_j$ 为梯度提升树集成，$x_i$ 的缺失分量由树的默认分裂方向处理，训练集 $\mathcal{D}_{tr}$ 包含全部含缺失样本，不删行；$\Omega$ 为叶子数、学习率与 L2 正则项。50 个维度共享同一化学特征矩阵 $X$。

整个求解按固定随机种子 42 执行，流程为：读入数据并分出 231 个特征列与 50 个标签列；按风格做分层 5 折划分，保证各折风格分布一致；在每个训练折内估计分箱映射 $g_j$、拟合回归器 $h_j$、记录特征重要性；在验证折上生成连续预测并经式 (2) 得到整数等级，逐维累计二次加权 Kappa、平均绝对误差与决定系数；同口径跑均值、线性与随机森林基线以及插补对照；最后在全部 250 样本上重训一次，对全样本输出 0-6 分级写入结果文件。完整流程见算法 1。

\begin{algorithm}[htbp]
\caption{问题一：分层五折的有序感官分级预测}
\label{alg:q1}
\small
\begin{algorithmic}[1]
\Require 化学矩阵 $X\in\mathbb{R}^{250\times231}$（含 NaN）、标准化感官标签 $Y\in\mathbb{R}^{250\times50}$、风格标签、折数 $K=5$、种子 42
\Ensure 折外等级 $\hat y\in\{0,\dots,6\}^{250\times50}$、连续预测、逐维指标
\State 按风格分层：样本量 $\ge 5$ 的风格各自成层，其余并入 \texttt{\_rare}
\State 用 \texttt{StratifiedKFold}$(K=5,\ \mathrm{seed}=42)$ 切分
\For{每一折 $(\mathcal{D}_{tr},\mathcal{D}_{va})$}
  \For{每个感官维 $j=1$ \dots 50}
    \State 在 $\mathcal{D}_{tr}$ 上估计 6 个分位点 $\{q^{(j)}_\ell\}$，得映射 $g_j$
    \State 诊断分箱退化：若 $(q_5-q_1)/(\max Y_{\cdot j}-\min Y_{\cdot j})<5\%$ 则判为退化维
    \If{非退化维}
      \State 训练 LightGBM 回归 $h_j$（叶片 8、学习率 0.05、150 轮、L2=$1.0$）
      \State $\hat y_{ij}\leftarrow\mathrm{round}(g_j(h_j(x_i)))$，截断到 $[0,6]$
    \Else
      \State 在 6 个内部阈值上各训一个类加权二分类器（正负样本按频率反比加权）
      \State 累加各阈值概率得等级期望，取整即 $\hat y_{ij}$
    \EndIf
  \EndFor
\EndFor
\State 汇总逐维 QWK、Spearman、MAE、RMSE、$\pm1$ 与严格一致率
\State 在全部 250 样本上重训，输出提交用的 0--6 分级
\end{algorithmic}
\end{algorithm}

\subsection{预测区间与不确定性}

点预测无法告诉使用者“这个 4 级有多可信”。本节为每个感官维给出 90\% 预测区间，并比较两种口径。第一种是\textbf{直接分位数回归}：把 LightGBM 的目标函数换成 $\alpha=0.05$ 与 $\alpha=0.95$ 的分位数损失，两个模型分别给出下界与上界。第二种是 \textbf{split-conformal}：在每个训练折内再切出 30\% 作校准集，用点模型的绝对残差取 $\lceil (n+1)(1-\alpha)\rceil$ 分位作为半宽，对验证折输出对称区间。

结果见\textbf{图 12}。直接分位数回归的平均覆盖率为 \textbf{75.3\%}，显著低于名义的 90\%，平均宽度仅 1.025 个标准化单位——区间偏窄，属于典型的\textbf{欠覆盖}；这与 250 样本、50 个维度逐维拟合的设定相符：分位数损失在小样本上对尾部估计不稳，两个分位模型各自独立拟合，误差难以相互抵消。split-conformal 则把覆盖率拉回 \textbf{90.2\%}、达到名义的 90\% 目标，代价是平均宽度增至 \textbf{1.555}，即用更宽的区间换取覆盖率的名义保证。分组看，香气 0.902、风味 0.899、口感 0.904，三组基本一致，说明校准并未在某一组上系统性失效。

这一对照也说明了选择 conformal 的理由：它不依赖分布假设，只要求校准集与验证集可交换，在本题这种小样本、逐维多输出的场景下比直接分位数回归更可靠。区间宽度的量级（约 1.55 个标准化单位）也从侧面量化了问题一的固有难度——即便覆盖率达标，单个样本的感官等级仍存在相当的不确定性，这与 MAE 1.50 级的结果相互印证。

\caption{90\% 预测区间的两种口径：覆盖率与宽度}

总体覆盖率达标不等于每一维都达标。\textbf{图 13} 把 50 个维度逐一铺开：共形口径下的覆盖率落在 0.836--0.936 之间，其中 5 维低于 0.88——香气·木质（0.836）、香气·焦糖（0.868）、味·异丁酸乙酯（0.872）、味·酯（0.876）与味·果香酯（0.876）；最高的几维是香气·乙酸乙酯（0.936）、味·热带果（0.932）与畜栅味（0.928）。偏差的方向与信号强度一致：覆盖率偏低的都是弱信号维，其标签分布集中、残差尾部难以由 30\% 的校准集稳定刻画；而分位数回归在全部 50 维上都落在 0.704--0.836，从无一维达到名义水平，这也解释了为什么它的总体覆盖率只有 75.3\%。

\section{问题二：化合物共表达图与关键化合物归因}

\subsection{共表达图构建与模块结构}

问题二要为每个感官维度找出 Top-3 关键\textbf{化合物}，而化合物之间高度相关会干扰归因。为严格贴合找出关键化合物的题意，本文先把 231 个化学特征中的 16 个理化/过程参数（酒精度、色度、pH、苦度、二氧化碳压力、蛋白、甘油、未发酵糖等）与 4 个多化合物汇总列（总酯、酒花香气总量、总酸、含硫总量）排除，仅在 \textbf{211 个单一化合物构成的候选集 $C$（$|C|=231-16-4=211$）} 内建图与归因；问题一的特征矩阵仍保留全部 231 列，因为理化指标对预测同样有用。借鉴基因共表达网络的建模思想\cite{b13,b14}，本文以 $C$ 中化合物为节点、以化合物相关系数为边权构建无向图，并按相关强度阈值化去除弱边：

\begin{equation}
E=\big\{(p,q):\ p,q\in C,\ |R_{pq}|\ge \rho\big\},\qquad w_{pq}=R_{pq},\quad \rho=0.5,\ |C|=211.
\end{equation}

关于相关系数口径：附件 2 标称 Pearson，本文从 1.csv 重算 Pearson 与 Spearman，26565 对化合物相关系数的中位绝对差仅 0.062，二者对模块结构的刻画几乎一致。为与附件保持一致，边权沿用附件 2 的相关值；7.3 节的建图阈值灵敏度还会说明结论对该选择不敏感。在所得图上做 Louvain 贪心模块度社区检测\cite{b15}以识别化合物模块，模块度定义为

\begin{equation}
Q_{mod}=\frac{1}{2m}\sum_{p,q}\Big(w_{pq}-\frac{k_p k_q}{2m}\Big)\,\delta(c_p,c_q),\qquad k_p=\sum_q w_{pq}.
\end{equation}

在阈值 $\rho=0.5$ 下，共表达图含 \textbf{211 个节点、564 条边}，社区检测得到 \textbf{55 个社区}，模块度 $Q_{mod}=0.625$，远高于随机网络的水平，表明化合物确实存在明显的模块化组织结构。

图 13(a) 中节点按 Louvain 社区着色、面积正比于度数，各社区沿全局质心方向外推后留出空白，主要模块标出枢纽化合物；可见同一酿造来源或同一代谢途径的化合物聚成一个模块，且模块之间有明确分界。图 13(b) 回答孤立节点的来源：以 $\rho=0.5$ 建图时 44 个化合物没有达到阈值的伙伴，但它们的最大 $|r|$ 中位为 0.444、其中 11 个落在 0.48–0.50，说明孤立主要是硬阈值截断的结果，而非这些化合物与其余 210 个真正无关；阈值降到 0.45 时孤立数即从 44 降到 23。

社区规模分布显示 55 个社区高度不均衡：前 8 个大社区，各有 11–28 个化合物，已包含 159 个节点（约 75\%），其余多为 1–2 个化合物的小簇。这一结构正是归因去冗余的依据：若不加约束，同一模块内可互相替代的化合物会把一个维度的 Top-3 名额占满，掩盖真正多样的驱动因素。因此下一步的关键度打分必须引入模块代表机制。在融合模型证据之前，先看化学与感官之间最直接的线性关联。

\subsection{多证据融合 Top-3 归因}

对每个感官维度 $j$，本文融合三类证据给化合物 $p$ 打关键度分：

\begin{equation}
\phi_{jp}=\alpha\,\widetilde{\mathrm{SHAP}}_{jp}+\beta\,\big|\tilde C_{pj}\big|+\gamma\,\mathrm{rep}_{jp},\qquad \alpha+\beta+\gamma=1.
\end{equation}

其中 $\widetilde{\mathrm{SHAP}}_{jp}$ 是问题一模型对维度 $j$ 的归一化 SHAP 值，刻画非线性预测贡献；$\tilde C_{pj}$ 是化学与感官交叉相关的归一化绝对值，刻画线性关联；$\mathrm{rep}_{jp}$ 是模块代表加权，使同模块内多个可互替化合物只保留关键度最高者进入候选，避免 Top-3 被单一模块占满，这一簇代表的思路与稳健特征选择中的聚类代表方法一致\cite{b16}。按权重 $\alpha=0.5,\beta=0.3,\gamma=0.2$ 取每维得分前三者：

\begin{equation}
\mathrm{Top3}(j)=\operatorname*{arg\,top3}_{p}\ \phi_{jp}.
\end{equation}

SHAP 值通过对问题一全量梯度提升模型使用树解释器逐样本计算得到，权重 $\alpha$ 最大体现了以预测贡献为主、相关与去冗余为辅的归因哲学。为避免同一模块内高度相关的化合物重复占满 Top-3，在 argtop-3 选取时还施加显式去冗余规则：当候选 $p$ 与某个已入选化合物 $q$ 同属一个社区且 $\lvert R_{pq}\rvert\ge 0.7$ 时跳过 $p$，即 $c_p=c_q\neq-1$ 且二者强相关时 $p$ 不再入选，强制 Top-3 来自相互独立的化学证据，而非三个彼此近似的共表达冗余物。最终每个维度恰好交付 3 个化合物。从建图到证据分级、再到分层重采样的完整流程见算法 2。

\begin{algorithm}[htbp]
\caption{问题二：共表达图构造与三路证据融合的 Top-3 归因}
\label{alg:q2}
\small
\begin{algorithmic}[1]
\Require 化学矩阵 $X\in\mathbb{R}^{250\times231}$、感官标签 $Y$、交叉相关 $C$、问题一模型、重采样次数 $B=500$
\Ensure 每维 Top-3 化合物、入选频率、证据等级 A/B/C
\State 剔除 16 个理化参数与 4 个汇总列，得化合物集 $C$（$|C|=211$）
\State 以 $|R_{pq}|\ge\rho=0.5$ 建边、边权取 $R_{pq}$，得 211 节点、564 边的共表达图
\State 用 Louvain 贪心模块度做社区检测，得 55 个社区、模块度 $Q=0.625$
\For{每个感官维 $j$}
  \State 对 $p\in C$ 计算三路证据：归一化 SHAP、$|\tilde C_{pj}|$、模块代表权重
  \State 融合打分 $\phi_{jp}=0.5\,\widetilde{\mathrm{SHAP}}+0.3\,|\tilde C|+0.2\,\mathrm{rep}$
  \State 按 $\phi_{jp}$ 降序贪心取 3 个，同社区且 $|R|\ge0.7$ 者跳过（去冗余）
\EndFor
\State 按风格分层重采样 $B=500$ 次，每次重算 Top-3，统计入选频率 $f_{jp}$
\State 在 200/300/500 三处设检查点，确认 Top-1 选择已收敛
\State 做两组置换实验：单独打乱该化合物（条件增量）与打乱整个社区（模块增量）
\State 按四条件判 A/B/C：频率 $\ge0.8$、折外 $R^2>0$、$\ge3$ 折为正、超置换 95\% 分位
\end{algorithmic}
\end{algorithm}

\subsection{稳定性量化}

\begin{figure}[htbp]
\centering
\includegraphics[width=0.88\textwidth,height=0.217\textheight,keepaspectratio]{fig_q2_rho_sweep.png}
\caption{建图阈值 ρ 的灵敏度：边数、孤立节点与模块度的取舍}
\end{figure}

阈值 ρ 不是随手取定的常数。图 16(a) 显示边数随 ρ 单调塌缩：0.40 时 1500 条边、最大分量 200 节点，0.60 时只剩 234 条边、86 节点；图 16(b) 给出另一侧代价：孤立节点从 11 升到 95，而模块度在 0.55–0.60 才见顶（0.684、0.704）后回落。ρ=0.5 是折中点：保留 159 节点的连通骨架、模块度 0.625。本文据此固定 ρ=0.5。

稳定性严格按题面指定的两种口径量化。第一种是 bootstrap 入选频率\cite{b19}：对样本做 $B=500$ 次\textbf{按风格分层}的有放回重采样（样本量少于 5 折的风格合并为 \texttt{\_rare} 一层，避免小风格被抽空），每次重算 Top-3，统计化合物 $p$ 进入维度 $j$ 的 Top-3 的频率

\begin{equation}
f_{jp}=\frac{1}{B}\sum_{b=1}^{B}\mathbb{1}\!\left[p\in\mathrm{Top3}^{(b)}(j)\right]\in[0,1].
\end{equation}

为确认 $B=500$ 已收敛，本文另在 200 次与 300 次处设检查点：三个规模下 Top-1 频率均值为 0.9996/0.9997/0.9997，相对最终结果的 Top-1 选择\textbf{改变 0 维}，说明 500 次已充分稳定。

第二种是跨方法 Jaccard：对 SHAP 法交叉相关法随机森林重要性法三类方法两两比较其 Top-3 集合，

\begin{equation}
\mathrm{Jac}(A,B)=\frac{|A\cap B|}{|A\cup B|}\in[0,1].
\end{equation}

入选频率高说明单一方法内部稳健，Jaccard 高说明不同证据之间一致。为回答这样的稳定性是否显著优于随机，本文还构造了随机基线：在 211 个化合物集 $C$ 上随机抽取 3 个作为 Top-3，重复 100000 次，计算随机 Top-3 与固定参照的 Jaccard 期望。两指标的全维分布如下图。

图 17(a) 的联合分布把两个口径放在同一平面上：横轴方向 50 个维度几乎全部堆在 1.000（$47/50$），说明单方法内部的 Top-1 选择极其稳健；纵轴方向则从 0 铺到 0.72，平均 \textbf{0.200}，即三类证据的 Top-3 集合平均约两成重叠。图 17(b) 把实测 Jaccard 与“两个独立随机 3 子集”的零分布并列，实测累积曲线整体右移。而 10 万次随机抽取的 Jaccard 期望仅 \textbf{0.0086}，本文 0.200 是随机基线的 \textbf{23.3 倍}——这意味着虽然三类证据视角互补、绝对 Jaccard 不高，但相对于随机抽取已高度显著，归因绝非偶然。这一高入选频率、中等 Jaccard、远高于随机的组合恰如实反映了 SHAP、线性相关与共表达三类证据侧重不同、各自内部稳定而彼此互补，而非虚高的一致。

\subsection{融合增益消融与归因集中度}

7.2 节的三路融合建立在两个未经检验的假设上：共表达模块代表的引入能让 Top-3 覆盖更多化学模块，以及三类证据的结合优于任一单方法。本节对这两个假设做消融，并进一步考察 Top-3 结果在维度间的集中程度。

消融（表 8）保持去冗余规则、候选集 $C$ 与 Top-3 基数完全不变，只替换证据来源，构造四个变体：仅 SHAP、仅交叉相关、SHAP 与相关两路融合，以及本文采用的三路融合。评价指标取“模块覆盖数”，即某一变体的 Top-3 落在多少个互不相同的 Louvain 社区内；覆盖数越高，说明选出的三个化合物越来自不同的化学模块，去冗余的意图越得到落实。

图 24 把 150 个 Top-3 席位按化合物归并，左侧的累计曲线显示：仅 4 个化合物（acetaldehyde、MeSH、ethyl octanoate、DMS）就占据了 32\% 的席位，而其余 26 个化合物各只出现一次。右侧把席位按化合物来源拆开，并与各感官维的期望来源对比：酵母代谢产物占了约 60\% 的席位，而各感官维的期望来源中酵母仅占 24\%；反之，麦芽来源的席位仅占 9\%，而期望来源为麦芽的维度占 20\%。这一偏离与后文的来源一致性检验相互印证：模型倾向于选出丰度高、检出稳定的酵母酯醇，而麦芽焙烤类化合物在成品中检出稀疏，难以在排序中进入前三。

三路融合的模块覆盖数为 2.92，接近满分 3，比仅用相关高出 27.0\%，也比仅用 SHAP 高出 12.3\%。这说明模块代表项确实在做它该做的事：若只依赖 SHAP，同一共表达模块里高度相关、可以互相替代的化合物会把 Top-3 名额占满；引入模块代表与同社区去冗余后，三个席位更可能分属不同化学证据。需要注意的是，仅 SHAP 的 Top-1 覆盖了 34 个不同化合物，看似更“分散”，但其 Top-3 的模块覆盖仅 2.60，说明这种分散来自对同一模块内不同成员的反复选择，而非跨模块的多样化。仅用交叉相关的覆盖最低（2.30），反映线性相关更容易被整体丰度共变主导。

接着考察归因结果在维度之间的集中程度。50 个维度共使用了 50 个不同的 Top-1 化合物，但分布极不均衡：acetaldehyde 出现在 16 个维度的 Top-3 中，MeSH 12 次、ethyl\_octanoate 10 次、DMS 10 次；另一方面，26 个化合物只进入过 1 个维度。前四个化合物合计占据了 150 个 Top-3 席位中的 48 个。

这种集中有两种可能解释：一是这些化合物是多个感官维度共享的真实驱动，二是它们只是整体风味强度的统计代理，因与某些维度共同变化而被动入榜。为区分二者，本文计算每个维度 Top-1 化合物与 overall 维度的相关性：中位 $|r|$ 为 0.228，属于中等偏弱。若集中完全由整体强度造成，Top-1 应普遍与 overall 高度相关；实测的中等相关水平说明整体强度只能解释一部分集中现象，剩余部分应归因于化合物与特定感官维度的实质关联。这与 7.3 节的结果相互印证：Top-1 的 bootstrap 入选频率在 47/50 维上恰为 1.000，说明这些选择在重采样下高度稳定，并非偶然的共变假象。

Top-3 结果需经得起酿造机理的检验。方法学上最具说服力的一例是酯香维度：异戊酯香气维 A\_esters\_isoaa 对应香蕉味，其 Top-1 关键化合物正是 isopentyl\_acetate，即异戊基乙酸酯，它恰恰是公认的香蕉味酯，其 Top-3 三者，即异戊基乙酸酯、正己醇、苯甲醛，均为酵母发酵产物、bootstrap 频率均为 1.0、来源判定为一致；指甲油味酯维 A\_esters\_ethac 的 Top-1 是 ethyl\_acetate，即乙酸乙酯与指甲油气味的主体，同样机理一致。这说明在因果清晰的维度上，数据驱动的归因确实命中了正确的分子。

为系统检验而非只举成功个例，本文借助 8.xlsx 的 Sensory thresholds 表对每个化合物标注来源，分为酵母、酒花、麦芽、香料、野生菌群、其他，按感官类别推断每个感官维的期望来源，逐维判定 Top-3 属于一致、部分一致还是不一致：三者全部来自期望来源为一致，至少一个来自期望来源为部分一致，无一个来自期望来源为不一致，并入图 26 的桑基图汇总感官类别到化合物来源的流向。

\section{问题三：风格条件生成与跨风格迁移}

\subsection{条件变分自编码器}

问题三要学习一个以风格为条件的化学谱生成模型，并在小样本下保持风格可区分。本文采用条件变分自编码器\cite{b17}：编码器 $q_\phi(z\mid x,s)$ 把 231 维化学谱连同风格条件压缩进低维隐空间，解码器 $p_\theta(x\mid z,s)$ 从隐变量与风格条件重建化学谱。模型最大化证据下界

\begin{equation}
\mathcal{L}(\theta,\phi)=\mathbb{E}_{q_\phi(z\mid x,s)}\big[\log p_\theta(x\mid z,s)\big]-\beta_{KL}\,\mathrm{KL}\!\big(q_\phi(z\mid x,s)\,\big\|\,p(z)\big),
\end{equation}

其中先验 $p(z)=\mathcal{N}(0,I)$，采用重参数化 $z=\mu_\phi+\sigma_\phi\odot\epsilon$ 使梯度可回传。为避免缺失位置污染梯度，重构项只对非缺失分量计算误差：

\begin{equation}
\log p_\theta(x\mid z,s)\ \propto\ -\tfrac12\sum_{p:\,M_{ip}=0}\big(x_{ip}-\hat x_{ip}\big)^2.
\end{equation}

隐维取 16 以适配 250 的小样本规模。生成时给定目标风格，从先验采隐变量并解码，即得该风格的化学谱。训练与迁移的完整流程见算法 3，架构的整体结构如下。

\caption{问题三风格条件生成（CVAE）架构}
\end{figure}

图 27 自左向右呈现了编码器、隐空间、条件解码器、缺陷阈值投影到感官画像打分的完整链路。架构中缺陷阈值投影是迁移任务的硬约束执行点，Q1 感官画像则把问题一的预测模型接回来形成闭环，二者是本问区别于一般无条件生成的两处关键设计。

训练初期曾出现后验坍塌：当 $\beta_{KL}=1$ 时 KL 项迅速趋零、重构质量差，KS 距离约 0.6。本文按建模阶段预案做等价的数值稳定化——把 $\beta_{KL}$ 降至 0.1，并对 KL 项施加前 120 轮线性退火与每维 0.5 nats 的 free-bits 下限，重构损失由 0.765 降至 0.255，KS 距离随之降到 0.36 至 0.41 区间。这一处理只改变优化过程、不改变题设与数据。

\begin{algorithm}[htbp]
\caption{问题三：风格条件 CVAE 生成与带缺陷投影的跨风格迁移}
\label{alg:q3}
\small
\begin{algorithmic}[1]
\Require 标准化化学谱 $X_{\mathrm{std}}$ 与缺失掩码 $M$、风格 one-hot $s$、隐维 $d=16$
\Ensure 三风格各 30 条生成谱、11 条迁移谱与缺陷合规标志
\State 编码器 $q_\phi(z\mid x,s)$：$x$ 与 $s$ 拼接后经隐层输出 $\mu,\log\sigma^2$
\State 重参数化 $z=\mu+\sigma\odot\epsilon,\ \epsilon\sim\mathcal{N}(0,I)$
\State 解码器 $p_\theta(x\mid z,s)$ 重建 231 维化学谱
\For{每一轮训练}
  \State 重构损失只在 $M_{ip}=0$ 的非缺失位上计算
  \State 总损失 $=$ 重构 $+\ \beta_{KL}\!\cdot\!\mathrm{KL}$，$\beta_{KL}=0.1$ 且前 120 轮线性退火
  \State KL 每维施加 0.5 nats 的 free-bits 下限，防后验坍塌
  \State 用 Adam（学习率 $10^{-3}$、批大小 64）更新；退火结束后按早停选最优权重
\EndFor
\State 生成：从先验采 $z$ 并给定目标风格 one-hot，解码得该风格化学谱
\State 迁移：$\Delta_{s\to t}=\bar z_t-\bar z_s$，把源样本 $z_s+\Delta$ 解码
\For{每个缺陷列 $k$ 与每条迁移样本}
  \State $x_k^{after}\leftarrow\min(\tilde x_k^{after},\ \min(x_k^{before},m_k^{t}))$
\EndFor
\State 把全部生成与迁移谱截断到各列训练观测区间 $[\ell_k,u_k]$
\end{algorithmic}
\end{algorithm}

\subsection{跨风格迁移与缺陷约束}

跨风格迁移在隐空间以风格质心之差作为平移向量实现：

\begin{equation}
\Delta_{s\to t}=\bar z_t-\bar z_s,\qquad \hat x_{t}=p_\theta\big(z_s+\Delta_{s\to t}\,\big|\,\mathrm{onehot}(t)\big),
\end{equation}

其中 $\bar z_c$ 为风格 $c$ 所有样本隐编码的均值。把源风格样本编码后沿该方向平移再解码，即得目标风格化学谱。迁移必须守住缺陷不恶化的硬约束，本文对每个缺陷化合物 $k$ 逐样本做下截断投影：

\begin{equation}
x^{def}_{k,after}\ =\min\!\Big(\tilde x^{def}_{k,after},\ \ \min\big(x^{def}_{k,before},\ m^t_k\big)\Big),
\end{equation}

其中 $\tilde x^{def}_{k,after}$ 为隐空间平移并解码得到的\textbf{无约束}值，$x^{def}_{k,before}$ 为该样本源风格 Pils/Lager 缺陷 $k$ 的原始含量，$m^t_k$ 为目标风格 Tripel 缺陷 $k$ 的典型分位值，取中位。该投影逐样本取三者最小值，构成两道防线：源款原值 $x_{before}$ 保证迁移后缺陷绝不高于源款，目标典型值 $m^t_k$ 作为第二道绝对阈值兜底。由于各化学维单位不可比、绝对阈值无法统一换算，本题不并入绝对阈值 $\tau^{*}_k$，默认关闭。8.3 节将以同一批样本不做投影的纯平移结果作为对照，量化该约束不可或缺。

表 10 显示三者各有强弱。重采样分布保真最好、KS 仅 0.098；但重复率 \textbf{100\%}、新颖性恒为 0，只能补样本量而不能产生新谱。高斯采样新颖性 18.1，却假设各化合物独立，相关结构差异 0.309 为三者最差、仅 80.5\% 落在观测区间。CVAE 的 KS 为 0.388，新颖性中位 40–657、相关结构差异 0.275，是唯一同时满足“生成新谱”与“保留共表达结构”的方案。

这一对照给出的结论不是“CVAE 全面占优”，而是\textbf{三种方法对应不同的任务需求}。若任务只是补足样本量，风格内重采样在分布意义上更可靠；但本题要求的是条件生成与可控迁移，即在给定风格下生成新的化学谱、并在隐空间中把源风格沿特定方向推向目标风格。重采样无法产生新谱，高斯采样不具备可解释的隐空间方向，只有 CVAE 能同时提供这两项能力。本文因此选择 CVAE，并把分布保真上的劣势如实列出，而不是以单一 KS 指标宣称生成质量全面领先。

\section{模型检验与灵敏度分析}

\subsection{验证方案与防泄漏}

三问的可信度都建立在独立的验证之上，且全程贯彻防泄漏纪律。问题一采用按风格分层的 5 折交叉验证，分箱分位点与标准化参数只在训练折估计、再施加到验证折，杜绝了在全量数据上估分箱这一最隐蔽的泄漏。问题二以 500 次按风格分层的 bootstrap 给出单方法稳健性（200/300/500 三次检查点 Top-1 无变化）、以三法 Jaccard 给出方法间一致性，化学合理性再以交叉相关与酿造机理双重佐证。问题三对生成以分布距离与降维簇重叠评估，对迁移以缺陷合规率这一硬指标评估，并用问题一感官画像核验风格特征。本题没有隐藏测试集，所有数字都如实标注为交叉验证或分布距离的内部估计。

本文系统排查了六类泄漏并逐一封堵：分箱与标准化参数折内估计；主办方模型的参考重要性只作问题二旁证、不进入问题一训练特征；样本主键与风格标签不进入问题一特征矩阵；不对风格做目标编码。此外，附件 2 与 1.csv 的关联经核验只能按 \texttt{beer} 名称与行序对齐，按 \texttt{beer\_id} 会因精度丢失只剩 37/250 行，本文对此显式断言而非静默合并。

\subsection{方法增益的消融汇总}

第 6 至 8 章的每处设计均配有对照，本节集中列出，量纲不同故统一换算为相对百分比。

各环节的增益排序与预期一致，但性质不同：融合与分维选型是实质性改进——模块覆盖 2.30$\to$2.92，折外 QWK 0.3663$\to$0.3830（+4.6\%）且增益完全集中在 5 个退化维上，与 6.2 节的退化诊断相互印证；缺失处理（+0.3\%）与值域截断（+1.6\%）则属正确性修正，前者的价值在于不删样本、把缺失当作可用信息，后者在于消除解码器外推造成的量级失控。

\subsection{模型层的两项对照实验}

本节报告两项离线对照：问题一的分组共享多输出（方案 A），以及问题三的判别辅助损失与按风格留出。两者都不改变主结果——主模型 0.3830、提交用的生成谱与迁移谱均保持原样，对照只用于回答“共享表示是否值得”与“隐空间能否被修好”这两个方法层面的问题。

\subsubsection{问题一：分组共享多输出（方案 A）}

主模型对 50 个维度各自独立训练。若同一组内的感官维确实共享化学驱动，把同组其他维的折内预测当作附加特征，应能借助组内相关性降低方差。本文按香气（15）/ 风味（15）/ 口感缺陷（20）三组实现这一思路：在每个训练折内，先用组内 5 折 OOF 预测构造“组画像特征”（只用训练折样本，防泄漏），再把每个目标重新训练为“231 原始特征 + 同组其余 $k-1$ 个组画像特征”；分箱退化维仍用类加权有序回归，与主模型同一判据、同一实现。

结果与预期相反：该方案宏平均 QWK 为 \textbf{0.3759}，低于主模型的 0.3830。配对 bootstrap 2000 次给出 $\Delta$QWK $=+0.0070$、95\% 区间 $[0.0001,0.0139]$，主模型在 97.7\% 的重采样中更优。分组看更清楚：香气由 0.322 降至 0.305、风味由 0.400 降至 0.394，两组都退步；只有口感缺陷组基本持平（0.416 降至 0.415）。

这一负结果本身有信息量。结合 6.2 节的相关矩阵可知：真正强的相关是“同名维的跨通道配对”（香气·酯与风味·酯 0.836、香气·酒花与风味·酒花 0.828），而不是“组内维之间”（香气组内中位 $|r|=0.124$）。按通道分组恰好把最相关的配对（A\_ 与同名 F\_）切开，组画像特征因此只能提供弱信息，却额外引入 14--19 个含噪特征，在 250 样本上放大了过拟合。换言之，组内共享表示的收益取决于相关结构是否与分组边界对齐，而本题的结构恰好不对齐。本文因此保留逐维独立建模。

\subsubsection{问题三：判别辅助损失能否修复隐空间塌缩}

问题三已报告一个关键局限：三风格隐质心的置换检验 $p=0.92/0.99/1.00$，即 16 维隐空间里不存在超出噪声的风格结构。本文在编码器输出 $z$ 上加一个线性风格分类头，把总损失改为 $L=L_{\mathrm{recon}}+\beta_{KL}\cdot\mathrm{KL}+\lambda\cdot\mathrm{CE}(s\mid z)$，其余设定（KL 退火、free-bits、截断、隐维 16、600 轮）完全不变，只扫 $\lambda\in\{0,0.02,0.1,0.3,0.5\}$。

结果是一条清晰的权衡曲线（图 38）。$\lambda=0$ 即现状：置换检验 $p=1.00$、隐空间线性分类准确率 3.2\%（随机基线 4.5\%）。只要加入判别项，隐空间立刻可分：$\lambda=0.02$ 时 $p=0.000$、分类 54\%；$\lambda\ge0.1$ 时分类接近 100\%。但代价同步上升：生成谱 KS 由 0.373 依次升至 0.392 / 0.411 / 0.445 / 0.468，重构 MSE 由 0.266 升至 0.284 / 0.340 / 0.397 / 0.429。判别约束确实修好了“风格在隐空间不可辨识”这一缺陷，但收益建立在分布保真之上。

本文不把判别头并入主模型，因为任务目标是生成像真实的化学谱，而不是让隐空间可分；为一个诊断指标牺牲 KS 与重构质量，与任务目标不一致。这一对照的价值在于把局限的性质说清：隐空间塌缩不是训练不足或超参没调好，而是“重构全部 231 列”这一目标本身的取舍——加入显式风格判别项即可改变，但代价可量化。若后续任务更看重风格可控性（例如按风格插值），本文推荐 $\lambda=0.02$ 这一折中档：风格已显著可分，而 KS 只上升 0.019。该结论在 seed 7 上复现（$\lambda=0$：$p=1.00$、分类 5.2\%；$\lambda=0.1$：$p=0.000$、分类 99.2\%）。

表 10 是静态对照（用全部真实谱拟合生成器，再与同一批真实谱比较）。更能反映泛化的是留出口径：每折只用训练折拟合生成器、留出折作参照分布。本文对三种生成器（CVAE、风格内多元高斯、风格内重采样）做同一处理，每风格每折生成 30 条。折数按风格样本量自适应，以保证每折留出不少于 5 条（Tripel 5 折，Kriek 与 Lambic 各 2 折）；解读绝对值时必须考虑这一点。

\section{模型评价与推广}

\subsection{优点与创新}

第一，以共享的化学到感官预测底座贯通三问：同一套经交叉验证的模型既是问题二的 SHAP 归因对象，又是问题三生成谱的感官打分器，预测、归因与生成三者联动。

第二，归因限定为 211 个单一化合物，并以模块代表加权与同社区去冗余；三路融合把单维 Top-3 命中的模块数由 2.30 提到 2.92（满分 3），跨方法 Jaccard 0.200 为随机基线 0.0086 的 23.3 倍，并以配对 bootstrap 与 A/B/C 分级给出可信度。

第三，把缺陷不恶化形式化为 $\min(\tilde x_{after},x_{before},m_t)$ 逐样本投影，配无约束对照（72.7\% 本会升高）；另用真实浓度阈值做绝对口径审计，区分“相对不恶化”与“绝对达标”。

第四，识别出分位分箱在标签分布高度集中时失效的隐性前提，据此只在退化维改用类加权有序回归，折外 QWK 由 0.3663 升至 0.3830（+4.6\%）；并对“更强的表示”与“更可分的隐空间”两条路线做了严格对照、如实报告负结果，使方法选择有可复核依据。

\subsection{不足与改进}

其一，0-6 分级由连续值单调映射重建而非原始品评卡复现，分级绝对值带有映射口径的印记；250 样本下增维（阈值列、模块 PC1、分组共享）亦未兑现精度。

其二，生成谱需按观测区间截断、迁移依赖缺陷投影兜底，判别头以 KS 上升换取隐空间可分；来源一致率仅 12\%，高删失列未建显式删失似然。


\subsection{推广}

本文框架可推广到其他成分谱与感官建模场景：缺失感知有序预测适用于品评缺测数据，共表达图加多证据归因适用于高共线性组学或光谱筛选，带硬约束的条件生成可用于规避有害成分的配方设计。

DEGEN_SPAN = 0.05      # 前 5 个分位切点跨度 < 极差的 5% 判为退化
ORD_MIN_FRAC = 0.10    # 阈值两侧任一类占比低于 10% 时不做二分类

def binning_degenerate(ytr, span_th=DEGEN_SPAN):
    """判断该维的分位分箱是否退化：切点挤在极窄区间内，等级在原始尺度上不可分。"""
    y = np.asarray(ytr, dtype=float)
    y = y[np.isfinite(y)]
    if y.size < 20:
        return False
    rng = float(y.max() - y.min())
    if rng <= 0:
        return True
    edges = U.Binner().fit(y).edges
    return bool((edges[4] - edges[0]) / rng < span_th)

def _fit_ordinal(Xtr, ytr, Xva, n_levels=P.N_LEVELS):
    """类加权阈值分解：对每个内部阈值训练一个「y > t」二分类器，概率累加后取整。

    与直接回归再分箱相比，它不依赖切点位置，因而能绕开密集分布下切点重合的问题；
    阈值两侧样本不均衡时按类频率反比加权，避免多数类主导。
    """
    ytr = np.asarray(ytr, dtype=float)
    edges = np.quantile(ytr, np.linspace(0, 1, n_levels + 1)[1:-1])
    edges = np.maximum.accumulate(edges)
    acc = np.zeros(len(Xva))
    for t in edges:
        z = (ytr > t).astype(int)
        frac = float(z.mean())
        if frac < ORD_MIN_FRAC or frac > 1 - ORD_MIN_FRAC:
            acc += frac                      # 无区分度的阈值直接用先验
            continue
        w = np.where(z == 1, 1.0 / max(frac, 1e-6), 1.0 / max(1.0 - frac, 1e-6))
        clf = lgb.LGBMClassifier(**CLF_PARAMS)
        clf.fit(Xtr, z, sample_weight=w)
        acc += clf.predict_proba(Xva)[:, 1]
    return np.clip(np.round(acc), P.LEVEL_MIN, P.LEVEL_MAX).astype(int)

def _corr_evidence(C6, comp_rows6, comp_names, feat_cols, sens_cols):

    col_targets = U.align_sensory_cols(list(C6.columns))

    for ri, r in enumerate(comp_rows6):

        if pos is None:
            continue

            evid[j, pos] = abs(v) if np.isfinite(v) else 0.0
    print(f"[Q2] 6.csv 交叉相关映射化合物 {n_mapped}/{len(comp_rows6)} → 231 位置；"
          f"感官列按名映射 {len(set(col_to_j))}/50")
    return evid

def _module_rep(base_scores, comm_arr):
    """模块代表加权：同社区（仅 C，comm!=-1）内按 base 排名，第 1 名 rep=1，第 2=1/2…

    非 C 位置 comm=-1 直接跳过（rep 保持 0），促进 Top-3 跨模块多样。
    """
    rep = np.zeros_like(base_scores, dtype=float)
    for ci in np.unique(comm_arr):
        if ci == -1:
            continue                      # 非 C 节点不参与模块代表
        idx = np.where(comm_arr == ci)[0]
        order = idx[np.argsort(-base_scores[idx])]
        for rank, p in enumerate(order, 1):
            rep[p] = 1.0 / rank
    return rep

def _fuse_and_stability(sens_cols, feat_cols, shap_imp, corr_evid, rf_imp,
                        abs_shap_list, comm_arr, c_mask, R, styles):
    """多证据融合 + 去冗余 Top-3 + bootstrap 入选频率 + 跨方法 Jaccard（全部只在 C 内取）。"""
    J, Pn = len(sens_cols), len(feat_cols)
    a, b, g = P.FUSE_ALPHA, P.FUSE_BETA, P.FUSE_GAMMA
    per_dim = {}
    top3_idx = {}
    # 点估计：φ=0.5SHAP+0.3|corr|+0.2module_rep，module_rep 仅在 C 社区内
    shap_n_all = np.vstack([_norm(shap_imp[j]) for j in range(J)])
    corr_n_all = np.vstack([_norm(corr_evid[j]) for j in range(J)])
    rf_n_all = np.vstack([_norm(rf_imp[j]) for j in range(J)])
    phi_all = np.zeros((J, Pn))
    for j in range(J):
        base = a * shap_n_all[j] + b * corr_n_all[j]
        rep = _module_rep(base, comm_arr)          # 仅 C 社区
        phi = base + g * rep

        # 去冗余 Top-3（phi 先掩码到 C）
        top3_idx[j] = _select_topk(_mask_c(phi, c_mask), R, comm_arr)
    # bootstrap 入选频率：**按风格分层**有放回重采样 → 重算 SHAP → 同一融合+去冗余流程（只在 C 内）。
    # 分层可避免小样本风格在重采样中整体缺席，使频率反映"同风格内"的稳定性。
    rng_bt = np.random.default_rng(P.SEED)
    N = abs_shap_list[0].shape[0]
    style_arr = np.asarray(styles)
    strata = [np.where(style_arr == s)[0] for s in pd.unique(style_arr)]
    freq = np.zeros((J, Pn))
    B = P.N_BOOTSTRAP
    conv_trace = {}          # 200/300/500 收敛检查
    for bi in range(B):
        parts = [rng_bt.choice(idx, size=len(idx), replace=True) for idx in strata if len(idx)]
        idx = np.concatenate(parts)
        for j in range(J):
            shap_b = _norm(abs_shap_list[j][idx].mean(axis=0))
            base_b = a * shap_b + b * corr_n_all[j]
            phi_b = base_b + g * _module_rep(base_b, comm_arr)
            for p in _select_topk(_mask_c(phi_b, c_mask), R, comm_arr):
                freq[j, p] += 1
        if (bi + 1) in (200, 300, 500):
            snap = freq / (bi + 1)
            top1 = [int(np.argmax(snap[j])) for j in range(J)]
            conv_trace[str(bi + 1)] = {
                "mean_top1_freq": round(float(np.mean([snap[j, top1[j]] for j in range(J)])), 4),
                "n_top1_changed_vs_final": None,   # 稍后填
                "top1": top1,
            }
            print(f"[Q2] bootstrap {bi+1}/{B}  mean_top1={conv_trace[str(bi+1)]['mean_top1_freq']:.4f}")
    freq /= B
    # 跨方法 Jaccard（SHAP / 6.csv相关 / RF；各方法 Top-3 只在 C 内取）
    jac_dim = {}
    for j in range(J):
        ts = _topk_masked(shap_n_all[j], c_mask)
        tc = _topk_masked(corr_n_all[j], c_mask)
        tr = _topk_masked(rf_n_all[j], c_mask)
        pj = np.mean([_jaccard(ts, tc), _jaccard(ts, tr), _jaccard(tc, tr)])
        jac_dim[sens_cols[j]] = round(float(pj), 4)

    for j, col in enumerate(sens_cols):
        t3 = top3_idx[j]
        per_dim[col] = {
            "top3": [feat_cols[p] for p in t3],
            "top3_idx": [int(p) for p in t3],
            "phi": [round(float(phi_all[j, p]), 4) for p in t3],
            "shap_norm": [round(float(shap_n_all[j, p]), 4) for p in t3],
            "corr_abs": [round(float(corr_n_all[j, p]), 4) for p in t3],
            "select_freq": [round(float(freq[j, p]), 4) for p in t3],
            "module": [int(comm_arr[p]) for p in t3],
            "jaccard_cross_method": jac_dim[col],
        }
    # 收敛检查：200/300 次的 Top-1 与最终（500 次）Top-1 差异维数
    final_top1 = [int(np.argmax(freq[j])) for j in range(J)]
    for k in conv_trace:
        prev = conv_trace[k]["top1"]
        conv_trace[k]["n_top1_changed_vs_final"] = int(sum(1 for a_, b_ in zip(prev, final_top1) if a_ != b_))
        conv_trace[k].pop("top1", None)
    print("[Q2] 收敛检查:", {k: (v["mean_top1_freq"], v["n_top1_changed_vs_final"]) for k, v in conv_trace.items()})

    mean_top1_freq = float(np.mean([per_dim[c]["select_freq"][0] for c in sens_cols]))
    mean_jac = float(np.mean(list(jac_dim.values())))
    n_high_stable = int(sum(1 for c in sens_cols if per_dim[c]["select_freq"][0] >= 0.7))
    print(f"[Q2] 平均Top-1入选频率={mean_top1_freq:.4f} 平均跨方法Jaccard={mean_jac:.4f} "
          f"高稳定维={n_high_stable}")
    return {
        "problem": 2,
        "method": ("共表达图(networkx+louvain,仅C 211项) + SHAP/相关/模块代表融合(φ=0.5/0.3/0.2) "
                   "+ 同社区|R|>=0.7去冗余 + bootstrap频率 + 跨方法Jaccard + 随机基线对照"),
        "candidate_set": {"name": "C", "n": int(c_mask.sum()),
                          "excluded_physicochem": sorted(P.PHYSICOCHEM_COLS),
                          "excluded_aggregate": sorted(P.AGG_COLS)},
        "summary": {"n_dims": J, "n_bootstrap": B, "topn": P.TOPN,
                    "mean_top1_select_freq": round(mean_top1_freq, 4),
                    "mean_cross_method_jaccard": round(mean_jac, 4),
                    "n_high_stable_dims": n_high_stable,
                    "redun_rho": REDUN_RHO,
                    "fuse_weights": {"alpha": a, "beta": b, "gamma": g},
                    "bootstrap_stratified_by_style": True,
                    "bootstrap_convergence": conv_trace},
        "per_dim": per_dim, "sensory_cols": sens_cols,
    }

def _elbo_loss(xhat, x, mask, mu, logvar, beta_kl, free_bits=P.FREE_BITS):
    # 掩码重构（只对非缺失分量计 MSE，式11）
    diff2 = ((xhat - x) ** 2) * mask
    recon = diff2.sum() / mask.sum().clamp(min=1.0)
    # 逐维 KL + free-bits（每维 KL 低于 free_bits 时不再惩罚，防后验坍塌）
    kld_dim = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp())   # [B, d]
    kld_dim = torch.clamp(kld_dim.mean(dim=0), min=free_bits)
    kld = kld_dim.sum()
    return recon + beta_kl * kld, recon.item(), float(kld.item())

def _train_cvae(Xstd, mask, onehot, device):
    model = CVAE(Xstd.shape[1], onehot.shape[1]).to(device)
    opt = torch.optim.Adam(model.parameters(), lr=P.CVAE_LR)
    Xt = torch.tensor(Xstd, dtype=torch.float32, device=device)
    Mt = torch.tensor(mask, dtype=torch.float32, device=device)
    St = torch.tensor(onehot, dtype=torch.float32, device=device)
    N = Xt.shape[0]
    best, best_state, patience, bad = 1e18, None, 60, 0
    rng = np.random.default_rng(P.SEED)
    for ep in range(1, P.CVAE_EPOCHS + 1):
        model.train()
        perm = rng.permutation(N)
        ep_loss = ep_rec = ep_kl = 0.0
        for st in range(0, N, P.CVAE_BATCH):
            bidx = perm[st:st + P.CVAE_BATCH]
            xb, mb, sb = Xt[bidx], Mt[bidx], St[bidx]
            opt.zero_grad()
            xhat, mu, lv = model(xb, sb)
            beta = P.BETA_KL * min(1.0, ep / max(1, P.KL_ANNEAL_EPOCHS))  # KL 退火
            loss, rec, kl = _elbo_loss(xhat, xb, mb, mu, lv, beta)
            loss.backward()
            opt.step()
            ep_loss += loss.item() * len(bidx); ep_rec += rec * len(bidx); ep_kl += kl * len(bidx)
        ep_loss /= N
        if ep <= P.KL_ANNEAL_EPOCHS:
            if ep % 50 == 0 or ep == 1:
                print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS}(退火) loss={ep_loss:.4f} "
                      f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
            continue   # 退火阶段不计入早停
        if ep_loss < best - 1e-4:
            best, best_state, bad = ep_loss, {k: v.detach().clone() for k, v in model.state_dict().items()}, 0
        else:
            bad += 1
        if ep % 50 == 0 or ep == 1:
            print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS} loss={ep_loss:.4f} "
                  f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
        if bad >= patience:
            print(f"[Q3] 早停于 epoch {ep}（best loss={best:.4f}）")
            break
    if best_state is not None:
        model.load_state_dict(best_state)
    model.eval()
    return model

def _transfer(model, style_list, s2i, S, Xstd, Xv, styles, feat_cols, mu_f, sd_f,
              device, lo=None, hi=None):
    """Pils/Lager → Tripel 隐空间平移 + 缺陷投影（式12/13）。"""
    tgt = P.TRANSFER_TARGET
    zt, _ = _style_latent_mean(model, Xstd, styles, tgt, s2i, S, device)
    # 目标风格缺陷典型值 m^t（native 中位）
    tgt_idx = np.where(styles == tgt)[0]
    col_med_all = np.nanmedian(Xv, axis=0)
    defect_pos = {d: feat_cols.index(c) for d, c in P.DEFECT_COL_MAP.items()}
    m_t = {d: float(np.nanmedian(Xv[tgt_idx, pos])) for d, pos in defect_pos.items()}

    records = []
    before = {d: [] for d in defect_pos}
    after = {d: [] for d in defect_pos}
    cap_rec = {d: [] for d in defect_pos}
    raw_after = {d: [] for d in defect_pos}   # 无约束纯平移对照（缺陷投影前的解码值）
    for src in P.TRANSFER_SOURCES:
        if src not in s2i:
            print(f"[Q3] 迁移源 {src} 不存在，跳过")
            continue
        zs, sidx = _style_latent_mean(model, Xstd, styles, src, s2i, S, device)
        delta = zt - zs
        # 逐源样本编码 -> 平移 -> 用目标风格解码
        oh_src = np.zeros((len(sidx), S)); oh_src[:, s2i[src]] = 1
        with torch.no_grad():
            mu_s, _ = model.encode(torch.tensor(Xstd[sidx], dtype=torch.float32, device=device),
                                   torch.tensor(oh_src, dtype=torch.float32, device=device))
            z_moved = mu_s.cpu().numpy() + delta
            oh_t = np.zeros((len(sidx), S)); oh_t[:, s2i[tgt]] = 1
            xhat = model.decode(torch.tensor(z_moved, dtype=torch.float32, device=device),
                                torch.tensor(oh_t, dtype=torch.float32, device=device)).cpu().numpy()
        native = xhat * sd_f + mu_f
        if lo is not None and hi is not None:
            native = _clip_to_observed(native, lo, hi)
        for row, si in enumerate(sidx):
            x_after_vec = native[row].copy()
            for d, pos in defect_pos.items():
                xb = Xv[si, pos]
                if not np.isfinite(xb):
                    xb = float(col_med_all[pos])
                raw_val = float(x_after_vec[pos])           # 无约束纯平移的缺陷取值（对照）
                raw_after[d].append(raw_val)
                # 严格不恶化：迁移后缺陷既不得高于源款原值 xb，也不高于目标典型安全值 m_t，取严
                cap = min(xb, m_t[d])
                if P.USE_ABS_THRESHOLD:
                    pass  # 可换算时此处并入 τ 上界（本题单位不可比，默认关闭）
                # 缺陷列逐样本投影回安全区（式13，np.minimum 下截断）
                xa = float(np.minimum(raw_val, cap))
                x_after_vec[pos] = xa
                before[d].append(float(xb)); after[d].append(xa); cap_rec[d].append(cap)
            records.append({"style": f"{src}->{tgt}", "sample_type": "transfer",
                            "src_beer_row": int(si), "_native": x_after_vec})
        print(f"[Q3] 迁移 {src}->{tgt}: {len(sidx)} 条")
    # 合规率（式13：x_after <= min(xb, m_t)）
    n_tot = n_ok = 0
    n_rise_raw = n_rise_constrained = 0
    per_defect = {}
    for d in defect_pos:
        bf = np.array(before[d]); af = np.array(after[d]); cp = np.array(cap_rec[d])
        raw = np.array(raw_after[d])
        ok = int((af <= cp + 1e-9).sum())
        rise_raw = int((raw > bf + 1e-9).sum())    # 无约束时缺陷升高的样本数
        rise_c = int((af > bf + 1e-9).sum())       # 严格约束后缺陷升高数（应为 0）
        n_tot += len(af); n_ok += ok
        n_rise_raw += rise_raw; n_rise_constrained += rise_c
        per_defect[d] = {"n": len(af), "n_compliant": ok,
                         "before_mean": round(float(bf.mean()), 4),
                         "after_mean": round(float(af.mean()), 4),
                         "raw_after_mean": round(float(raw.mean()), 4),
                         "m_t": round(m_t[d], 4),
                         "delta_mean": round(float((af - bf).mean()), 4),
                         "delta_raw_mean": round(float((raw - bf).mean()), 4),
                         "n_rise_unconstrained": rise_raw,
                         "n_rise_constrained": rise_c}
    rate = n_ok / n_tot if n_tot else 1.0
    info = {"compliance_rate": round(rate, 6), "n_checks": n_tot, "n_compliant": n_ok,
            "per_defect": per_defect, "defect_cols": list(P.DEFECT_COL_MAP.values()),
            "defect_no_chem": P.DEFECT_NO_CHEM, "m_t": {k: round(v, 4) for k, v in m_t.items()},
            "unconstrained_control": {
                "description": "同批迁移仅做隐空间平移、不做缺陷投影（对照），量化约束必要性",
                "n_defect_rise_unconstrained": n_rise_raw, "n_total": n_tot,
                "rise_frac_unconstrained": round(n_rise_raw / n_tot, 4) if n_tot else None,
                "n_defect_rise_constrained": n_rise_constrained,
                "rise_frac_constrained": round(n_rise_constrained / n_tot, 4) if n_tot else None}}
    print(f"[Q3] 缺陷合规率={rate:.4f}（{n_ok}/{n_tot}）；无约束升高 {n_rise_raw}/{n_tot}，"
          f"严格约束后升高 {n_rise_constrained}/{n_tot}")
    return records, info
