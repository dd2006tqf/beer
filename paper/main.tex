\begin{cumcmabstract}
啤酒风味由化合物协同作用与酵母代谢共同塑造，“从化学谱预测感官、再解释并定向设计风味”是啤酒智能化研发的关键难题。本文基于 250 个商用啤酒样本的化学谱与 50 个感官维（含真实缺失与未检出），构建“预测—归因—生成”贯通流水线，三问共享同一化学到感官模型。

\textbf{针对问题一}，本问要求在缺失机制异质的化学谱上对 50 个感官维逐维预测 0--6 等级，难点在未检出与真缺失并存、等级口径特殊。本文采用\textbf{原生缺失感知梯度提升}逐维回归，按训练折内分位映射等级，风格分层 5 折验证且分箱参数全程折内估计，杜绝信息泄漏。求解得平均 QWK \textbf{0.3830}、折外 Spearman 0.4109、$\pm$1 级准确率 57.3\%，\textbf{全面优于}随机森林（0.328）、ElasticNet（0.276）与 KNN 插补（0.3652）三类基线，2000 次配对重采样的 95\% 区间对三类基线均不跨零；split-conformal 预测区间实测覆盖率 \textbf{90.2\%}（目标 90\%）。灵敏度对照显示加入 43 个阈值超限列或模块 PC1 反使 QWK 降至 0.376/0.375，故予舍弃；酒精、苦味等强信号维 QWK 超 0.77，与感官感知规律吻合。

\textbf{针对问题二}，本问要从高维化合物中找出驱动感官维的关键化合物，难点在强共线与单一归因稳定性差。本文剔除 16 个理化参数与 4 个汇总列，仅在 \textbf{211 个单一化合物}上建共表达图（211 节点、564 边、55 社区、模块度 \textbf{0.625}），融合 SHAP、交叉相关与模块代表\textbf{三路证据}选出 Top-3 并去冗余。Top-1 的分层 bootstrap 入选频率均值达 \textbf{0.992}，跨方法 Jaccard \textbf{0.200} 为随机基线 0.0086 的 \textbf{23.3 倍}，稳定性远超单一方法；联合检验进一步揭示 QWK 与 Top-1 稳定性相关仅 $r=0.101$，随可预测性下降而失稳的是第 3 名，避免了“以精度筛化合物”的误判。按 8.xlsx 来源标注逐维判定，一致 6 维、部分一致 17 维，与发酵后风味载体的真实结构吻合。

\textbf{针对问题三}，本问要生成指定风格化学谱且缺陷化合物不得超标，难点在生成谱的\textbf{化学合规性}。本文构建以风格为条件的\textbf{条件变分自编码器}，在隐空间做质心平移实现跨风格迁移，并对缺陷维采用逐样本 min 投影。生成谱与真实谱的 KS 距离 0.351--0.411，风格 Top-3 识别率恒为 \textbf{100\%}（随机 13.6\%），50 维画像 Spearman 0.65--0.92；5 个随机种子下 KS 标准差不超过 0.015，生成过程稳定。Pils/Lager 到 Tripel 迁移后缺陷 \textbf{0/44 次升高}，而纯平移有 32/44 次升高，证明 min 投影是化学合规的关键设计。

全部数字由代码在 SEED=42 下实算产出，三问结论均经交叉验证、配对 bootstrap 与分布距离三重检验，证据链完整、可复现，框架可推广至其他成分谱—感官建模场景。

\section{问题重述}

啤酒风味高度依赖酵母代谢与化合物成分的协同作用，定量刻画“化学成分如何决定感官体验”需要把实验室测得的风味化合物与品评小组的感官强度联系起来，机器学习方法已为此提供了方法论基础\cite{b1,b2,b3}。本文使用一套商用啤酒风味代谢物实测数据集：250 个样本测量了酒精、异 $\alpha$-酸、pH、糖浓度等酿造参数与 200 余种风味化合物丰度（涵盖酒花萜类、酵母酯醇、麦芽与野生菌群及陈化类），并由品评小组给出约 50 个感官维度评分；数据来自真实测量，含噪声、真实缺失值与异常值。围绕化学成分、感官风味与啤酒风格这条链条，本文研究三个递进的问题。

问题一：在化学数据存在真实缺失的条件下，以化合物与理化丰度为自变量，预测香气 Aroma 与风味 Flavour 两套合计约 40 个感官维度的 0-6 分级评分；关键边界是自变量含缺失而不能删除样本。本问为后两问提供化学到感官的基础模型。

问题二：利用化合物相关数据构建共表达图，结合化学特征给出每个感官维度的 Top-3 关键化合物，并按题面两种口径量化稳定性——bootstrap 重采样入选频率与跨方法 Top-3 集合的 Jaccard 系数，辅以化学合理性论证。本问依赖问题一的模型做可解释归因，其关键化合物清单又为问题三提供先验。

问题三：以风格标签 \texttt{tasting\_\allowbreak{}category\_\allowbreak{}fine} 为条件学习风格条件生成模型，对给定风格（如 Tripel、Kriek、Lambic）生成合理化合物谱并给出感官画像；同时把 Pils/Lager 的化合物谱迁移为 Tripel 风格，并保持 DMS、Diacetyl、4VG、trans-2-nonenal、Stale hops 等缺陷化合物不恶化。该问反向利用问题一的画像与问题二的关键化合物，是三问的综合应用。

三个问题沿数据预处理、化学到感官的判别式预测、可解释归因、风格到化学的条件生成与迁移逐级推进，构成一条从理解到生成的完整流水线，其整体求解思路与依赖关系概括如下。

\section{问题分析}

\subsection{问题一的分析}

问题一本质是带缺失数据的多输出有序预测任务，难点有三。其一，化学特征 231 列高维且含真实缺失（63 个样本、合计 73 个缺失值集中在少数几列），删样本会损失四分之一数据并引入选择偏差，必须在缺失条件下建模。其二，感官标签是中心化连续值而非 0-6 整数，需建立连续值到 7 级刻度的单调映射。其三，约 40 个感官维度相关性强，宜共享化学特征表示。据此本文选择原生支持缺失的梯度提升树\cite{b5,b6,b7}逐维回归再分箱映射，并用分层交叉验证逐维评估二次加权 Kappa、MAE 与 $R^2$；原生缺失处理避免插补偏差，其特征重要性直接服务于问题二归因。

\subsection{问题二的分析}

问题二是共线性干扰下既准、又稳、还有化学道理的可解释归因任务。高度相关的化合物成簇出现，单一重要性指标易把同一模块内可互相替代的化合物反复选入，造成 Top-3 虚假冗余。因此本文先建共表达图揭示模块结构，再融合三类证据归因：问题一的 SHAP 预测贡献、化学-感官交叉相关、共表达模块去冗余加权。稳定性按题面两法量化，化学合理性逐条对照酿造机理。需要强调，强信号维 Top-3 应当稳定、弱信号维不稳定是数据本身的真实现象，本文如实报告而不强行制造稳定。

\subsection{问题三的分析}

问题三是条件生成加可控迁移任务，难点在于部分风格仅 3 至 11 个样本，既要保证生成谱的化学合理性与风格可区分性，又要在迁移时守住缺陷不恶化的硬约束。本文用条件变分自编码器以风格标签为条件编码解码，兼顾多样性与可控性，极小样本风格辅以分布采样兜底；生成谱的感官画像复用问题一模型，形成生成再预测的闭环。迁移经隐空间方向平移实现，并对缺陷化合物施加阈值与源值双重投影，确保迁移后不劣化。生成质量用分布距离与降维重叠度评估。

\section{模型假设}

为聚焦核心建模，本文做出以下假设。

（1）以标准化连续感官值为问题一的训练目标，再按训练折内分位点单调映射回 0-6 等级。原始品评卡汇总表为全 0 模板、不可用，标准化连续值是唯一完整可用的全样本标签。

（2）题面的"约 40 个感官维度"对应 Aroma 与 Flavour 两套共 30 维，本文另输出口感、缺陷与总体评价共 20 维，合计 50 维以覆盖任一解读。

（3）化学特征的数值尺度经 8.xlsx 校准浓度逐列核实为混合尺度：70 个可校准列中 37 列为常用对数、33 列为原值，无自然对数列；其余 161 列按列分布归类。建模在原生数值空间内进行而不做反变换，树模型对单调变换不敏感，该选择不影响分裂结果。

（4）缺陷不恶化取严口径：迁移后缺陷须同时不高于源款原值 $x^{def}_{k,before}$ 与目标风格典型值 $m^t_k$，即上界为 $\min\!\big(x^{def}_{k,before},m^t_k\big)$。该口径保证相对不升高；绝对达标情况另按 8.xlsx 真实阈值审计（见 8.3 节）。

（5）各样本近似独立同分布，风格标签为问题三唯一的条件变量。附件为截面数据、无时间序列结构，故交叉验证采用按风格分层的随机折。

本文主分析\textbf{只使用主办方提供的 8 个附件}，另以 Kaggle 公开啤酒集作\textbf{外部旁证}（5.5 节），不与本数据合并、不进入任何模型。建模核心是四块数据：化合物与理化丰度矩阵 $250\times231$、化合物相关矩阵 $231\times231$、感官标签矩阵 $250\times50$、化学-感官交叉相关 $44\times50$。附件实测规模与题面表述的出入见附录 A（表 A.1、A.2），一律以实测为准。

附件对齐有一处容易被静默忽略的陷阱：1.csv 与 4.csv 的 \texttt{beer\_id} 在后者已丢精度（如 \texttt{5410230000000.0}），按它取交集只剩 \textbf{37/250} 行，inner join 会无声丢掉四分之三样本；改用 \texttt{beer} 名称关联可恢复 250 行，且两表该列逐行相同。本文因此按行序对齐并显式断言（\texttt{code/data\_check.py}），2.csv 按位置与 231 列对应、6.csv 按名称映射回 231 列，任何不符即中断。

231 个化学特征按含义分三类：\textbf{理化/过程参数} 16 列、\textbf{多化合物汇总} 4 列（总酯、酒花香气总量、总酸、含硫总量）、\textbf{单一化合物集 $C$} 211 列。问题一用全部 231 列，问题二只在 $C$ 内建图归因，以免把酒精度、苦度或加总列误当化合物。

感官标签是\textbf{已中心化但未归一化}的连续值（列均值绝对值 $\le0.063$、标准差 0.37--0.86），并非原始 0-6 整数；化学特征为对数/原值混合尺度（5.3 节）。树模型对单调变换不敏感，故建模统一在原生数值空间，既免去尺度换算风险，又让问题三生成与缺陷判定同空间可比。

\subsection{风格分布与化学可分性}

数据集涵盖 22 个精细风格类别，样本量分布高度不均：Blond 有 31 个、Tripel 有 28 个样本，而 Faro 仅 3 个、Brut 仅 4 个。这一长尾结构直接决定了问题三对极小样本风格必须设置分布采样兜底。在进入建模前，本文先用主成分分析观察化学谱是否天然按风格分离，以判断化学成分能否区分风格这一前提是否成立。


按风格对化学谱前两个主成分做散点检查：Lambic、Kriek 等酸味野发酵风格与 Tripel、Blond 等常规发酵风格形成可辨识的区域偏移，说明化学成分确实携带了区分风格的信息，为问题三以风格为条件生成化学谱提供了数据层面的可行性依据；同时各风格簇之间存在重叠，也预示生成与迁移任务并非平凡，需要隐空间模型而非简单的类别均值替代。

\subsection{对数底核实与尺度统一}

化合物丰度取对数还是原值，直接影响浓度叙述。8.xlsx 的 Calibrated chemical dataset 给出 70 个化合物的校准绝对浓度 $c_{ik}$，本文据此对每列计算 $x_{ik}$ 与 $\log_{10}c_{ik}$、$c_{ik}$、$\ln c_{ik}$ 三者的中位绝对残差，残差低于 $10^{-6}$ 者即判定其尺度。结果为 \textbf{37 列严格为常用对数、33 列严格为原值}，两类残差均为 0、与对应尺度相关系数为 1.0，无自然对数；连 pH 也取常用对数（$0.625=\log_{10}4.21$）。常用对数列含全部 16 个理化指标与 21 个酵母酯、醇、硫化合物，原值列以酒花萜烯、醛、酚类为主。其余 161 列无校准浓度，按列分布归类并标注未经校准。

需要特别说明化学谱中的负值。231 个特征中有 \textbf{175 列出现负数，合计 10797 个负值单元格}，它们不是异常值或测量错误，而是浓度小于 1 的化合物取常用对数后的正常结果，例如 $\log_{10}0.1=-1$。按列核查，负值全部出现在已判定为常用对数的列上，原值列不含负值。因此本文不做任何剔除、截断或取绝对值，保留其原始对数取值；剔除这些行等于删掉近半数观测信息，还会使分布严重右偏。

\subsection{未检出、真实缺失与异常值}

化学谱中的大量低值是\textbf{未检出}（低于仪器检出限，取本列下限 $\ell_k=\min_i x_{ik}$），与真正的缺失必须分开。真正的缺失共 \textbf{73 个 NA、9 列、63 个样本}，集中在乙酸戊酯（27 个，10.8\%）、酒花香气合计（13 个）、甲基吡嗪（12 个）、双乙酰（9 个）与 3-甲基丁醛（7 个），其余 4 列各 1--2 个。

未检出的分布同样高度不均：211 个单一化合物的检出率仅 85.5\%（未检出 14.4\%），而 16 个理化列与 4 个汇总列分别为 98.0\% 与 98.3\%，可见丰度稀疏是化合物的常态。逐列看，\textbf{40 列有 30\% 以上的样本卡在同一最小值}、12 列超过 60\%（limonene 与 6-methyl-5-hepten-2-one 达 84.8\%、CS2 为 83.6\%、4VG 为 67.2\%），这是检出限造成的\textbf{左删失}，而非自然测量得到的连续值。

本文因此不把下限值当作普通观测：主模型保留 231 列原生数值（含 NaN），未检出以下限档位进入分裂，另定义指示 $\delta_{ik}=\mathbb{1}[x_{ik}\le\ell_k]$（共 102 列适用）用于值域截断与核对，但不展开成额外特征（树模型能直接利用该档位）。仅 73 个真实 NA 需要插补，本文用 $K=5$ 近邻插补，距离在标准化特征上计算，且只在训练折内拟合；KNN 插补仅用于基线对照，主模型不插补。

对异常值本文不删样本：树模型按秩分裂、二次加权 Kappa 只看等级次序，对极值与单调变换天然稳健；问题三的生成谱则在各列观测区间 $[\ell_k,u_k]$ 内截断，从源头杜绝越界。

\subsection{外部数据旁证：Kaggle 公开啤酒集}

为校验本文风格规格是否符合行业常识，引入 Kaggle 公开数据集 *Top Beer Information*\cite{b4}，由 Stephen Polozoff 整理，含 5558 款、112 个风格与 ABV、IBU 区间及网友平均评分作为外部旁证。它与本数据是互补而非替代关系：Kaggle 是大众风格的网友评分与规格大样本库，本文是 22 个比利时/欧洲小众风格的实验室化学谱与单一小组标准化分精标小样本。两者没有共同主键，因此不逐行合并、不进入任何模型，仅作宏观对照。


两库整体酒精度分布区间一致，都集中在 0–12\% vol；本文样本偏比利时修道院风格，整体偏强，峰值落在 6.5\%–8\%。在 16 个能明确对应的风格上，把本文实测酒精度按 $10^{x}$ 从 $\log_{10}$ 列还原后与 Kaggle 同风格区间对照：\textbf{14/16 落在 Kaggle 的 P5–P95 区间内，跨风格的酒精度排序 Spearman 相关达 0.84}。苦度排序相关也达 0.86，由于 Kaggle 的 Min/Max IBU 是风格指南标称区间，每风格退化为单一值、并非逐款实测，而本文是仪器实测苦度，口径不同，故苦度只比较排序、不报告命中率。低强度低苦风格与 Tripel 等高强度风格的相对格局完全一致。Kaggle 评分由大量评论聚合、比本文每款数人的小组打分更平滑，这也部分解释了问题一弱信号维的可预测性偏低。需要强调，\textbf{主分析仅使用给定的 8 个附件，Kaggle 数据仅作外部旁证、不进入建模}。

\section{问题一：含缺失的多输出有序感官分级预测}

\subsection{缺失结构与建模策略选择}

问题一的第一道关卡是缺失数据。如 5.4 节所述，73 个真实缺失集中在 9 列、涉及 63 个样本；化合物集另有平均 14.4\% 的未检出值，信息极少但不是缺失。删除这 63 行将损失四分之一样本并引入选择偏差，故本文不删行：真正缺失交给原生支持缺失的梯度提升树，未检出保留下限档位\cite{b5,b6,b7}。其中分箱映射与评估口径是保证交付整数且不泄漏的两个要害，下面分别展开。

\subsection{标签构建与 0-6 分箱映射}

品评小组提供的标准化连续值无法直接作为 0-6 分级交付，需要一个单调映射把连续强度离散为 7 个等级。本文在训练折内对维度 $j$ 估计 6 个分位点 $\{q^{(j)}_1,\dots,q^{(j)}_6\}$，定义累计计数式的单调映射：

\begin{equation}
g_j(y)=\sum_{\ell=1}^{6}\mathbb{1}\!\left[y> q^{(j)}_\ell\right],\qquad \tilde y_{ij}=g_j(Y_{ij})\in\{0,\dots,6\}.
\end{equation}

预测阶段对回归输出 $r_{ij}$ 施加同一映射，并截断取整以严格落在 0-6 整数区间：

\begin{equation}
\hat y_{ij}=\min\!\Big(6,\ \max\!\big(0,\ \mathrm{round}(g_j(r_{ij}))\big)\Big).
\end{equation}

式 (1) 的分位点与标准化参数只由训练折估计、再套用到验证折，这是本题最易被忽视的泄漏点：若在全量数据上估计分箱阈值，等于让模型偷看了验证样本的标签分布。

50 个感官目标并非彼此独立。\texttt{5.csv} 的 50$\times$50 相关矩阵（对角为 1，范围 $-0.502$ 至 $0.966$，中位 $|r|=0.127$）显示：直觉预期“组内紧密、组间松散”，实测相反，香气组内中位 0.124、风味组内 0.152，组间 0.151；真正强的是\textbf{同名维的跨通道配对}（香气·酯与风味·酯 0.836、酒花—酒花 0.828、麦芽—麦芽 0.825），15 对同名维中位 \textbf{0.692}、12 对超 0.6，而全体非对角中位仅 0.127。即“闻到的酯香”与“尝到的酯味”几乎是同一变量，共享同一化学来源。

这有三点直接含义：50 维不是 50 个独立任务，共享信息沿“同名维”这条轴而非香气/风味分组边界（第 9 章的分组对照验证了分组共享无增益）；全局最强的一对是陈酒花与畜栅味（0.966），二者几乎等价，预示弱信号维的归因会互相混淆；36 对 $|r|\ge 0.6$ 若逐维独立建模等于重复学习同一信号——这是本文仍逐维建模的代价，换来每维可独立诊断与解释。


分位分箱并非唯一选择。灵敏度对照：等距分箱（按极差 7 等分）在偏态连续值上产生 8 个空等级、最小等级平均仅占 0.9\%、等级频次变异系数高达 1.155；分位分箱无空等级、每等级平均 13.8\%、变异系数仅 0.022。等距分箱的平均 QWK 反而略高（0.4013 对 0.3830），但以空等级与严重失衡的等级频次为代价，对偏态分布不稳健；分位分箱的等级频次跨维可比、只依赖秩、对单调变换稳健，故采用后者。两口径对 QWK 绝对量级的影响在 9.4 节另作说明。

分位分箱有一个前提：连续标签必须足够分散，否则 6 个分位点会挤在极窄区间，切出的等级在原始尺度上无法区分。以“前 5 个切点跨度占该维极差的比例”度量退化程度，50 维中有 5 维显著退化：acetic 为 0.006、coriander 与 clove 为 0.008、lactic 为 0.011、orange 为 0.033——其等级虽各占约 14\% 样本，但对应的原始强度几乎重叠，等级边界不具备实际含义。

应对有两种：保留分位分箱，承认这些维只是“相对排序”；或改用\textbf{有序回归}，直接学习“是否越过某一等级阈值”、不依赖分位点。为判断优劣，本文在同一批样本、同一 5 折划分、同一 LightGBM 家族下对照：有序分支对每个内部阈值训练一个“标签高/低于该阈值”的二分类器，预测概率累加取整得到等级。

据此把判据接入主流水线：退化维改用\textbf{类加权有序回归}（6 个阈值各训一个二分类器、按两侧频率反比加权），其余维保持不变。自动识别的退化维为 orange、coriander、clove、lactic、acetic 共 5 个，折外 QWK 由 0.3663 升至 \textbf{0.3830}（+4.6\%），5 维全部改善。需如实说明：若铺到全部 50 维，QWK 0.4089、Spearman 0.4509、$\pm$1 58.7\% 三项更高；但该分支输出等级期望值而非连续强度，而问题二、三都依赖连续底座，故以 0.026 的 QWK 换取三问共用。

判据只依赖标签分布形态、在建模前即可确定，不接触验证信息；切换也是单侧的，只有退化维改用有序回归。作为对照，嵌套交叉验证下的逐维自适应选型无偏估计为 0.3856，但内层样本仅约 133 条、受抽样噪声驱动，反使 17 个原本良好的维度退化，未予采用。

\subsection{预测模型与求解过程}

对每个感官维度 $j$，本文训练一个独立的梯度提升回归器 $h_j$，以平方损失加正则求参：

\begin{equation}
\Theta_j=\arg\min_{\Theta}\ \sum_{i\in\mathcal{D}_{tr}}\big(Y_{ij}-h_j(x_i;\Theta)\big)^2+\Omega(\Theta),
\end{equation}

其中 $h_j$ 为梯度提升树集成，$x_i$ 的缺失分量由树的默认分裂方向处理，训练集 $\mathcal{D}_{tr}$ 包含全部含缺失样本，不删行；$\Omega$ 为叶子数、学习率与 L2 正则项。50 个维度共享同一化学特征矩阵 $X$。

整个求解按固定随机种子 42 执行：按风格分层切 5 折，折内估计分箱映射 $g_j$、拟合回归器 $h_j$，折外累计二次加权 Kappa、平均绝对误差与决定系数，最后在全部 250 样本上重训一次产生提交分级。该流程可写成如下的闭式递推。记第 $k$ 折的训练集与验证集为 $\mathcal{D}^{(k)}_{tr}$、$\mathcal{D}^{(k)}_{va}$，样本 $i$ 的风格为 $s_i$，分层折指派取同风格样本的循环编号
\begin{equation}
\kappa(i)=\big(\#\{i':\ s_{i'}=s_i,\ i'\le i\}-1\big)\bmod K,
\end{equation}
其中 $\kappa(i)=k$ 即 $i\in\mathcal{D}^{(k)}_{va}$，同风格样本因此近似均分到各折。分位点与退化判据只在训练折内估计：
\begin{equation}
q^{(j,k)}_\ell=\mathrm{Quantile}_{\ell/7}\big(\{Y_{ij}:i\in\mathcal{D}^{(k)}_{tr}\}\big),\qquad
\delta_j=\mathbb{1}\!\left[\frac{q^{(j,k)}_5-q^{(j,k)}_1}{\max_i Y_{ij}-\min_i Y_{ij}}<0.05\right].
\end{equation}
折外等级由回归分支与有序分支按 $\delta_j$ 逐维硬选择：
\begin{equation}
\hat y_{ij}=(1-\delta_j)\,\mathrm{clip}_{[0,6]}\!\Big(\mathrm{round}\big(g_j(h_j(x_i))\big)\Big)+\delta_j\,\mathrm{round}\!\Big(\sum_{\ell=1}^{6}\hat p^{(j)}_{i\ell}\Big),
\end{equation}
其中 $\hat p^{(j)}_{i\ell}$ 为第 $\ell$ 个内部阈值二分类器给出的“高于该阈值”概率，$\delta_j=1$ 时累加概率即等级期望值。50 维指标再对折外样本宏平均，二次加权 Kappa 取
\begin{equation}
\mathrm{QWK}=\frac{1}{50}\sum_{j=1}^{50}\frac{\sum_{a,b=0}^{6}w_{ab}O^{(j)}_{ab}}{\sum_{a,b=0}^{6}w_{ab}E^{(j)}_{ab}},\qquad w_{ab}=\frac{(a-b)^2}{36},
\end{equation}
$O^{(j)}_{ab}$、$E^{(j)}_{ab}$ 为第 $j$ 维混淆矩阵的观测与期望计数。

\subsection{预测区间与不确定性}

点预测无法告诉使用者“这个 4 级有多可信”。本节为每个感官维给出 90\% 预测区间，比较两种口径：\textbf{直接分位数回归}（把 LightGBM 的目标函数换成 $\alpha=0.05$ 与 $\alpha=0.95$ 的分位数损失，分别给出下上界）；\textbf{split-conformal}（每个训练折内再切 30\% 作校准集，用点模型绝对残差取 $\lceil (n+1)(1-\alpha)\rceil$ 分位作半宽，对验证折输出对称区间）。

直接分位数回归的平均覆盖率为 \textbf{75.3\%}，显著低于名义的 90\%，平均宽度仅 1.025 个标准化单位——典型的\textbf{欠覆盖}，与 250 样本、50 维逐维拟合的设定相符：分位数损失在小样本上对尾部估计不稳。split-conformal 把覆盖率拉回 \textbf{90.2\%}、达到 90\% 目标，代价是平均宽度增至 \textbf{1.555}。分组看香气 0.902、风味 0.899、口感 0.904，三组基本一致，校准未在某组系统性失效。

这一对照说明选择 conformal 的理由：它不依赖分布假设，只要求校准集与验证集可交换，在小样本逐维多输出场景下更可靠。区间宽度约 1.55 个标准化单位，也从侧面量化了问题一的固有难度，与 MAE 1.50 级相互印证。

总体覆盖率达标不等于每一维都达标。\textbf{图 5} 把 50 个维度逐一铺开：共形口径下的覆盖率落在 0.836--0.936 之间，其中 5 维低于 0.88——香气·木质（0.836）、香气·焦糖（0.868）、味·异丁酸乙酯（0.872）、味·酯（0.876）与味·果香酯（0.876）；最高的几维是香气·乙酸乙酯（0.936）、味·热带果（0.932）与畜栅味（0.928）。两口径的逐维中位数分别落在 0.752 与 0.904，几乎每一维都随共形校准上移（50/50 维改善），只是幅度在弱信号维上略小。偏差的方向与信号强度一致：覆盖率偏低的都是弱信号维，其标签分布集中、残差尾部难以由 30\% 的校准集稳定刻画。而分位数回归在全部 50 维上都落在 0.704--0.836，从无一维达到名义水平，这也解释了为什么它的总体覆盖率只有 75.3\%。

\section{问题二：化合物共表达图与关键化合物归因}

\subsection{共表达图构建与模块结构}

问题二要为每个感官维度找出 Top-3 关键\textbf{化合物}，而化合物高度相关会干扰归因。本文先把 231 个化学特征中的 16 个理化/过程参数（酒精度、色度、pH、苦度、二氧化碳压力、蛋白、甘油、未发酵糖等）与 4 个汇总列（总酯、酒花香气总量、总酸、含硫总量）排除，仅在 \textbf{211 个单一化合物候选集 $C$（$|C|=231-16-4=211$）} 内建图与归因；问题一的特征矩阵仍保留全部 231 列，因理化指标对预测同样有用。借鉴基因共表达网络思想\cite{b13,b14}，以 $C$ 中化合物为节点、相关系数为边权构建无向图，并按阈值去除弱边：

\begin{equation}
E=\big\{(p,q):\ p,q\in C,\ |R_{pq}|\ge \rho\big\},\qquad w_{pq}=R_{pq},\quad \rho=0.5,\ |C|=211.
\end{equation}

关于相关系数口径：题面称附件 2 为 Pearson，但本文从 1.csv 逐对重算后发现它实际是 \textbf{Spearman}——重算的 Spearman 与附件 2 逐元素一致（最大差 $7.8\times10^{-16}$），而同口径 Pearson 的最大差达 1.12、平均绝对差 0.088。故边权即附件 2 的秩相关值，无需换算；7.3 节的建图阈值灵敏度还说明结论对阈值选择不敏感。在所得图上做 Louvain 贪心模块度社区检测\cite{b15}以识别化合物模块，模块度定义为

\begin{equation}
Q_{mod}=\frac{1}{2m}\sum_{p,q}\Big(w_{pq}-\frac{k_p k_q}{2m}\Big)\,\delta(c_p,c_q),\qquad k_p=\sum_q w_{pq}.
\end{equation}

在阈值 $\rho=0.5$ 下，共表达图含 \textbf{211 个节点、564 条边}，社区检测得到 \textbf{55 个社区}，模块度 $Q_{mod}=0.625$，远高于随机网络的水平，表明化合物确实存在明显的模块化组织结构。

模块归属若只是算法产物，就不该与感官有系统关联。图 7 对 5 个 Louvain 大模块与三组感官分别做 Mantel 检验（各 999 次置换）：相关系数 0.014–0.262，全部 $p<0.05$。最强的是 M5（酒花萜烯）与口感缺陷组（$r=0.262$）；M2（萜烯醇/酯）对三组较均衡（0.175–0.206），承载整体风味强度；M4（双乙酰/醛）与香气组仅 0.048，与该模块检出稀疏一致。这一层补上了“整谱可分”与“单化合物相关”之间的空白。

两类混杂需要分别剥离。第一类是\textbf{风格间差异}：每个风格先减去风格内均值，再对 44 化合物 $\times$ 50 感官的 2200 个配对重算 Spearman——全样本相关中位绝对值 0.113，去风格均值后降至 0.065，两者相关 0.649、符号一致率 70.8\%，$|r|\ge 0.3$ 的配对由 251 个减到 36 个。第二类是\textbf{酒精度这一全局混杂}：乙醇与麦芽汁浓度、酯醇生成共同变化，会把无关的化学-感官关联一同抬高。以乙醇为控制变量对同一 2200 个配对计算偏 Spearman：中位 $|r|$ 由 0.113 降至 \textbf{0.084}，$|r|\ge 0.3$ 的配对占比由 11.4\% 降至 \textbf{4.3\%}，符号一致率 83.7\%。分化合物看，收缩程度恰好刻画“是否被酒精度带出来”：乙醇自身与酒精、酒体的相关（0.817、0.719）控制后几乎归零（$-0.026$、$-0.013$），甘油—酒精由 0.625 降至 0.066、己酸乙酯—酒精由 0.619 降至 0.036，属酒精度驱动的表面关联。而\textbf{异 $\alpha$-酸—苦味仅从 0.682 降到 0.646}、辛酸乙酯—苦味从 0.593 降到 0.401，是独立于酒精度的真实化学信号。这直接支撑 7.5 节的来源判定：麦芽维 Top-3 落在酵母酯醇上并非独立关联，而是都随发酵强度同向变化——剔除酒精度后大幅收缩，正说明它们只是统计代理。

把相关矩阵按 Louvain 模块重排后，五个模块在对角线上形成成片的高相关方块：块内 $|r|$ 中位 0.353，块间仅 0.143，相差 2.47 倍。这直接解释了 Top-3 为何必须做模块去冗余。


线性层面，14 个代表性化合物与 50 个感官维的逐对相关呈清晰的条带结构：酯类化合物与果香、酒花类维度呈较强正相关，硫化物与蔬菜硫味维度相关显著，这些强相关区域与酿造机理高度吻合，构成归因的线性证据一路。但线性相关无法捕捉非线性贡献，也无法识别共线性冗余，故需与模型的非线性归因联合使用。

\subsection{多证据融合 Top-3 归因}

对每个感官维度 $j$，本文融合三类证据给化合物 $p$ 打关键度分：

\begin{equation}
\phi_{jp}=\alpha\,\widetilde{\mathrm{SHAP}}_{jp}+\beta\,\big|\tilde C_{pj}\big|+\gamma\,\mathrm{rep}_{jp},\qquad \alpha+\beta+\gamma=1.
\end{equation}

其中 $\widetilde{\mathrm{SHAP}}_{jp}$ 是问题一模型对维度 $j$ 的归一化 SHAP 值，刻画非线性预测贡献；$\tilde C_{pj}$ 是化学与感官交叉相关的归一化绝对值，刻画线性关联；$\mathrm{rep}_{jp}$ 是模块代表加权，使同模块内多个可互替化合物只保留关键度最高者进入候选，避免 Top-3 被单一模块占满，这一簇代表的思路与稳健特征选择中的聚类代表方法一致\cite{b16}。按权重 $\alpha=0.5,\beta=0.3,\gamma=0.2$ 取每维得分前三者：

\begin{equation}
\mathrm{Top3}(j)=\operatorname*{arg\,top3}_{p}\ \phi_{jp}.
\end{equation}

SHAP 值通过对问题一全量梯度提升模型使用树解释器逐样本计算得到，权重 $\alpha$ 最大体现了以预测贡献为主、相关与去冗余为辅的归因哲学。去冗余规则可写成筛选算子：设已入选集合为 $\mathcal{S}_j$，候选 $p$ 同社区内已有强相关成员时被剔除，
\begin{equation}
\mathcal{A}_j=\Big\{p\in C:\ \nexists\,q\in\mathcal{S}_j\ \text{s.t.}\ c_p=c_q\neq-1,\ \lvert R_{pq}\rvert\ge 0.7\Big\},
\end{equation}
于是贪心选取等价于在剩余候选上反复取最大，直至满 3 席：
\begin{equation}
\begin{aligned}
p^\star_{j1}&=\arg\max_{p\in\mathcal{A}_j}\phi_{jp},\\
p^\star_{j,m+1}&=\arg\max_{p\in\mathcal{A}_j\setminus\{p^\star_{j1},\dots,p^\star_{jm}\}}\phi_{jp},\quad m=1,2,
\end{aligned}
\end{equation}
强制 Top-3 来自相互独立的化学证据，而非三个彼此近似的共表达冗余物，每个维度恰好交付 3 个化合物。证据分级再把每个候选 $p$ 映射到 A/B/C 三档：
\begin{equation}
\mathrm{grade}_{jp}=\begin{cases}
\mathrm{A}, & \sum_{m=1}^{4}\mathbb{1}\big[\text{条件 } m \text{ 满足}\big]=4,\\
\mathrm{B}, & \sum_{m=1}^{4}\mathbb{1}\big[\text{条件 } m \text{ 满足}\big]=3,\\
\mathrm{C}, & \text{否则},
\end{cases}
\end{equation}
四个条件依次为 $f_{jp}\ge0.8$、该维折外 $R^2>0$、条件增量在 5 折中至少 3 折为正、条件增量超过同维随机列置换的 95\% 分位。

\subsection{稳定性量化}


阈值 ρ 不是随手取定的常数。边数随 ρ 单调塌缩：0.40 时 1500 条边、最大分量 200 节点，0.60 时只剩 234 条边、86 节点；孤立节点从 11 升到 95，而模块度在 0.55–0.60 才见顶（0.684、0.704）后回落。ρ=0.5 是折中点：保留 159 节点的连通骨架、模块度 0.625。本文据此固定 ρ=0.5。

稳定性严格按题面指定的两种口径量化。第一种是 bootstrap 入选频率\cite{b19}：对样本做 $B=500$ 次\textbf{按风格分层}的有放回重采样（样本量少于 5 折的风格合并为 \texttt{\_rare} 一层，避免小风格被抽空），每次重算 Top-3，统计化合物 $p$ 进入维度 $j$ 的 Top-3 的频率

\begin{equation}
f_{jp}=\frac{1}{B}\sum_{b=1}^{B}\mathbb{1}\!\left[p\in\mathrm{Top3}^{(b)}(j)\right]\in[0,1].
\end{equation}

为确认 $B=500$ 已收敛，本文另在 200 次与 300 次处设检查点：三个规模下 Top-1 频率均值为 0.9996/0.9997/0.9997，相对最终结果的 Top-1 选择\textbf{改变 0 维}，说明 500 次已充分稳定。

第二种是跨方法 Jaccard：对 SHAP 法交叉相关法随机森林重要性法三类方法两两比较其 Top-3 集合，

\begin{equation}
\mathrm{Jac}(A,B)=\frac{|A\cap B|}{|A\cup B|}\in[0,1].
\end{equation}

入选频率高说明单一方法内部稳健，Jaccard 高说明不同证据之间一致。为回答这样的稳定性是否显著优于随机，本文还构造了随机基线：在 211 个化合物集 $C$ 上随机抽取 3 个作为 Top-3，重复 100000 次，计算随机 Top-3 与固定参照的 Jaccard 期望。两指标的全维分布如下图。


单方法稳定性极高：Top-1 入选频率 47/50 维恰为 1.000、三组中位数均为 1.000，单方法内部的关键化合物判定极其稳健。跨方法一致性中等：三对方法的逐维 Jaccard 中位数都是 0.200，均值 0.128、0.274、0.156，整体均值 \textbf{0.200}，即三类证据的 Top-3 平均约两成重叠。作为参照，10 万次随机抽取的 Jaccard 期望仅 \textbf{0.0086}，本文 0.200 是随机基线的 \textbf{23.3 倍}，三类证据侧重不同、绝对 Jaccard 不高，但相对随机已高度显著，归因绝非偶然而非虚高的一致。

全部 150 个上榜配对的入选频率中位数为 \textbf{1.000}、均值 0.960，其中 138 个（92.0\%）不低于 0.8，106 个（70.7\%）在 500 次重采样中每次都入选。抽样设计与候选集规模与同类研究不同，此处只作量级参照。

Jaccard 均值掩盖了"不一致"的形态。把三法 Top-3 集合逐维拆开比对后：三法有共同候选 21 维、两对各自重合 6 维、仅一对重合 16 维、完全互斥 7 维。可见一致性偏低主要来自第三种视角带进新候选，而非三法彼此无关，这正符合三路融合的设计意图。

\subsection{融合增益消融与归因集中度}

7.2 节的三路融合建立在两个未经检验的假设上：共表达模块代表的引入能让 Top-3 覆盖更多化学模块，以及三类证据的结合优于任一单方法。本节对这两个假设做消融，并进一步考察 Top-3 结果在维度间的集中程度。

消融实验保持去冗余规则、候选集 $C$ 与 Top-3 基数完全不变，只替换证据来源，构造四个变体：仅 SHAP、仅交叉相关、SHAP 与相关两路融合，以及本文采用的三路融合。评价指标取“模块覆盖数”，即某一变体的 Top-3 落在多少个互不相同的 Louvain 社区内；覆盖数越高，说明选出的三个化合物越来自不同的化学模块，去冗余的意图越得到落实。


把 150 个 Top-3 席位按化合物归并：仅 4 个化合物（acetaldehyde、MeSH、ethyl octanoate、DMS）占 32\% 的席位，其余 26 个化合物各只出现一次。按来源拆开并与期望来源对比：酵母代谢产物占约 60\% 的席位，而期望来源中酵母仅占 24\%；麦芽来源席位仅占 9\%，而期望来源为麦芽的维度占 20\%。这一偏离与来源一致性检验相互印证：模型倾向选出丰度高、检出稳定的酵母酯醇，麦芽焙烤类化合物在成品中检出稀疏，难以进入前三。

三路融合的模块覆盖数为 2.92，接近满分 3，比仅用相关高出 27.0\%、比仅用 SHAP 高出 12.3\%，模块代表项确实在做它该做的事。若只依赖 SHAP，同一模块里可互相替代的化合物会把 Top-3 名额占满。引入模块代表与同社区去冗余后，三个席位更可能分属不同化学证据。仅 SHAP 的 Top-1 覆盖 34 个不同化合物、看似更“分散”，但其模块覆盖仅 2.60，说明这种分散来自同一模块内不同成员的反复选择。仅用交叉相关的覆盖最低（2.30），反映线性相关易被整体丰度共变主导。

接着考察归因结果在维度之间的集中程度。50 个维度共使用了 50 个不同的 Top-1 化合物，但分布极不均衡：acetaldehyde 出现在 16 个维度的 Top-3 中，MeSH 12 次、ethyl\_octanoate 10 次、DMS 10 次；另一方面，26 个化合物只进入过 1 个维度。前四个化合物合计占据了 150 个 Top-3 席位中的 48 个。

这种集中有两种解释：多维度共享的真实驱动，或整体风味强度的统计代理。为区分，本文计算每个维度 Top-1 化合物与 overall 维的相关：中位 $|r|$ 为 0.228、中等偏弱——若集中完全由整体强度造成，Top-1 应普遍与 overall 高度相关；实测说明整体强度只能解释一部分，剩余归因于化合物与特定维度的实质关联。这与 7.3 节相互印证：Top-1 的 bootstrap 频率在 47/50 维上恰为 1.000，并非偶然的共变假象。

为系统检验而非只举成功个例，本文借助 8.xlsx 的 Sensory thresholds 表对每个化合物标注来源，分为酵母、酒花、麦芽、香料、野生菌群、其他，按感官类别推断每个感官维的期望来源，逐维判定 Top-3 属于一致、部分一致还是不一致：三者全部来自期望来源为一致，至少一个来自期望来源为部分一致，无一个来自期望来源为不一致。


表 6 的来源判定以不一致为主，完全一致的集中在酯香、酒精等酵母主导维度。最显眼的错位是麦芽感官：香/味麦芽的 Top-3 几乎全是乙醛、DMS、癸酸乙酯等酵母产物。原因有二：吡嗪、糠醛等麦芽焙烤香气物在成品酒中检出稀疏（阈值表标注麦芽来源仅 24 个），候选集内缺稳定可选分子。而酵母酯醇丰度最高、最稳定，成为与麦芽甜香共变最强的可测载体——是统计代理而非直接分子。这类不一致是发酵后风味载体的真实反映，分离因果仍需受控实验（见 10.2 节）。弱信号维来源更分散、可预测性接近噪声，两问结论互相印证。

\section{问题三：风格条件生成与跨风格迁移}

\subsection{条件变分自编码器}

问题三要学习一个以风格为条件的化学谱生成模型，并在小样本下保持风格可区分。本文采用条件变分自编码器\cite{b17}：编码器 $q_\phi(z\mid x,s)$ 把 231 维化学谱连同风格条件压缩进低维隐空间，解码器 $p_\theta(x\mid z,s)$ 从隐变量与风格条件重建化学谱。模型最大化证据下界

\begin{equation}
\mathcal{L}(\theta,\phi)=\mathbb{E}_{q_\phi(z\mid x,s)}\big[\log p_\theta(x\mid z,s)\big]-\beta_{KL}\,\mathrm{KL}\!\big(q_\phi(z\mid x,s)\,\big\|\,p(z)\big),
\end{equation}

其中先验 $p(z)=\mathcal{N}(0,I)$，采用重参数化 $z=\mu_\phi+\sigma_\phi\odot\epsilon$ 使梯度可回传。为避免缺失位置污染梯度，重构项只对非缺失分量计算误差：

\begin{equation}
\log p_\theta(x\mid z,s)\ \propto\ -\tfrac12\sum_{p:\,M_{ip}=0}\big(x_{ip}-\hat x_{ip}\big)^2.
\end{equation}

隐维取 16 以适配 250 的小样本规模：维度过低时 231 列的重构压力全落在少数隐变量上、各风格趋于同一均值，过高则在 250 个样本上过拟合。编码器 $E_\phi$ 把化学谱与风格条件拼接后映射为对角高斯的参数，解码器 $D_\theta$ 再从隐变量与条件重建化学谱：
\begin{equation}
(\mu_\phi,\log\sigma^2_\phi)=E_\phi(x,s),\qquad \hat x=D_\theta(z,s),\qquad z=\mu_\phi+\sigma_\phi\odot\epsilon.
\end{equation}

式 (17) 的 KL 项对对角高斯有闭式解，可直接逐维累加而不必采样估计：
\begin{equation}
\mathrm{KL}_d=\tfrac12\Big(\mu_{\phi,d}^2+\sigma_{\phi,d}^2-1-\log\sigma_{\phi,d}^2\Big),\qquad d=1,\dots,16.
\end{equation}

重构项按样本自身的观测位数归一化，使缺失比例不同的样本对总损失的贡献可比；若直接对 231 列求和，缺失多的样本会因观测位少而被系统性低估权重。由此得到训练所用的完整目标
\begin{equation}
\mathcal{J}(\theta,\phi)=\frac{1}{N}\sum_{i=1}^{N}\Bigg[\frac{1}{\lvert\mathcal{O}_i\rvert}\sum_{p\in\mathcal{O}_i}\big(x_{ip}-\hat x_{ip}\big)^2+\frac{\beta_{KL}(t)}{16}\sum_{d=1}^{16}\max\big(\mathrm{KL}_d,\ 0.5\big)\Bigg],
\end{equation}
其中 $\mathcal{O}_i=\{p:M_{ip}=0\}$ 为样本 $i$ 的非缺失位，除以 16 使 KL 项与逐列重构项量级相当，free-bits 下限 $\max(\cdot,0.5)$ 阻止某一维 KL 塌到零。

这套生成器只是“能采样”，本问还要它“能定向改造”。跨风格迁移之所以在隐空间而不是在 231 维化学谱上直接做，是因为化学谱各列尺度相差数个数量级、且列间共表达结构强，直接在原空间加减会破坏相关结构；隐空间则把谱压缩成低维表示，风格差异近似为一个可估的平移方向。

训练初期曾出现后验坍塌：$\beta_{KL}=1$ 时 KL 项迅速趋零、重构质量差，KS 距离约 0.6。本文把 $\beta_{KL}$ 降至 0.1，并对 KL 项施加前 120 轮线性退火与每维 free-bits 下限，重构损失由 0.765 降至 0.255，KS 距离随之降到 0.36 至 0.41；退火系数取
\begin{equation}
\beta_{KL}(t)=0.1\cdot\min\!\Big(1,\ \frac{t}{120}\Big),
\end{equation}
即前 120 轮由零线性升至 0.1，$t$ 为当前轮次；此后再按早停取最优权重。该处理只改变优化过程、不改变题设与数据。解码后统一截断到各列训练观测区间，使生成谱不越界：
\begin{equation}
\hat x_{ip}\leftarrow\min\!\Big(u_p,\ \max\big(\ell_p,\ \hat x_{ip}\big)\Big),\qquad \ell_p=\min_i x_{ip},\ \ u_p=\max_i x_{ip}.
\end{equation}

\subsection{跨风格迁移与缺陷约束}

跨风格迁移在隐空间以风格质心之差作为平移向量实现：

\begin{equation}
\Delta_{s\to t}=\bar z_t-\bar z_s,\qquad \hat x_{t}=p_\theta\big(z_s+\Delta_{s\to t}\,\big|\,\mathrm{onehot}(t)\big),
\end{equation}

其中 $\bar z_c$ 为风格 $c$ 所有样本隐编码的均值。该式是“把源点整体搬到目标质心”的最小位移解：若要求平移后的源质心恰为目标质心，则 $\bar z_s+\Delta=\bar z_t$，解得 $\Delta=\bar z_t-\bar z_s$；解码器同时接收目标风格 one-hot，使解码走的是目标风格的重建通路而非源风格通路。

\begin{equation}
x^{def}_{k,after}\ =\min\!\Big(\tilde x^{def}_{k,after},\ \ \min\big(x^{def}_{k,before},\ m^t_k\big)\Big),
\end{equation}

其中 $\tilde x^{def}_{k,after}$ 为隐空间平移并解码得到的\textbf{无约束}值，$x^{def}_{k,before}$ 为该样本源风格 Pils/Lager 缺陷 $k$ 的原始含量，$m^t_k$ 为目标风格 Tripel 缺陷 $k$ 的典型值（取中位）。该投影是一个带单侧上界的最近点问题，可行集为 $(-\infty,\min(x_{before},m^t_k)]$，而欧氏投影到半直线上的解就是截断本身，故它在满足约束的所有取值中离无约束值最近，除约束之外不再额外改写含量。源款原值构成第一道防线，目标典型值构成第二道兜底。由于各化学维单位不可比、绝对阈值无法统一换算，本题不并入绝对阈值 $\tau^{*}_k$，默认关闭；8.3 节以同一批样本不做投影的纯平移结果作对照，量化该约束不可或缺。

迁移谱的感官画像直接由问题一模型给出，$\hat y^{sens}=h_j(\hat x_t)$，由此把“化学上像 Tripel”与“感官上像 Tripel”两个层面的检验接在同一套底座上。

绝对口径需与目标风格本身的化学特征一并解读，否则易误读为投影失效。Tripel 的 28 条真实谱中 25 条 DMS 高于 19 μg/L、18 条 Diacetyl 高于 0.09 mg/L——目标风格在数据层面本就以较高 DMS 为特征；若强行把全部迁移样本压到阈值以下，生成谱将不再像 Tripel，与迁移目标冲突。本文因此以相对口径为硬约束（可逐样本审计且必然成立），绝对阈值作为诊断指标如实报告，而不宣称实现绝对意义的缺陷安全。这也说明：真实数据上风格迁移与缺陷达标并不总能同时满足，张力应由使用者按场景加权。

第五类缺陷 Stale hops 在化学谱中没有对应测量列，无法施加浓度投影。本文改用问题一模型对迁移谱打感官分作为代理：11 条迁移样本的 Stale hops 等级为 2 至 5、中位 3，与其源款等级分布一致，未出现系统性上升。需要说明这只是感官代理，不是对 Stale hops 相关化合物的直接浓度约束；要给出化学层面的保证，仍需该类陈化标志物的实测列。


上述只看四个缺陷化合物，而迁移到底改动了哪些化合物、改了多少并不清楚。把 11 条迁移样本的 12 个关键化合物相对源风格均值的变化按标准差归一化后逐列检查：酵母酯醇类被系统性上调，四个缺陷化合物的平均位移接近于零、个别为负，即约束确实用于阻止这些列被拉高。

隐空间平移是黑箱，本文因此在化学层给出方向对照。以"Tripel 真实均值 $-$ Pils/Lager 真实均值"为参照方向，与 11 条迁移谱的实际位移逐列比较：12 个关键调节化合物的符号全部一致（kcalperc $+$7.60 对 $+$7.74、乙醇 $+$7.33 对 $+$7.24、乙酸乙酯 $+$5.18 对 $+$5.29 等），全 231 列符号一致率 92.2\%，但余弦相似度仅 0.34，方向大体正确、幅度与部分列不一致。这个量化的"方向对、幅度不齐"正是需要缺陷投影兜底的原因。若只靠隐空间平移，少数列会被推过目标风格的真实水平，其中就包含缺陷化合物。

\section{模型检验与灵敏度分析}

\subsection{验证方案与防泄漏}

三问的可信度都建立在独立验证与全程防泄漏之上。问题一采用按风格分层的 5 折交叉验证，分箱分位点与标准化参数只在训练折估计，杜绝了在全量数据上估分箱这一最隐蔽的泄漏。问题二以 500 次按风格分层的 bootstrap 给出单方法稳健性（200/300/500 检查点 Top-1 无变化）、三法 Jaccard 给出方法间一致性，化学合理性再以交叉相关与酿造机理双重佐证。问题三对生成以分布距离与降维簇重叠评估，对迁移以缺陷合规率这一硬指标评估。本题没有隐藏测试集，所有数字均如实标注为交叉验证或分布距离的内部估计。

本文系统排查了六类泄漏并逐一封堵：分箱与标准化参数折内估计；主办方模型的参考重要性只作问题二旁证、不进入问题一训练特征；样本主键与风格标签不进入问题一特征矩阵；不对风格做目标编码。此外，附件 2 与 1.csv 的关联经核验只能按 \texttt{beer} 名称与行序对齐，按 \texttt{beer\_id} 会因精度丢失只剩 37/250 行，本文对此显式断言而非静默合并。

\subsection{方法增益的消融汇总}

第 6 至 8 章的每处设计均配有对照，本节集中列出，量纲不同故统一换算为相对百分比。

各环节的增益排序与预期一致，但性质不同：融合与分维选型是实质性改进——模块覆盖 2.30$\to$2.92，折外 QWK 0.3663$\to$0.3830（+4.6\%）且增益完全集中在 5 个退化维上，与 6.2 节的退化诊断相互印证；缺失处理（+0.3\%）与值域截断（+1.6\%）则属正确性修正，前者的价值在于不删样本、把缺失当作可用信息，后者在于消除解码器外推造成的量级失控。

\subsection{模型层的两项对照实验}

本节报告两项离线对照：问题一的分组共享多输出（方案 A），以及问题三的判别辅助损失与按风格留出。两者都不改变主结果——主模型 0.3830、提交用的生成谱与迁移谱均保持原样，对照只用于回答“共享表示是否值得”与“隐空间能否被修好”这两个方法层面的问题。

\subsubsection{问题一：分组共享多输出（方案 A）}

主模型对 50 个维度各自独立训练。若同一组内的感官维确实共享化学驱动，把同组其他维的折内预测当作附加特征，应能借助组内相关性降低方差。本文按香气（15）/ 风味（15）/ 口感缺陷（20）三组实现这一思路：在每个训练折内，先用组内 5 折 OOF 预测构造“组画像特征”（只用训练折样本，防泄漏），再把每个目标重新训练为“231 原始特征 + 同组其余 $k-1$ 个组画像特征”；分箱退化维仍用类加权有序回归，与主模型同一判据、同一实现。

结果与预期相反，该方案宏平均 QWK 为 \textbf{0.3759}，低于主模型的 0.3830。配对 bootstrap 2000 次给出 $\Delta$QWK $=+0.0070$、95\% 区间 $[0.0001,0.0139]$，主模型在 97.7\% 的重采样中更优。分组看更清楚，香气由 0.322 降至 0.305、风味由 0.400 降至 0.394，两组都退步。只有口感缺陷组基本持平（0.416 降至 0.415）。

这一负结果有信息量。结合 6.2 节的相关矩阵：真正强的相关是“同名维的跨通道配对”（香气·酯与风味·酯 0.836、香气·酒花与风味·酒花 0.828），而非“组内维之间”（香气组内中位 $|r|=0.124$）。按通道分组恰好把最相关的配对（A\_ 与同名 F\_）切开，组画像特征只能提供弱信息，却额外引入 14--19 个含噪特征，在 250 样本上放大过拟合。组内共享表示的收益取决于相关结构与分组边界是否对齐，本题恰好不对齐，故保留逐维独立建模。

\subsubsection{问题三：判别辅助损失能否修复隐空间塌缩}

问题三已报告一个关键局限：三风格隐质心的置换检验 $p=0.92/0.99/1.00$，即 16 维隐空间里不存在超出噪声的风格结构。本文在编码器输出 $z$ 上加一个线性风格分类头，把总损失改为 $L=L_{\mathrm{recon}}+\beta_{KL}\cdot\mathrm{KL}+\lambda\cdot\mathrm{CE}(s\mid z)$，其余设定（KL 退火、free-bits、截断、隐维 16、600 轮）完全不变，只扫 $\lambda\in\{0,0.02,0.1,0.3,0.5\}$。

对照给出一条清晰的权衡曲线。$\lambda=0$ 即现状，置换检验 $p=1.00$、隐空间线性分类准确率 3.2\%（随机基线 4.5\%）；只要加入判别项，隐空间立刻可分，$\lambda=0.02$ 时 $p=0.000$、分类 54\%，$\lambda\ge0.1$ 时分类接近 100\%。但代价同步上升：生成谱 KS 由 0.373 依次升至 0.392 / 0.411 / 0.445 / 0.468，重构 MSE 由 0.266 升至 0.284 / 0.340 / 0.397 / 0.429。判别约束确实修好了“风格在隐空间不可辨识”这一缺陷，但收益建立在分布保真之上。

本文不把判别头并入主模型：任务目标是生成像真实的化学谱，而非让隐空间可分，为诊断指标牺牲 KS 与重构质量与任务目标不一致。这一对照的价值在于把局限的性质说清：隐空间塌缩不是训练不足，而是“重构全部 231 列”这一目标本身的取舍——加入显式判别项即可改变，但代价可量化。若后续任务更看重风格可控性（如按风格插值），推荐 $\lambda=0.02$ 这一折中档：风格已显著可分而 KS 只上升 0.019，该结论在 seed 7 上复现（$\lambda=0$：$p=1.00$、分类 5.2\%；$\lambda=0.1$：$p=0.000$、分类 99.2\%）。

\section{模型评价与推广}

\subsection{优点与创新}

第一，以共享的化学到感官预测底座贯通三问：同一套经交叉验证的模型既是问题二的 SHAP 归因对象，又是问题三生成谱的感官打分器，预测、归因与生成三者联动。

第二，归因限定为 211 个单一化合物，并以模块代表加权与同社区去冗余；三路融合把单维 Top-3 命中的模块数由 2.30 提到 2.92（满分 3），跨方法 Jaccard 0.200 为随机基线 0.0086 的 23.3 倍，并以配对 bootstrap 与 A/B/C 分级给出可信度。

第三，把缺陷不恶化形式化为 $\min(\tilde x_{after},x_{before},m_t)$ 逐样本投影，配无约束对照（72.7\% 本会升高）；另用真实浓度阈值做绝对口径审计，区分“相对不恶化”与“绝对达标”。

第四，识别出分位分箱在标签分布高度集中时失效的隐性前提，据此只在退化维改用类加权有序回归，折外 QWK 由 0.3663 升至 0.3830（+4.6\%）；并对“更强的表示”与“更可分的隐空间”两条路线做了严格对照、如实报告负结果，使方法选择有可复核依据。

\subsection{不足与改进}

其一，0-6 分级由连续值单调映射重建而非原始品评卡复现，分级绝对值带有映射口径的印记；250 样本下增维（阈值列、模块 PC1、分组共享）亦未兑现精度。

其二，生成谱需按观测区间截断、迁移依赖缺陷投影兜底，判别头以 KS 上升换取隐空间可分；来源一致率仅 12\%，高删失列未建显式删失似然。


\subsection{推广}

本文框架可推广到其他成分谱与感官建模场景：缺失感知有序预测适用于品评缺测数据，共表达图加多证据归因适用于高共线性组学或光谱筛选，带硬约束的条件生成可用于规避有害成分的配方设计。

DEGEN_SPAN = 0.05      # 前 5 个分位切点跨度 < 极差的 5% 判为退化
ORD_MIN_FRAC = 0.10    # 阈值两侧任一类占比低于 10% 时不做二分类

def binning_degenerate(ytr, span_th=DEGEN_SPAN):
    """判断该维的分位分箱是否退化：切点挤在极窄区间内，等级在原始尺度上不可分。"""
    y = np.asarray(ytr, dtype=float)
    y = y[np.isfinite(y)]
    if y.size < 20:
        return False
    rng = float(y.max() - y.min())
    if rng <= 0:
        return True
    edges = U.Binner().fit(y).edges
    return bool((edges[4] - edges[0]) / rng < span_th)

def _fit_ordinal(Xtr, ytr, Xva, n_levels=P.N_LEVELS):
    """类加权阈值分解：对每个内部阈值训练一个「y > t」二分类器，概率累加后取整。

    与直接回归再分箱相比，它不依赖切点位置，因而能绕开密集分布下切点重合的问题；
    阈值两侧样本不均衡时按类频率反比加权，避免多数类主导。
    """
    ytr = np.asarray(ytr, dtype=float)
    edges = np.quantile(ytr, np.linspace(0, 1, n_levels + 1)[1:-1])
    edges = np.maximum.accumulate(edges)
    acc = np.zeros(len(Xva))
    for t in edges:
        z = (ytr > t).astype(int)
        frac = float(z.mean())
        if frac < ORD_MIN_FRAC or frac > 1 - ORD_MIN_FRAC:
            acc += frac                      # 无区分度的阈值直接用先验
            continue
        w = np.where(z == 1, 1.0 / max(frac, 1e-6), 1.0 / max(1.0 - frac, 1e-6))
        clf = lgb.LGBMClassifier(**CLF_PARAMS)
        clf.fit(Xtr, z, sample_weight=w)
        acc += clf.predict_proba(Xva)[:, 1]
    return np.clip(np.round(acc), P.LEVEL_MIN, P.LEVEL_MAX).astype(int)

def _module_rep(base_scores, comm_arr):
    """模块代表加权：同社区（仅 C，comm!=-1）内按 base 排名，第 1 名 rep=1，第 2=1/2…

    非 C 位置 comm=-1 直接跳过（rep 保持 0），促进 Top-3 跨模块多样。
    """
    rep = np.zeros_like(base_scores, dtype=float)
    for ci in np.unique(comm_arr):
        if ci == -1:
            continue                      # 非 C 节点不参与模块代表
        idx = np.where(comm_arr == ci)[0]
        order = idx[np.argsort(-base_scores[idx])]
        for rank, p in enumerate(order, 1):
            rep[p] = 1.0 / rank
    return rep

    top3_idx = {}
    # 点估计：φ=0.5SHAP+0.3|corr|+0.2module_rep，module_rep 仅在 C 社区内
    shap_n_all = np.vstack([_norm(shap_imp[j]) for j in range(J)])
    corr_n_all = np.vstack([_norm(corr_evid[j]) for j in range(J)])
    rf_n_all = np.vstack([_norm(rf_imp[j]) for j in range(J)])
    phi_all = np.zeros((J, Pn))
    for j in range(J):
        base = a * shap_n_all[j] + b * corr_n_all[j]
        rep = _module_rep(base, comm_arr)          # 仅 C 社区
        phi = base + g * rep
        phi_all[j] = phi
        # 去冗余 Top-3（phi 先掩码到 C）
        top3_idx[j] = _select_topk(_mask_c(phi, c_mask), R, comm_arr)
    # bootstrap 入选频率：**按风格分层**有放回重采样 → 重算 SHAP → 同一融合+去冗余流程（只在 C 内）。
    # 分层可避免小样本风格在重采样中整体缺席，使频率反映"同风格内"的稳定性。
    rng_bt = np.random.default_rng(P.SEED)
    N = abs_shap_list[0].shape[0]
    style_arr = np.asarray(styles)
    strata = [np.where(style_arr == s)[0] for s in pd.unique(style_arr)]
    freq = np.zeros((J, Pn))
    B = P.N_BOOTSTRAP
    conv_trace = {}          # 200/300/500 收敛检查
    for bi in range(B):
        parts = [rng_bt.choice(idx, size=len(idx), replace=True) for idx in strata if len(idx)]
        idx = np.concatenate(parts)
        for j in range(J):
            shap_b = _norm(abs_shap_list[j][idx].mean(axis=0))
            base_b = a * shap_b + b * corr_n_all[j]
            phi_b = base_b + g * _module_rep(base_b, comm_arr)
            for p in _select_topk(_mask_c(phi_b, c_mask), R, comm_arr):
                freq[j, p] += 1
        if (bi + 1) in (200, 300, 500):
            snap = freq / (bi + 1)
            top1 = [int(np.argmax(snap[j])) for j in range(J)]
            conv_trace[str(bi + 1)] = {
                "mean_top1_freq": round(float(np.mean([snap[j, top1[j]] for j in range(J)])), 4),
                "n_top1_changed_vs_final": None,   # 稍后填
                "top1": top1,
            }
            print(f"[Q2] bootstrap {bi+1}/{B}  mean_top1={conv_trace[str(bi+1)]['mean_top1_freq']:.4f}")
    freq /= B
    # 跨方法 Jaccard（SHAP / 6.csv相关 / RF；各方法 Top-3 只在 C 内取）
    jac_dim = {}
    for j in range(J):
        ts = _topk_masked(shap_n_all[j], c_mask)
        tc = _topk_masked(corr_n_all[j], c_mask)
        tr = _topk_masked(rf_n_all[j], c_mask)
        pj = np.mean([_jaccard(ts, tc), _jaccard(ts, tr), _jaccard(tc, tr)])
        jac_dim[sens_cols[j]] = round(float(pj), 4)

    for j, col in enumerate(sens_cols):
        t3 = top3_idx[j]
        per_dim[col] = {
            "top3": [feat_cols[p] for p in t3],
            "top3_idx": [int(p) for p in t3],
            "phi": [round(float(phi_all[j, p]), 4) for p in t3],
            "shap_norm": [round(float(shap_n_all[j, p]), 4) for p in t3],
            "corr_abs": [round(float(corr_n_all[j, p]), 4) for p in t3],
            "select_freq": [round(float(freq[j, p]), 4) for p in t3],
            "module": [int(comm_arr[p]) for p in t3],
            "jaccard_cross_method": jac_dim[col],
        }
    # 收敛检查：200/300 次的 Top-1 与最终（500 次）Top-1 差异维数
    final_top1 = [int(np.argmax(freq[j])) for j in range(J)]
    for k in conv_trace:
        prev = conv_trace[k]["top1"]
        conv_trace[k]["n_top1_changed_vs_final"] = int(sum(1 for a_, b_ in zip(prev, final_top1) if a_ != b_))
        conv_trace[k].pop("top1", None)
    print("[Q2] 收敛检查:", {k: (v["mean_top1_freq"], v["n_top1_changed_vs_final"]) for k, v in conv_trace.items()})

    mean_top1_freq = float(np.mean([per_dim[c]["select_freq"][0] for c in sens_cols]))
    mean_jac = float(np.mean(list(jac_dim.values())))
    n_high_stable = int(sum(1 for c in sens_cols if per_dim[c]["select_freq"][0] >= 0.7))
    print(f"[Q2] 平均Top-1入选频率={mean_top1_freq:.4f} 平均跨方法Jaccard={mean_jac:.4f} "
          f"高稳定维={n_high_stable}")
    return {
        "problem": 2,
        "method": ("共表达图(networkx+louvain,仅C 211项) + SHAP/相关/模块代表融合(φ=0.5/0.3/0.2) "
                   "+ 同社区|R|>=0.7去冗余 + bootstrap频率 + 跨方法Jaccard + 随机基线对照"),
        "candidate_set": {"name": "C", "n": int(c_mask.sum()),
                          "excluded_physicochem": sorted(P.PHYSICOCHEM_COLS),
                          "excluded_aggregate": sorted(P.AGG_COLS)},
        "summary": {"n_dims": J, "n_bootstrap": B, "topn": P.TOPN,
                    "mean_top1_select_freq": round(mean_top1_freq, 4),
                    "mean_cross_method_jaccard": round(mean_jac, 4),
                    "n_high_stable_dims": n_high_stable,
                    "redun_rho": REDUN_RHO,
                    "fuse_weights": {"alpha": a, "beta": b, "gamma": g},
                    "bootstrap_stratified_by_style": True,
                    "bootstrap_convergence": conv_trace},
        "per_dim": per_dim, "sensory_cols": sens_cols,
    }

def _elbo_loss(xhat, x, mask, mu, logvar, beta_kl, free_bits=P.FREE_BITS):
    # 掩码重构（只对非缺失分量计 MSE，式11）
    diff2 = ((xhat - x) ** 2) * mask
    recon = diff2.sum() / mask.sum().clamp(min=1.0)
    # 逐维 KL + free-bits（每维 KL 低于 free_bits 时不再惩罚，防后验坍塌）
    kld_dim = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp())   # [B, d]
    kld_dim = torch.clamp(kld_dim.mean(dim=0), min=free_bits)
    kld = kld_dim.sum()
    return recon + beta_kl * kld, recon.item(), float(kld.item())

def _train_cvae(Xstd, mask, onehot, device):
    model = CVAE(Xstd.shape[1], onehot.shape[1]).to(device)
    opt = torch.optim.Adam(model.parameters(), lr=P.CVAE_LR)
    Xt = torch.tensor(Xstd, dtype=torch.float32, device=device)
    Mt = torch.tensor(mask, dtype=torch.float32, device=device)
    St = torch.tensor(onehot, dtype=torch.float32, device=device)
    N = Xt.shape[0]
    best, best_state, patience, bad = 1e18, None, 60, 0
    rng = np.random.default_rng(P.SEED)
    for ep in range(1, P.CVAE_EPOCHS + 1):
        model.train()
        perm = rng.permutation(N)
        ep_loss = ep_rec = ep_kl = 0.0
        for st in range(0, N, P.CVAE_BATCH):
            bidx = perm[st:st + P.CVAE_BATCH]
            xb, mb, sb = Xt[bidx], Mt[bidx], St[bidx]
            opt.zero_grad()
            xhat, mu, lv = model(xb, sb)
            beta = P.BETA_KL * min(1.0, ep / max(1, P.KL_ANNEAL_EPOCHS))  # KL 退火
            loss, rec, kl = _elbo_loss(xhat, xb, mb, mu, lv, beta)
            loss.backward()
            opt.step()
            ep_loss += loss.item() * len(bidx); ep_rec += rec * len(bidx); ep_kl += kl * len(bidx)
        ep_loss /= N
        if ep <= P.KL_ANNEAL_EPOCHS:
            if ep % 50 == 0 or ep == 1:
                print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS}(退火) loss={ep_loss:.4f} "
                      f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
            continue   # 退火阶段不计入早停
        if ep_loss < best - 1e-4:
            best, best_state, bad = ep_loss, {k: v.detach().clone() for k, v in model.state_dict().items()}, 0
        else:
            bad += 1
        if ep % 50 == 0 or ep == 1:
            print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS} loss={ep_loss:.4f} "
                  f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
        if bad >= patience:
            print(f"[Q3] 早停于 epoch {ep}（best loss={best:.4f}）")
            break
    if best_state is not None:
        model.load_state_dict(best_state)
    model.eval()
    return model

def _transfer(model, style_list, s2i, S, Xstd, Xv, styles, feat_cols, mu_f, sd_f,
              device, lo=None, hi=None):
    """Pils/Lager → Tripel 隐空间平移 + 缺陷投影（式12/13）。"""
    tgt = P.TRANSFER_TARGET
    zt, _ = _style_latent_mean(model, Xstd, styles, tgt, s2i, S, device)
    # 目标风格缺陷典型值 m^t（native 中位）
    tgt_idx = np.where(styles == tgt)[0]
    col_med_all = np.nanmedian(Xv, axis=0)
    defect_pos = {d: feat_cols.index(c) for d, c in P.DEFECT_COL_MAP.items()}
    m_t = {d: float(np.nanmedian(Xv[tgt_idx, pos])) for d, pos in defect_pos.items()}

    records = []
    before = {d: [] for d in defect_pos}
    after = {d: [] for d in defect_pos}
    cap_rec = {d: [] for d in defect_pos}
    raw_after = {d: [] for d in defect_pos}   # 无约束纯平移对照（缺陷投影前的解码值）
    for src in P.TRANSFER_SOURCES:
        if src not in s2i:
            print(f"[Q3] 迁移源 {src} 不存在，跳过")
            continue
        zs, sidx = _style_latent_mean(model, Xstd, styles, src, s2i, S, device)
        delta = zt - zs
        # 逐源样本编码 -> 平移 -> 用目标风格解码
        oh_src = np.zeros((len(sidx), S)); oh_src[:, s2i[src]] = 1
        with torch.no_grad():
            mu_s, _ = model.encode(torch.tensor(Xstd[sidx], dtype=torch.float32, device=device),
                                   torch.tensor(oh_src, dtype=torch.float32, device=device))
            z_moved = mu_s.cpu().numpy() + delta
            oh_t = np.zeros((len(sidx), S)); oh_t[:, s2i[tgt]] = 1
            xhat = model.decode(torch.tensor(z_moved, dtype=torch.float32, device=device),
                                torch.tensor(oh_t, dtype=torch.float32, device=device)).cpu().numpy()
        native = xhat * sd_f + mu_f
        if lo is not None and hi is not None:
            native = _clip_to_observed(native, lo, hi)
        for row, si in enumerate(sidx):
            x_after_vec = native[row].copy()
            for d, pos in defect_pos.items():
                xb = Xv[si, pos]
                if not np.isfinite(xb):
                    xb = float(col_med_all[pos])
                raw_val = float(x_after_vec[pos])           # 无约束纯平移的缺陷取值（对照）
                raw_after[d].append(raw_val)
                # 严格不恶化：迁移后缺陷既不得高于源款原值 xb，也不高于目标典型安全值 m_t，取严
                cap = min(xb, m_t[d])
                if P.USE_ABS_THRESHOLD:
                    pass  # 可换算时此处并入 τ 上界（本题单位不可比，默认关闭）
                # 缺陷列逐样本投影回安全区（式13，np.minimum 下截断）
                xa = float(np.minimum(raw_val, cap))
                x_after_vec[pos] = xa
                before[d].append(float(xb)); after[d].append(xa); cap_rec[d].append(cap)
            records.append({"style": f"{src}->{tgt}", "sample_type": "transfer",
                            "src_beer_row": int(si), "_native": x_after_vec})
        print(f"[Q3] 迁移 {src}->{tgt}: {len(sidx)} 条")
    # 合规率（式13：x_after <= min(xb, m_t)）
    n_tot = n_ok = 0
    n_rise_raw = n_rise_constrained = 0
    per_defect = {}
    for d in defect_pos:
        bf = np.array(before[d]); af = np.array(after[d]); cp = np.array(cap_rec[d])
        raw = np.array(raw_after[d])
        ok = int((af <= cp + 1e-9).sum())
        rise_raw = int((raw > bf + 1e-9).sum())    # 无约束时缺陷升高的样本数
        rise_c = int((af > bf + 1e-9).sum())       # 严格约束后缺陷升高数（应为 0）
        n_tot += len(af); n_ok += ok
        n_rise_raw += rise_raw; n_rise_constrained += rise_c
        per_defect[d] = {"n": len(af), "n_compliant": ok,
                         "before_mean": round(float(bf.mean()), 4),
                         "after_mean": round(float(af.mean()), 4),
                         "raw_after_mean": round(float(raw.mean()), 4),
                         "m_t": round(m_t[d], 4),
                         "delta_mean": round(float((af - bf).mean()), 4),
                         "delta_raw_mean": round(float((raw - bf).mean()), 4),
                         "n_rise_unconstrained": rise_raw,
                         "n_rise_constrained": rise_c}
    rate = n_ok / n_tot if n_tot else 1.0
    info = {"compliance_rate": round(rate, 6), "n_checks": n_tot, "n_compliant": n_ok,
            "per_defect": per_defect, "defect_cols": list(P.DEFECT_COL_MAP.values()),
            "defect_no_chem": P.DEFECT_NO_CHEM, "m_t": {k: round(v, 4) for k, v in m_t.items()},
            "unconstrained_control": {
                "description": "同批迁移仅做隐空间平移、不做缺陷投影（对照），量化约束必要性",
                "n_defect_rise_unconstrained": n_rise_raw, "n_total": n_tot,
                "rise_frac_unconstrained": round(n_rise_raw / n_tot, 4) if n_tot else None,
                "n_defect_rise_constrained": n_rise_constrained,
                "rise_frac_constrained": round(n_rise_constrained / n_tot, 4) if n_tot else None}}
    print(f"[Q3] 缺陷合规率={rate:.4f}（{n_ok}/{n_tot}）；无约束升高 {n_rise_raw}/{n_tot}，"
          f"严格约束后升高 {n_rise_constrained}/{n_tot}")
    return records, info
