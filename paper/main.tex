\begin{cumcmabstract}
啤酒风味由化合物组成与酵母代谢共同决定。本文在含真实缺失与噪声的 250 个商用啤酒样本上，构建“化学到感官判别预测 → 可解释归因 → 风格条件生成”的贯通流水线，三问共享同一化学到感官模型。

针对问题一，采用\textbf{原生缺失感知的梯度提升}对 50 个感官维逐维回归，再按训练折内分位点映射为 0-6 等级，按风格分层 5 折验证且分箱参数全程折内估计。平均 QWK 达 \textbf{0.3830}，折外 Spearman 0.4109，$\pm$1 级准确率 57.3\%，优于随机森林 0.328、ElasticNet 0.276 与 KNN 插补 0.3652；2000 次配对重采样的 95\% 区间对三类基线均不跨零。风味组 QWK 0.400 高于香气组 0.322，酒精、苦味等强信号维超 0.77，花香酯类弱信号维接近噪声。

针对问题二，剔除 16 个理化参数与 4 个汇总列，仅在 \textbf{211 个单一化合物}上建共表达图，得 211 节点、564 边、55 社区，模块度 \textbf{0.625}；融合 SHAP、交叉相关与模块代表三路证据选出 Top-3 并去共线冗余。Top-1 的 bootstrap 入选频率均值 \textbf{0.991}，跨方法 Jaccard \textbf{0.186} 为随机基线 0.0086 的 \textbf{21.7 倍}。50 维联合检验显示 QWK 与 Top-1 稳定性的相关仅 $r=0.110$，二者是相互独立的两个维度；随可预测性下降而失稳的是第 3 名。按 8.xlsx 标注的来源逐维判定，一致 7 维、部分一致 16 维，麦芽维多落于酵母酯醇，如实反映发酵后风味载体的真实结构。

针对问题三，用\textbf{条件变分自编码器}以风格为条件生成化学谱，在隐空间做质心平移实现跨风格迁移。三个代表风格的 KS 为 0.351–0.411，逐列核查显示偏离集中于稀疏检出列（KS 与未检出率 $r=0.66$）；风格 Top-3 识别率 100\%（随机 13.6\%），画像 Spearman 0.65–0.92。Pils/Lager 到 Tripel 的缺陷采用逐样本 min 投影，迁移后 \textbf{0/44 次升高}，而同批不做投影的纯平移有 32/44 次升高。

三问结论均经交叉验证、bootstrap 与分布距离检验，框架可推广到其他成分谱与感官建模场景。
\cumcmkeywords{啤酒风味；缺失感知梯度提升；共表达网络；条件变分自编码器；配对 bootstrap}

\section{问题重述}

啤酒以麦芽水为原料、加酒花并经酵母发酵而成，其风味高度依赖酵母代谢与化合物成分的协同作用。要定量刻画化学成分如何决定一款啤酒喝起来是什么味道，需要把实验室测得的数百种风味化合物与品评小组给出的感官强度联系起来。近年来，机器学习方法已被用于从化学成分预测啤酒及其他发酵饮品的风味特征\cite{b1,b2,b3}，为本文提供了方法论基础。本文使用一套商用啤酒风味代谢物实测数据集：对 250 个啤酒样本测量了酒精、异 $\alpha$-酸、pH、糖浓度等酿造参数，以及 200 余种风味化合物的丰度，涵盖酒花萜类、酵母代谢酯醇、麦芽与野生菌群化合物及陈化类，并由品评小组给出约 50 个感官维度的评分。数据来自真实测量，含噪声、真实缺失值与异常值。围绕化学成分、感官风味与啤酒风格这条链条，本文研究三个递进的问题。

问题一：在化学数据存在真实缺失的条件下，以化合物与理化丰度为自变量，预测品评卡定义的香气 Aroma 与风味 Flavour 两套、合计约 40 个感官维度在 0-6 分制上的分级评分。任务对象是每一款啤酒样本，待求量是各感官维度的离散等级，关键边界是自变量含缺失而不能简单删除样本，评价目标是在缺失干扰下给出稳定可信的分级。本问为后两问提供化学如何映射到感官的基础模型。

问题二：利用化合物相关数据构建化合物共表达图，结合化学特征，给出每一个感官维度的 Top-3 关键因素化合物，并对所得结果做稳定性与化学合理性论证。稳定性按题面指定的两种口径量化——bootstrap 重采样下化合物进入 Top-3 的入选频率，以及不同建模方法间 Top-3 集合的 Jaccard 系数。本问依赖问题一的预测模型做可解释归因，其产出的关键化合物清单又为问题三识别风格判别成分提供先验。

问题三：以风格标签 \texttt{tasting\_\allowbreak{}category\_\allowbreak{}fine} 为条件学习一个风格条件生成模型，在给定风格时，例如 Tripel、Kriek、Lambic，生成合理的化合物谱并给出对应感官画像；同时完成跨风格迁移，即把 Pils/Lager 的化合物谱迁移为 Tripel 风格，并保持 DMS、Diacetyl、4VG、trans-2-nonenal、Stale hops 等缺陷化合物不恶化。该问反向利用问题一的感官画像与问题二的关键化合物，是三问的综合应用。

三个问题沿数据预处理、化学到感官的判别式预测、可解释归因、风格到化学的条件生成与迁移逐级推进，构成一条从理解到生成的完整流水线，其整体求解思路与依赖关系概括如下。

\section{问题分析}

\subsection{问题一的分析}

问题一本质是一个带缺失数据的多输出有序预测任务，核心难点集中在三处。其一，化学特征高维，共 231 列，且含真实缺失，其中 63 个样本、合计 73 个缺失值集中在少数几列，直接删除含缺失的样本会损失四分之一的数据并引入选择偏差，因此必须在缺失条件下建模。其二，品评小组提供的感官标签是经过标准化、中心化的连续值而非原始 0-6 整数，要交付题面要求的 0-6 分级，需要建立连续值到 7 级离散刻度的单调映射。其三，约 40 个感官维度彼此相关性强，宜共享同一套化学特征表示以提升稳健性。据此，本文选择原生支持缺失的梯度提升树\cite{b5,b6,b7}作为主模型，对每个维度做回归后再分箱映射回 0-6 整数，并用分层交叉验证逐维评估二次加权 Kappa、平均绝对误差与决定系数。相较先插补再建模的常规路线，原生缺失处理避免了插补偏差，其输出的特征重要性又可直接服务于问题二的归因。

\subsection{问题二的分析}

问题二是一个在共线性干扰下仍要既准、又稳、还有化学道理的可解释归因任务。许多化合物在相关矩阵里高度相关、成簇出现，单一重要性指标容易把同一化学模块里可以互相替代的化合物反复选入，造成 Top-3 虚假冗余。因此本文先用化合物共表达图揭示模块结构，再在模块意识下融合三类证据做归因：问题一模型给出的 SHAP 预测贡献、化学与感官的交叉相关，以及共表达模块的去冗余加权。稳定性严格按题面两法量化，bootstrap 入选频率刻画单方法内部的稳健性，跨方法 Jaccard 刻画不同证据之间的一致性。化学合理性则逐条对照已知酿造机理加以论证。需要强调，强信号维度的 Top-3 应当稳定、弱信号维度不稳定，这是数据本身的真实现象，本文如实报告而不强行制造稳定。

\subsection{问题三的分析}

问题三是条件生成加可控迁移任务，难点在于小样本条件下，部分风格仅有 3 至 11 个样本，既要保证生成谱的化学合理性与风格可区分性，又要在迁移时守住缺陷不恶化这一硬约束。本文用条件变分自编码器把化合物谱编码进低维隐空间、以风格标签为条件解码，兼顾生成多样性与风格可控；对极小样本风格辅以按风格的分布采样作为对照与兜底。生成谱的感官画像直接复用问题一的化学到感官模型，形成生成化学谱再预测感官的闭环。迁移通过在隐空间做源风格到目标风格的方向平移实现，并对缺陷化合物施加阈值与源值的双重投影，一旦超限即拉回安全区，确保迁移后缺陷不劣化。生成质量用真实谱与生成谱的分布距离及降维重叠度评估。

\section{模型假设}

为聚焦核心建模，本文做出以下假设。

（1）以标准化连续感官值为问题一的训练目标，再按训练折内分位点单调映射回 0-6 等级。原始品评卡汇总表为全 0 模板、不可用，标准化连续值是唯一完整可用的全样本标签。

（2）题面的"约 40 个感官维度"对应 Aroma 与 Flavour 两套共 30 维，本文另输出口感、缺陷与总体评价共 20 维，合计 50 维以覆盖任一解读。

（3）化学特征的数值尺度经 8.xlsx 校准浓度逐列核实为混合尺度：70 个可校准列中 37 列为常用对数、33 列为原值，无自然对数列；其余 161 列按列分布归类。建模在原生数值空间内进行而不做反变换，树模型对单调变换不敏感，该选择不影响分裂结果。

（4）缺陷不恶化取严口径：迁移后缺陷须同时不高于源款原值 $x^{def}_{k,before}$ 与目标风格典型值 $m^t_k$，即上界为 $\min\!\big(x^{def}_{k,before},m^t_k\big)$。该口径保证相对不升高；绝对达标情况另按 8.xlsx 真实阈值审计（见 8.3 节）。

（5）各样本近似独立同分布，风格标签为问题三唯一的条件变量。附件为截面数据、无时间序列结构，故交叉验证采用按风格分层的随机折。

本文主分析\textbf{只使用主办方提供的 8 个附件}；另引入一个公开啤酒数据集作为\textbf{外部旁证}，见 5.5 节，它既不与本数据逐行合并，也不进入任何模型，仅用于校验风格规格的行业常识。建模所用的核心数据包含四部分：化合物与理化丰度矩阵，250 样本 $\times$ 231 特征；化合物相关矩阵，231 $\times$ 231；标准化感官值矩阵，250 $\times$ 50，作为问题一训练标签；化学与感官的交叉相关矩阵，44 化合物 $\times$ 50 感官，作为归因的线性证据。8 个附件的实测规模与用途见附录 A（表 A.1），行列数均以本文程序实际读取为准。

题面文字与附件实测存在若干出入，本文一律以实测为准，差异核对见附录 A（表 A.2）。

附件之间如何对齐同样需要核对，这里有一处容易被静默忽略的陷阱。1.csv 与 4.csv 都带有 \texttt{beer\_id}，直觉上应以它作为关联键；但从 4.csv 读出的 \texttt{beer\_id} 已被转成浮点并丢掉了尾部精度，例如 \texttt{5410230000000.0}，两表按 \texttt{beer\_id} 取交集只剩 \textbf{37/250} 行。若按该键做 inner join，四分之三的样本会被无声丢弃，而程序不会报错。改用 \texttt{beer} 名称关联可恢复 250 行，且本文进一步核验了两表的 \texttt{beer} 列逐行完全相同、行序一致，因此四份数据在对齐上不存在歧义。

本文的实现在这一点上采用按行序对齐并显式校验：读入后立即断言 1.csv 与 4.csv 均为 250 行，且两者的 \texttt{beer} 列逐行相同；任何一步不符都会直接中断而不是静默继续。此外，2.csv 与 1.csv 的 231 个特征按位置一一对应（已用重算的 Spearman 逐元素核对），6.csv 的 44 个化学行按名称映射回 231 列位置，未覆盖的化合物记为 0 而不参与排序。这些校验写在 \texttt{code/data\_check.py} 中，可独立运行复核。

在 231 个化学特征中，本文按化学含义把它们分为三类：\textbf{理化/过程参数} 16 列，如酒精度、色度、pH、苦度、二氧化碳压力、蛋白、甘油、未发酵糖等；\textbf{多化合物汇总列} 4 列，分别为总酯 esters\_sum、酒花香气总量 aroma\_hops\_sum、总酸 acids\_sum、含硫总量 sulfur\_sum，均为多个化合物的加总；\textbf{单一化合物集 $C$} 211 列，即 $231-16-4$。问题一以全部 231 个特征为自变量，理化指标对预测感官同样有用，不应删除；问题二为严格回应找出关键化合物的题意，仅在 211 个单一化合物构成的集合 $C$ 内建图与归因，避免把酒精度、苦度这类理化指标或总酯这类加总列误当作某个具体化合物。

三类数据的数值口径并不一致，必须先对齐认知再建模。感官标签列为中心化的标准化连续值，范围约 $-2.15$ 至 $6.17$、均值接近 0，并非原始 0–6 整数；化学特征的对数/原值尺度经 5.3 节核实为混合尺度。由于本文主模型为树模型、对单调变换不敏感，建模统一在该原生数值空间内进行而不做反变换，既规避了对数尺度换算的风险，又保证问题三生成与缺陷判定在同一空间内可比。

\subsection{对数底核实与尺度统一}

化合物丰度究竟取对数还是原值，直接影响浓度叙述。8.xlsx 的 Calibrated chemical dataset 提供了 70 个化合物的校准绝对浓度 $c_{ik}$，本文据此逐列反推 1.csv 取值 $x_{ik}$ 的尺度：对每个校准列，在 $c_{ik}>0$ 的样本上分别计算 $\mathrm{median}_i|x_{ik}-\log_{10}c_{ik}|$、$\mathrm{median}_i|x_{ik}-c_{ik}|$ 与 $\mathrm{median}_i|x_{ik}-\ln c_{ik}|$，若第一个小于 $10^{-6}$ 判为常用对数列、第二个小于 $10^{-6}$ 判为原值列，第三个用于排除自然对数。核实结果为：70 个校准列中 \textbf{37 列严格为常用对数、33 列严格为原值}，二者的中位残差均为 0、与对应尺度的相关系数均为 1.0，且不存在自然对数列；值得注意的是连 pH 也取常用对数，$0.625=\log_{10}4.21$。常用对数列包含全部 16 个理化指标与 21 个酵母酯、醇、硫化合物；原值列则以酒花萜烯、醛、酚类为主，如芳樟醇、香叶醇、香茅醇、丁香酚、糠醛、反式-2-壬烯醛、双乙酰。其余 161 列没有校准绝对浓度，本文按列分布与已知理化列归类，并对其尺度明确标注未经校准，不编造校准残差。

需要特别说明化学谱中的负值。231 个特征中有 \textbf{175 列出现负数，合计 10797 个负值单元格}，它们不是异常值或测量错误，而是浓度小于 1 的化合物取常用对数后的正常结果，例如 $\log_{10}0.1=-1$。按列核查，负值全部出现在已判定为常用对数的列上，原值列不含负值。因此本文不做任何剔除、截断或取绝对值，保留其原始对数取值；剔除这些行等于删掉近半数观测信息，还会使分布严重右偏。

\subsection{未检出、真实缺失与异常值}

化学谱里大量低值并非缺失，而是\textbf{未检出}，即浓度低于仪器检出限，它本身携带该化合物极少的信息，必须与真正的缺失严格区分。本文定义未检出为取值不超过本列下限 $\ell_k=\min_i x_{ik}$；真正缺失则是 1.csv 中确实为空的单元格，全表共 \textbf{73 个 NA、分布在 9 列、涉及 63 个样本}：乙酸戊酯 amyl.acetate 一列 27 个，占 10.8\%；酒花香气合计列 13 个（5.2\%）、甲基吡嗪 12 个（4.8\%）、双乙酰 9 个（3.6\%）、3-甲基丁醛 7 个（2.8\%），烟酸乙酯 2 个，苯乙醛、糠醛、异丁酸乙酯各 1 个。

三类特征的未检出比例差异极大：211 个单一化合物平均有 14.4\% 的单元格处于未检出，检出率 0.855；而 16 个理化列几乎全部检出，未检出仅 2.0\%、4 个汇总列未检出 0.4\%。这说明化合物丰度是稀疏的，未检出是主流信号而非异常。对未检出比例落在 5\%–95\% 之间的列，共 \textbf{102 列}，本文为每列定义二值指示 $\delta_{ik}=\mathbb{1}[x_{ik}\le\ell_k]$ 显式标记未检出事件。由于 LightGBM 对缺失与常量列有原生处理，且下限值本身作为一个独立档位已携带“接近零”的信息，指示变量的信息被该档位吸收，故最终特征矩阵仍为 231 列、未额外展开 102 个指示列；指示定义用于问题三的值域截断与附录的数据核对。

未检出并非简单的低值，它在统计上是\textbf{左删失}结构，这一点值得单独说明。本文对 231 个特征逐列统计取值为本列最小值的样本占比：\textbf{40 列有 30\% 以上的样本卡在同一最小值}，其中 12 列超过 60\%，limonene 与 6-methyl-5-hepten-2-one 达 84.8\%、CS2 为 83.6\%、4VG 为 67.2\%。同列大量样本取到完全相同的下限，不是自然测量的结果，而是仪器在该浓度以下无法分辨、统一记录为检出限的痕迹。若把这类下限值当作普通连续观测参与标准化与回归，分布的重心与尾部都会被压缩，均值的含义也随之改变。

本文据此把未检出保留为独立下限档位，并在问题三生成时按 $[\ell_k,u_k]$ 截断，避免解码器外推。

真正的缺失，即 73 个 NA，才需要插补，本文采用 $K=5$ 的近邻插补，近邻距离在标准化后的特征上计算，并严格在训练折内拟合、再施加到验证折。主模型的特征矩阵为 231 列原生数值（含 NaN），未检出以“下限档位”的形式进入分裂；KNN 插补只用于基线对照。标准化统计量、近邻关系与分箱切点都只在训练折内学习，防止验证折信息泄漏。

\section{问题一：含缺失的多输出有序感官分级预测}

\subsection{缺失结构与建模策略选择}

问题一要解决的第一道关卡是缺失数据。如 5.4 节所述，图 4 给出缺失结构；73 个真实缺失单元格集中在 9 列、涉及 63 个样本，呈少数列集中、多数样本完好的模式；此外化合物集里还有平均 14.4\% 的未检出值，它们携带该化合物极少的信息而非缺失。若按常规做法删除含缺失的 63 行，将损失全部样本的四分之一并引入选择偏差。由此本文确立策略：不删行，真正缺失交给原生支持缺失的梯度提升树，未检出则保留下限档位\cite{b5,b6,b7}，让模型在训练中直接为每个含缺失的分裂学习一个默认方向，把缺失本身也当作可利用的信息，而非需要先行填补的空白。该流水线自左向右依次为：含缺失的化学特征进入缺失感知的梯度提升，逐维回归后经 0-6 分箱映射得到有序等级，最后由分层交叉验证给出可信度评估。其中分箱映射与评估口径是保证交付 0-6 整数且不泄漏的两个要害环节，下面分别展开。

\subsection{标签构建与 0-6 分箱映射}

品评小组提供的标准化连续值无法直接作为 0-6 分级交付，需要一个单调映射把连续强度离散为 7 个等级。本文在训练折内对维度 $j$ 估计 6 个分位点 $\{q^{(j)}_1,\dots,q^{(j)}_6\}$，定义累计计数式的单调映射：

\begin{equation}
g_j(y)=\sum_{\ell=1}^{6}\mathbb{1}\!\left[y> q^{(j)}_\ell\right],\qquad \tilde y_{ij}=g_j(Y_{ij})\in\{0,\dots,6\}.
\end{equation}

预测阶段对回归输出 $r_{ij}$ 施加同一映射，并截断取整以严格落在 0-6 整数区间：

\begin{equation}
\hat y_{ij}=\min\!\Big(6,\ \max\!\big(0,\ \mathrm{round}(g_j(r_{ij}))\big)\Big).
\end{equation}

式 (1) 的分位点与标准化参数只由训练折估计、再套用到验证折，这是本题最易被忽视的泄漏点：若在全量数据上估计分箱阈值，等于让模型偷看了验证样本的标签分布。

分位分箱并非唯一选择。本文对分位分箱与等距分箱做了灵敏度对照：等距分箱把连续值按极差等分为 7 段，在偏态的标准化连续值上，50 个维度合计产生 8 个空等级、最小等级平均仅占 0.9\% 的样本、各等级样本数的变异系数高达 1.155；分位分箱则没有空等级、每等级平均占 13.8\%，接近 1/7，变异系数仅 0.022。等距分箱把多数样本压到中段，平均 QWK 反而略高（0.4013 对 0.3830），但这一偶然优势以空等级与严重失衡的等级频次为代价，对偏态分布不稳健；分位分箱的等级频次跨维可比、无空等级，且只依赖秩、对单调变换稳健，故本文采用后者。两口径下 QWK 绝对量级的依赖关系在 9.3 节另作说明。

分位分箱有一个容易被忽略的前提：各维度的连续标签必须足够分散，否则 6 个分位点会挤在极窄的区间内，切出的 7 个等级在原始尺度上无法区分。本文对 50 个维度逐一做了这项诊断，以“前 5 个切点跨度占该维极差的比例”作为退化程度的度量。结果显示有 5 个维度显著退化：acetic 为 0.006、coriander 与 clove 为 0.008、lactic 为 0.011、orange 为 0.033，它们的等级虽然仍各占约 14\% 的样本，但这些等级对应的原始强度几乎重叠，等级之间的边界不具备实际含义。

对这一现象有两种应对思路。第一种是保留分位分箱，承认这些维度的等级划分在市场意义上只是“相对排序”。第二种是改用\textbf{有序回归}，直接学习“是否越过某一等级阈值”，不依赖分位点落在哪里。为判断第二种是否真的更好，本文在同一批样本、同一 5 折划分、同一 LightGBM 家族下做了对照：回归分支沿用现有流程，有序分支对每个内部阈值训练一个“标签高/低于该阈值”的二分类器，将各阈值的预测概率累加后取整得到 6 级等级。

对照结果的分界非常清晰：退化维上有序回归平均提升 \textbf{0.166}（0.2052$\to$0.3715），其中 lactic 由 0.315 升至 0.611、clove 由 0.127 升至 0.305、coriander 由 0.093 升至 0.228；而在其余 45 维上，统一换用有序回归不但没有提升，反而平均下降 0.0041，甜味、酯类等标签分布较散的维度降幅更明显（甜味由 0.600 降至 0.494）。这一分化说明，有序回归的优势并非普遍存在，它恰好补偿的是分箱在密集分布上的信息损失；当标签本身足够分散时，连续回归保留的强度信息反而更有价值。因此本文只在退化维上切换，而不是全部换用。

据此本文把该判据接入主流水线：先按上述规则一次性完成退化诊断，退化维改用\textbf{类加权有序回归}，其余维保留回归加分位分箱。类加权有序回归在分解出的 6 个阈值上分别训练二分类器，并按阈值两侧样本比例反比加权，避免多数类主导。最终自动识别的退化维为 orange、coriander、clove、lactic、acetic 共 5 个，整体折外 QWK 由 0.3663 提升至 \textbf{0.3830}（+0.0167，相对 +4.6\%），5 个退化维全部改善，其余 45 维保持原值不变。

判据只依赖标签分布形态、在建模前即可确定，不接触验证信息；切换也是单侧的，只有退化维改用有序回归。作为对照，嵌套交叉验证下的逐维自适应选型无偏估计为 0.3856，但内层样本仅约 133 条、受抽样噪声驱动，反使 17 个原本良好的维度退化，未予采用。

\subsection{预测模型与求解过程}

对每个感官维度 $j$，本文训练一个独立的梯度提升回归器 $h_j$，以平方损失加正则求参：

\begin{equation}
\Theta_j=\arg\min_{\Theta}\ \sum_{i\in\mathcal{D}_{tr}}\big(Y_{ij}-h_j(x_i;\Theta)\big)^2+\Omega(\Theta),
\end{equation}

其中 $h_j$ 为梯度提升树集成，$x_i$ 的缺失分量由树的默认分裂方向处理，训练集 $\mathcal{D}_{tr}$ 包含全部含缺失样本，不删行；$\Omega$ 为叶子数、学习率与 L2 正则项。50 个维度共享同一化学特征矩阵 $X$。

整个求解按固定随机种子 42 执行，流程为：读入数据并分出 231 个特征列与 50 个标签列；按风格做分层 5 折划分，保证各折风格分布一致；在每个训练折内估计分箱映射 $g_j$、拟合回归器 $h_j$、记录特征重要性；在验证折上生成连续预测并经式 (2) 得到整数等级，逐维累计二次加权 Kappa、平均绝对误差与决定系数；同口径跑均值、线性与随机森林基线以及插补对照；最后在全部 250 样本上重训一次，对全样本输出 0-6 分级写入结果文件。

为了判断 0.383 相对基线的提升是否为随机波动，本文对同一批 250 个折外预测做 2000 次配对重采样，每次重算主模型与基线的 50 维平均 QWK 并取差，结果如表 6：三条对比的 95\% 置信区间均不跨零，重采样中主模型 2000 次全部更优（$\pi=1.000$）；对 KNN 插补的增量最小（+0.0177），对 ElasticNet 的增量最大（+0.1065）。

但均值掩盖了维间差异。把 50 个维度逐一对照可见三点：图 6(a) 给出 50 个维度的逐维差值分布，图 6(b) 把差值降序累加。其一，胜负并不一致：主模型对 ElasticNet 与随机森林分别胜出 43 与 44 维，对同为原生缺失处理的 KNN 插补只胜出 29 维，即仍有 21 维落后，中位差值仅 $+0.005$。其二，增益高度集中：与 KNN 相比，29 个胜维的正增量合计 1.184，其中最大的 5 维就占 66.4\%，其余维几乎打平（图 6(b) 的曲线在头几维后迅速贴近零线）。其三，落败维的亏幅很小，最差一维也只低 0.041，远小于胜维的最大增益 0.291。因此准确的结论是：缺失感知与非线性建模带来的是\textbf{少数维显著改善、多数维持平}，而不是在每个维度上都优于插补基线；50 维主模型指标均不劣于朴素基线，故全部 50 维提交主模型预测。

原生缺失的梯度提升主模型经分维选型后平均 QWK 0.3830、Spearman 0.4109、$\pm$1 级准确率 57.3\%，三项均为最优；它显著高于逐维均值基线，QWK 仅 0.0015、$\pm$1 仅 42.7\%，也高于线性收缩模型 ElasticNet，QWK 0.2762，后者与岭回归\cite{b8}、偏最小二乘回归\cite{b9}同属正则化回归族，也优于随机森林\cite{b10}的 0.3280，说明缺失感知与非线性建模共同带来了可观增益。本文同时以 KNN 插补\cite{b11}作为缺失处理对照，原生缺失处理 0.3663 略优于 KNN 插补后再建模 0.3652，差距虽小但方向稳定，从正面印证题面强调在缺失条件下建模的必要性：缺失位置本身携带信息，恰当处理优于先验填补。$\pm$1 级准确率还表明，即便在等级上偏差一级，主模型仍有过半预测落在真实等级相邻的 $\pm$1 级以内。逐维选型上，50 维主模型指标均不劣于朴素基线，故全部 50 维提交主模型预测。

\section{问题二：化合物共表达图与关键化合物归因}

\subsection{共表达图构建与模块结构}

问题二要为每个感官维度找出 Top-3 关键\textbf{化合物}，而化合物之间高度相关会干扰归因。为严格贴合找出关键化合物的题意，本文先把 231 个化学特征中的 16 个理化/过程参数（酒精度、色度、pH、苦度、二氧化碳压力、蛋白、甘油、未发酵糖等）与 4 个多化合物汇总列（总酯、酒花香气总量、总酸、含硫总量）排除，仅在 \textbf{211 个单一化合物构成的候选集 $C$（$|C|=231-16-4=211$）} 内建图与归因；问题一的特征矩阵仍保留全部 231 列，因为理化指标对预测同样有用。借鉴基因共表达网络的建模思想\cite{b13,b14}，本文以 $C$ 中化合物为节点、以化合物相关系数为边权构建无向图，并按相关强度阈值化去除弱边：

\begin{equation}
E=\big\{(p,q):\ p,q\in C,\ |R_{pq}|\ge \rho\big\},\qquad w_{pq}=R_{pq},\quad \rho=0.5,\ |C|=211.
\end{equation}

关于相关系数口径：附件 2 标称 Pearson，本文从 1.csv 重算 Pearson 与 Spearman，26565 对化合物相关系数的中位绝对差仅 0.062，二者对模块结构的刻画几乎一致。为与附件保持一致，边权沿用附件 2 的相关值；7.3 节的建图阈值灵敏度还会说明结论对该选择不敏感。在所得图上做 Louvain 贪心模块度社区检测\cite{b15}以识别化合物模块，模块度定义为

\begin{equation}
Q_{mod}=\frac{1}{2m}\sum_{p,q}\Big(w_{pq}-\frac{k_p k_q}{2m}\Big)\,\delta(c_p,c_q),\qquad k_p=\sum_q w_{pq}.
\end{equation}

在阈值 $\rho=0.5$ 下，共表达图含 \textbf{211 个节点、564 条边}，社区检测得到 \textbf{55 个社区}，模块度 $Q_{mod}=0.625$，远高于随机网络的水平，表明化合物确实存在明显的模块化组织结构。

社区规模分布显示 55 个社区高度不均衡：前 8 个大社区，各有 11–28 个化合物，已包含 159 个节点（约 75\%），其余多为 1–2 个化合物的小簇。这一结构正是归因去冗余的依据：若不加约束，同一模块内可互相替代的化合物会把一个维度的 Top-3 名额占满，掩盖真正多样的驱动因素。因此下一步的关键度打分必须引入模块代表机制。在融合模型证据之前，先看化学与感官之间最直接的线性关联。

\subsection{多证据融合 Top-3 归因}

对每个感官维度 $j$，本文融合三类证据给化合物 $p$ 打关键度分：

\begin{equation}
\phi_{jp}=\alpha\,\widetilde{\mathrm{SHAP}}_{jp}+\beta\,\big|\tilde C_{pj}\big|+\gamma\,\mathrm{rep}_{jp},\qquad \alpha+\beta+\gamma=1.
\end{equation}

其中 $\widetilde{\mathrm{SHAP}}_{jp}$ 是问题一模型对维度 $j$ 的归一化 SHAP 值，刻画非线性预测贡献；$\tilde C_{pj}$ 是化学与感官交叉相关的归一化绝对值，刻画线性关联；$\mathrm{rep}_{jp}$ 是模块代表加权，使同模块内多个可互替化合物只保留关键度最高者进入候选，避免 Top-3 被单一模块占满，这一簇代表的思路与稳健特征选择中的聚类代表方法一致\cite{b16}。按权重 $\alpha=0.5,\beta=0.3,\gamma=0.2$ 取每维得分前三者：

\begin{equation}
\mathrm{Top3}(j)=\operatorname*{arg\,top3}_{p}\ \phi_{jp}.
\end{equation}

SHAP 值通过对问题一全量梯度提升模型使用树解释器逐样本计算得到，权重 $\alpha$ 最大体现了以预测贡献为主、相关与去冗余为辅的归因哲学。为避免同一模块内高度相关的化合物重复占满 Top-3，在 argtop-3 选取时还施加显式去冗余规则：当候选 $p$ 与某个已入选化合物 $q$ 同属一个社区且 $\lvert R_{pq}\rvert\ge 0.7$ 时跳过 $p$，即 $c_p=c_q\neq-1$ 且二者强相关时 $p$ 不再入选，强制 Top-3 来自相互独立的化学证据，而非三个彼此近似的共表达冗余物。最终每个维度恰好交付 3 个化合物。

\subsection{稳定性量化}

\begin{figure}[htbp]
\centering
\includegraphics[width=0.88\textwidth,height=0.217\textheight,keepaspectratio]{fig_q2_rho_sweep.png}
\caption{建图阈值 ρ 的灵敏度：边数、孤立节点与模块度的取舍}
\end{figure}

阈值 ρ 不是随手取定的常数。图 15(a) 显示边数随 ρ 单调塌缩：0.40 时 1500 条边、最大分量 200 节点，0.60 时只剩 234 条边、86 节点；图 15(b) 给出另一侧代价：孤立节点从 11 升到 95，而模块度在 0.55–0.60 才见顶（0.684、0.704）后回落。ρ=0.5 是折中点：保留 159 节点的连通骨架、模块度 0.625。本文据此固定 ρ=0.5。

稳定性严格按题面指定的两种口径量化。第一种是 bootstrap 入选频率\cite{b19}：对样本做 $B=500$ 次有放回重采样，每次重算 Top-3，统计化合物 $p$ 进入维度 $j$ 的 Top-3 的频率

\begin{equation}
f_{jp}=\frac{1}{B}\sum_{b=1}^{B}\mathbb{1}\!\left[p\in\mathrm{Top3}^{(b)}(j)\right]\in[0,1].
\end{equation}

第二种是跨方法 Jaccard：对 SHAP 法交叉相关法随机森林重要性法三类方法两两比较其 Top-3 集合，

\begin{equation}
\mathrm{Jac}(A,B)=\frac{|A\cap B|}{|A\cup B|}\in[0,1].
\end{equation}

入选频率高说明单一方法内部稳健，Jaccard 高说明不同证据之间一致。为回答这样的稳定性是否显著优于随机，本文还构造了随机基线：在 211 个化合物集 $C$ 上随机抽取 3 个作为 Top-3，重复 100000 次，计算随机 Top-3 与固定参照的 Jaccard 期望。两指标的全维分布如下图。

\begin{figure}[htbp]
\centering
\includegraphics[width=0.88\textwidth,height=0.226\textheight,keepaspectratio]{fig_q2_stability.png}
\caption{单方法稳定性饱和与跨方法一致性分散}
\end{figure}

图 16(a) 的联合分布把两个口径放在同一平面上：横轴方向 50 个维度几乎全部堆在 1.000（$47/50$），说明单方法内部的 Top-1 选择极其稳健；纵轴方向则从 0 铺到 0.67，平均 \textbf{0.186}，即三类证据的 Top-3 集合平均约两成重叠。图 16(b) 把实测 Jaccard 与“两个独立随机 3 子集”的零分布并列，实测累积曲线整体右移。而 10 万次随机抽取的 Jaccard 期望仅 \textbf{0.0086}，本文 0.186 是随机基线的 \textbf{21.7 倍}——这意味着虽然三类证据视角互补、绝对 Jaccard 不高，但相对于随机抽取已高度显著，归因绝非偶然。这一高入选频率、中等 Jaccard、远高于随机的组合恰如实反映了 SHAP、线性相关与共表达三类证据侧重不同、各自内部稳定而彼此互补，而非虚高的一致。

\section{问题三：风格条件生成与跨风格迁移}

\subsection{条件变分自编码器}

问题三要学习一个以风格为条件的化学谱生成模型，并在小样本下保持风格可区分。本文采用条件变分自编码器\cite{b17}：编码器 $q_\phi(z\mid x,s)$ 把 231 维化学谱连同风格条件压缩进低维隐空间，解码器 $p_\theta(x\mid z,s)$ 从隐变量与风格条件重建化学谱。模型最大化证据下界

\begin{equation}
\mathcal{L}(\theta,\phi)=\mathbb{E}_{q_\phi(z\mid x,s)}\big[\log p_\theta(x\mid z,s)\big]-\beta_{KL}\,\mathrm{KL}\!\big(q_\phi(z\mid x,s)\,\big\|\,p(z)\big),
\end{equation}

其中先验 $p(z)=\mathcal{N}(0,I)$，采用重参数化 $z=\mu_\phi+\sigma_\phi\odot\epsilon$ 使梯度可回传。为避免缺失位置污染梯度，重构项只对非缺失分量计算误差：

\begin{equation}
\log p_\theta(x\mid z,s)\ \propto\ -\tfrac12\sum_{p:\,M_{ip}=0}\big(x_{ip}-\hat x_{ip}\big)^2.
\end{equation}

隐维取 16 以适配 250 的小样本规模。生成时给定目标风格，从先验采隐变量并解码，即得该风格的化学谱。该生成与迁移架构的整体结构如下。

\begin{figure}[htbp]
\centering
\includegraphics[width=0.88\textwidth,height=0.228\textheight,keepaspectratio]{fig_arch_q3.png}
\caption{问题三风格条件生成（CVAE）架构}
\end{figure}

图 27 自左向右呈现了编码器、隐空间、条件解码器、缺陷阈值投影到感官画像打分的完整链路。架构中缺陷阈值投影是迁移任务的硬约束执行点，Q1 感官画像则把问题一的预测模型接回来形成闭环，二者是本问区别于一般无条件生成的两处关键设计。

训练初期曾出现后验坍塌：当 $\beta_{KL}=1$ 时 KL 项迅速趋零、重构质量差，KS 距离约 0.6。本文按建模阶段预案做等价的数值稳定化——把 $\beta_{KL}$ 降至 0.1，并对 KL 项施加前 120 轮线性退火与每维 0.5 nats 的 free-bits 下限，重构损失由 0.765 降至 0.255，KS 距离随之降到 0.36 至 0.41 区间。这一处理只改变优化过程、不改变题设与数据。

\subsection{跨风格迁移与缺陷约束}

跨风格迁移在隐空间以风格质心之差作为平移向量实现：

\begin{equation}
\Delta_{s\to t}=\bar z_t-\bar z_s,\qquad \hat x_{t}=p_\theta\big(z_s+\Delta_{s\to t}\,\big|\,\mathrm{onehot}(t)\big),
\end{equation}

其中 $\bar z_c$ 为风格 $c$ 所有样本隐编码的均值。把源风格样本编码后沿该方向平移再解码，即得目标风格化学谱。迁移必须守住缺陷不恶化的硬约束，本文对每个缺陷化合物 $k$ 逐样本做下截断投影：

\begin{equation}
x^{def}_{k,after}\ =\min\!\Big(\tilde x^{def}_{k,after},\ \ \min\big(x^{def}_{k,before},\ m^t_k\big)\Big),
\end{equation}

其中 $\tilde x^{def}_{k,after}$ 为隐空间平移并解码得到的\textbf{无约束}值，$x^{def}_{k,before}$ 为该样本源风格 Pils/Lager 缺陷 $k$ 的原始含量，$m^t_k$ 为目标风格 Tripel 缺陷 $k$ 的典型分位值，取中位。该投影逐样本取三者最小值，构成两道防线：源款原值 $x_{before}$ 保证迁移后缺陷绝不高于源款，目标典型值 $m^t_k$ 作为第二道绝对阈值兜底。由于各化学维单位不可比、绝对阈值无法统一换算，本题不并入绝对阈值 $\tau^{*}_k$，默认关闭。8.3 节将以同一批样本不做投影的纯平移结果作为对照，量化该约束不可或缺。

这一对照给出的结论不是“CVAE 全面占优”，而是\textbf{三种方法对应不同的任务需求}。若任务只是补足样本量，风格内重采样在分布意义上更可靠；但本题要求的是条件生成与可控迁移，即在给定风格下生成新的化学谱、并在隐空间中把源风格沿特定方向推向目标风格。重采样无法产生新谱，高斯采样不具备可解释的隐空间方向，只有 CVAE 能同时提供这两项能力。本文因此选择 CVAE，并把分布保真上的劣势如实列出，而不是以单一 KS 指标宣称生成质量全面领先。

\section{模型检验与灵敏度分析}

\subsection{验证方案与防泄漏}

三问的可信度都建立在独立的验证之上，且全程贯彻防泄漏纪律。问题一采用按风格分层的 5 折交叉验证，分箱分位点与标准化参数只在训练折估计、再施加到验证折，杜绝了在全量数据上估分箱这一最隐蔽的泄漏。问题二以 500 次 bootstrap 给出单方法稳健性、以三法 Jaccard 给出方法间一致性，化学合理性再以交叉相关与酿造机理双重佐证。问题三对生成以分布距离与降维簇重叠评估，对迁移以缺陷合规率这一硬指标评估，并用问题一感官画像核验风格特征。本题没有隐藏测试集，所有数字都如实标注为交叉验证或分布距离的内部估计。

本文系统排查了六类泄漏并逐一封堵：分箱与标准化参数折内估计；主办方模型的参考重要性只作问题二旁证、不进入问题一训练特征；样本主键与风格标签不进入问题一特征矩阵；不对风格做目标编码。此外，附件 2 与 1.csv 的关联经核验只能按 \texttt{beer} 名称与行序对齐，按 \texttt{beer\_id} 会因精度丢失只剩 37/250 行，本文对此显式断言而非静默合并。

对数变换底数经 5.3 节核实为混合尺度（37 列常用对数、33 列原值），因树模型对单调变换不敏感，不影响问题一与问题二的结论，仅影响浓度的叙述性换算。问题二的建图阈值在 0.4 至 0.6 之间扫描（结果见图 15）：过高使图断裂、模块过碎，过低使图趋于全连通，取 0.5 时结构最清晰。问题三的隐维取 8 至 16，过小会后验坍塌、各风格雷同，过大则在小样本上过拟合，取 16 并配合 KL 退火与 free-bits 后生成分布稳定、风格可分。

\subsection{鲁棒性}

固定随机种子 42 下问题一完全可复现；问题二 47/50 维的 Top-1 频率恰为 1.000；问题三在不同采样下保持风格可分。50 维全部获得预测，无闲置维度。

\section{模型评价与推广}

\subsection{优点与创新}

第一，以一个共享的化学到感官预测底座贯通三问：同一套经交叉验证的模型既是问题二的 SHAP 归因对象，又是问题三生成谱的感官打分器，使预测、归因与生成真正联动。

第二，归因阶段把候选集限定为 211 个单一化合物，并以模块代表加权与同社区去冗余。消融显示三路融合把单维 Top-3 命中的模块数由 2.30 提到 2.92（满分 3）；跨方法 Jaccard 0.186 是随机基线 0.0086 的 21.7 倍。

第三，把缺陷不恶化形式化为 $\min(\tilde x_{after},x_{before},m_t)$ 逐样本投影，并配无约束对照（72.7\% 本会升高），使迁移带上可逐样本审计的硬约束；另用真实浓度阈值做绝对口径审计，区分“相对不恶化”与“绝对达标”。

第四，识别出分位分箱在标签分布高度集中时失效这一隐性前提，并提出可事前判定的退化诊断规则。据此对退化维改用类加权有序回归后，折外 QWK 由 0.3663 提升到 0.3830（+4.6\%），五个退化维全部改善、其余维度不受影响。

第五，预处理可核验、防泄漏：以校准浓度反推对数底（37 列常用对数、33 列原值），把未检出识别为左删失并与真实缺失分流，全程折内拟合。孤立节点亦已量化：$\rho=0.5$ 下 44 个孤立点的最大 $|r|$ 中位 0.444，$\rho=0.45$ 时降至 23，说明孤立源于硬阈值截断。

第六，归因同时给出可信度：以配对 bootstrap 区间检验主模型对三类基线的增益，以条件/模块增量把 Top-3 分为 A/B/C 三级，以 SHAP 与 ALE 展示同一化合物在不同浓度区间的方向反转。

\subsection{不足与改进}

其一，0-6 分级由标准化连续值单调映射重建，而非原始品评卡的直接复现，绝对分级值带有映射口径的印记；若获得填好的原始品评数据，可改为直接的有序分类。

其二，250 样本、16 维隐空间下 CVAE 的分布保真弱于重采样（KS 0.390 对 0.098），且个别化合物存在外推；更关键的是置换检验显示隐空间没有超出噪声的风格结构（图 31(b)，$p=0.92$/$0.99$/$1.00$），条件仅体现为质心微小平移。本文已按观测区间截断，进一步逼近真实分布更现实的路径是扩大样本量。分维选型使画像 Spearman 降至 0.65--0.92（Lambic 0.81 降至 0.75），反映的是虚高成分被剔除而非质量恶化。

其三，问题二 Top-3 的来源完全一致率仅 14\%，麦芽维归因多落在酵母酯醇上，这是发酵后风味载体以酵母产物为主的真实反映；其四，高删失列以下限档位与指示变量编码，未建显式删失似然，学到的是“接近检出限”的相对关系。受控实验与更多高于检出限的样本可分别改进这两点。

\subsection{推广}

本文框架可推广到其他成分谱、感官与品类问题：缺失感知有序预测适用于品评数据缺测场景，共表达图加多证据归因适用于高共线性组学或光谱筛选，带硬约束的条件生成可用于需规避有害成分的配方设计；分箱退化判据与领域无关。

class Binner:
    """对单个感官维，训练折内估分位点，映射连续值 -> 0..6 整数等级。"""

    def __init__(self, scheme=P.LABEL_BINNING, n_levels=P.N_LEVELS):
        self.scheme = scheme
        self.n_levels = n_levels
        self.edges = None   # 6 个内部切点

    def fit(self, y):
        y = np.asarray(y, dtype=float)
        y = y[np.isfinite(y)]
        q = self.n_levels  # 7 级 -> 6 个内部分位点
        if self.scheme == "quantile":
            probs = np.linspace(0, 1, q + 1)[1:-1]  # 6 点
            self.edges = np.quantile(y, probs)
        else:  # uniform 等距
            lo, hi = y.min(), y.max()
            self.edges = np.linspace(lo, hi, q + 1)[1:-1]
        # 去重保证单调（极端退化时）
        self.edges = np.maximum.accumulate(self.edges)
        return self

    def transform(self, y):
        y = np.asarray(y, dtype=float)
        lvl = np.searchsorted(self.edges, y, side="right")  # 0..6
        return np.clip(np.round(lvl), P.LEVEL_MIN, P.LEVEL_MAX).astype(int)

    def transform_continuous(self, r):
        """对回归连续输出施加同一映射 + clip + round（式2）。"""
        return self.transform(r)

def quadratic_weighted_kappa(y_true, y_pred, n_levels=P.N_LEVELS):
    """二次加权 Kappa（有序分级首选）。手写实现，避免 sklearn 对缺等级的边界问题。"""
    y_true = np.asarray(y_true, dtype=int)
    y_pred = np.asarray(y_pred, dtype=int)
    N = n_levels
    O = np.zeros((N, N), dtype=float)
    for a, b in zip(y_true, y_pred):
        O[a, b] += 1
    w = np.zeros((N, N), dtype=float)
    for i in range(N):
        for j in range(N):
            w[i, j] = (i - j) ** 2 / (N - 1) ** 2
    act = O.sum(axis=1)
    pred = O.sum(axis=0)
    E = np.outer(act, pred) / O.sum()
    denom = (w * E).sum()
    if denom == 0:
        return 1.0 if (w * O).sum() == 0 else 0.0
    return 1.0 - (w * O).sum() / denom

def _norm(v):
    v = np.asarray(v, dtype=float)
    v = np.where(np.isfinite(v), v, 0.0)
    mx = np.abs(v).max()
    return v / mx if mx > 0 else v

def build_coexpr_graph(R, comp_names, rho, c_idx):
    """仅以化合物集 C 的位置索引（211 项）为节点、|corr|>=rho 且两端均∈C 为边建无向图 + louvain 社区。

    节点 id 沿用其在全 231 特征中的位置，便于与 comm_arr/评分向量对齐。
    """
    c_set = set(int(i) for i in c_idx)
    G = nx.Graph()
    for i in c_idx:
        G.add_node(int(i), name=comp_names[i])
    n_edges = 0
    c_list = sorted(c_set)
    for a in range(len(c_list)):
        i = c_list[a]
        for b in range(a + 1, len(c_list)):
            j = c_list[b]
            w = R[i, j]
            if np.isfinite(w) and abs(w) >= rho:
                # 边权用 |相关系数|（louvain/模块度要求非负权；符号由 R 保留，去冗余直接查 R）
                G.add_edge(i, j, weight=abs(float(w)))
                n_edges += 1
    # 社区检测（louvain；回退 greedy_modularity）
    try:
        import community as community_louvain
        part = community_louvain.best_partition(G, weight="weight", random_state=P.SEED)
        comm = {int(k): int(v) for k, v in part.items()}
        method = "louvain"
    except Exception:
        from networkx.algorithms.community import greedy_modularity_communities
        comms = greedy_modularity_communities(G, weight="weight")
        comm = {int(node): ci for ci, cset in enumerate(comms) for node in cset}
        method = "greedy_modularity"
    # 模块度
    try:
        from networkx.algorithms.community import modularity
        groups = {}
        for node, ci in comm.items():
            groups.setdefault(ci, set()).add(node)
        Q = modularity(G, list(groups.values()), weight="weight")
    except Exception:
        Q = None
    return G, comm, method, n_edges, Q

def _shap_evidence(sens_cols, feat_cols, Xv):
    """用 Q1 全量 LightGBM 模型算每维 SHAP。返回 (importance[J×P], 每维|shap|矩阵列表)。"""
    ck = U.ckpt_path("q1_models.pkl")

    import joblib
    bundle = joblib.load(ck)
    models = bundle["models"]
    J, Pn = len(sens_cols), len(feat_cols)
    imp = np.zeros((J, Pn))
    abs_shap_list = []
    for j, col in enumerate(sens_cols):
        if col in models:
            expl = shap.TreeExplainer(models[col])
            sv = expl.shap_values(Xv)       # N×P
            sv = np.asarray(sv)

        else:

    return imp, abs_shap_list, sens_cols

def _module_rep(base_scores, comm_arr):
    """模块代表加权：同社区内按 base 排名，第 1 名 rep=1，第 2=1/2…（促进 Top-3 跨模块多样）。"""
    rep = np.zeros_like(base_scores)
    for ci in np.unique(comm_arr):
        idx = np.where(comm_arr == ci)[0]
        order = idx[np.argsort(-base_scores[idx])]
        for rank, p in enumerate(order, 1):
            rep[p] = 1.0 / rank
    return rep
def _topk(score, k=P.TOPN):
    return list(np.argsort(-score)[:k])

def _jaccard(a, b):
    a, b = set(a), set(b)
    u = a | b
    return len(a & b) / len(u) if u else 0.0

class CVAE(nn.Module):
    def __init__(self, n_feat, n_style, latent=P.LATENT_DIM, hidden=128):
        super().__init__()
        self.n_feat = n_feat
        self.enc = nn.Sequential(
            nn.Linear(n_feat + n_style, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU())
        self.fc_mu = nn.Linear(hidden, latent)
        self.fc_lv = nn.Linear(hidden, latent)
        self.dec = nn.Sequential(
            nn.Linear(latent + n_style, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, n_feat))

    def encode(self, x, s):
        h = self.enc(torch.cat([x, s], dim=1))
        return self.fc_mu(h), self.fc_lv(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def decode(self, z, s):
        return self.dec(torch.cat([z, s], dim=1))

    def forward(self, x, s):
        mu, logvar = self.encode(x, s)
        z = self.reparameterize(mu, logvar)
        return self.decode(z, s), mu, logvar

def _elbo_loss(xhat, x, mask, mu, logvar, beta_kl, free_bits=P.FREE_BITS):
    # 掩码重构（只对非缺失分量计 MSE，式11）
    diff2 = ((xhat - x) ** 2) * mask
    recon = diff2.sum() / mask.sum().clamp(min=1.0)
    # 逐维 KL + free-bits（每维 KL 低于 free_bits 时不再惩罚，防后验坍塌）
    kld_dim = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp())   # [B, d]
    kld_dim = torch.clamp(kld_dim.mean(dim=0), min=free_bits)
    kld = kld_dim.sum()
    return recon + beta_kl * kld, recon.item(), float(kld.item())

        ep_loss = ep_rec = ep_kl = 0.0
        for st in range(0, N, P.CVAE_BATCH):
            bidx = perm[st:st + P.CVAE_BATCH]
            xb, mb, sb = Xt[bidx], Mt[bidx], St[bidx]
            opt.zero_grad()
            xhat, mu, lv = model(xb, sb)
            beta = P.BETA_KL * min(1.0, ep / max(1, P.KL_ANNEAL_EPOCHS))  # KL 退火
            loss, rec, kl = _elbo_loss(xhat, xb, mb, mu, lv, beta)
            loss.backward()
            opt.step()
            ep_loss += loss.item() * len(bidx); ep_rec += rec * len(bidx); ep_kl += kl * len(bidx)
        ep_loss /= N
        if ep <= P.KL_ANNEAL_EPOCHS:
            if ep % 50 == 0 or ep == 1:
                print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS}(退火) loss={ep_loss:.4f} "
                      f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
            continue   # 退火阶段不计入早停
        if ep_loss < best - 1e-4:
            best, best_state, bad = ep_loss, {k: v.detach().clone() for k, v in model.state_dict().items()}, 0
        else:
            bad += 1
        if ep % 50 == 0 or ep == 1:
            print(f"[Q3] CVAE epoch {ep}/{P.CVAE_EPOCHS} loss={ep_loss:.4f} "
                  f"recon={ep_rec/N:.4f} kl={ep_kl/N:.4f}")
        if bad >= patience:
            print(f"[Q3] 早停于 epoch {ep}（best loss={best:.4f}）")
            break
    if best_state is not None:
        model.load_state_dict(best_state)
    model.eval()
    return model

def _style_latent_mean(model, Xstd, styles, target_style, s2i, S, device):
    """编码目标风格样本得隐均值 z̄_c（迁移用）。"""
    idx = np.where(styles == target_style)[0]
    oh = np.zeros((len(idx), S)); oh[:, s2i[target_style]] = 1
    with torch.no_grad():
        mu, _ = model.encode(torch.tensor(Xstd[idx], dtype=torch.float32, device=device),
                             torch.tensor(oh, dtype=torch.float32, device=device))
    return mu.cpu().numpy().mean(axis=0), idx

def _generate(model, style_list, s2i, S, Xstd, styles, mu_f, sd_f, device, n_gen=30):
    """代表风格条件采样生成；小样本风格走高斯兜底。"""
    rng = np.random.default_rng(P.SEED)
    records, native_rows = [], []
    for style in P.GEN_STYLES:
        if style not in s2i:
            print(f"[Q3] 跳过未知风格 {style}")
            continue
        cnt = int((styles == style).sum())
        if cnt >= P.MIN_STYLE_FOR_CVAE:
            # CVAE：z~N(0,I) 解码
            z = torch.tensor(rng.normal(size=(n_gen, P.LATENT_DIM)), dtype=torch.float32, device=device)
            oh = np.zeros((n_gen, S)); oh[:, s2i[style]] = 1
            with torch.no_grad():
                xhat = model.decode(z, torch.tensor(oh, dtype=torch.float32, device=device)).cpu().numpy()
            gen_std = xhat
            gmethod = "CVAE"
        else:
            # 高斯兜底：按风格样本多元高斯采样（标准化空间）
            idx = np.where(styles == style)[0]
            m = Xstd[idx].mean(axis=0); cov = np.cov(Xstd[idx].T) + 1e-3 * np.eye(Xstd.shape[1])
            gen_std = rng.multivariate_normal(m, cov, size=n_gen)
            gmethod = "gaussian_fallback"
        native = gen_std * sd_f + mu_f
        for k in range(n_gen):
            records.append({"style": style, "sample_type": "generated",
                            "gen_method": gmethod, "_native": native[k]})
            native_rows.append(native[k])
        print(f"[Q3] 生成 {style}: {n_gen} 条（{gmethod}，真实样本={cnt}）")
    return records, np.array(native_rows)
def _transfer(model, style_list, s2i, S, Xstd, Xv, styles, feat_cols, mu_f, sd_f, device):
    """Pils/Lager → Tripel 隐空间平移 + 缺陷投影（式12/13）。"""
    tgt = P.TRANSFER_TARGET
    zt, _ = _style_latent_mean(model, Xstd, styles, tgt, s2i, S, device)
    # 目标风格缺陷典型值 m^t（native 中位）
    tgt_idx = np.where(styles == tgt)[0]
    col_med_all = np.nanmedian(Xv, axis=0)
    defect_pos = {d: feat_cols.index(c) for d, c in P.DEFECT_COL_MAP.items()}
    m_t = {d: float(np.nanmedian(Xv[tgt_idx, pos])) for d, pos in defect_pos.items()}

    records = []
    before = {d: [] for d in defect_pos}
    after = {d: [] for d in defect_pos}
    cap_rec = {d: [] for d in defect_pos}
    for src in P.TRANSFER_SOURCES:
        if src not in s2i:
            print(f"[Q3] 迁移源 {src} 不存在，跳过")
            continue
        zs, sidx = _style_latent_mean(model, Xstd, styles, src, s2i, S, device)
        delta = zt - zs
        # 逐源样本编码 -> 平移 -> 用目标风格解码
        oh_src = np.zeros((len(sidx), S)); oh_src[:, s2i[src]] = 1
        with torch.no_grad():
            mu_s, _ = model.encode(torch.tensor(Xstd[sidx], dtype=torch.float32, device=device),
                                   torch.tensor(oh_src, dtype=torch.float32, device=device))
            z_moved = mu_s.cpu().numpy() + delta
            oh_t = np.zeros((len(sidx), S)); oh_t[:, s2i[tgt]] = 1
            xhat = model.decode(torch.tensor(z_moved, dtype=torch.float32, device=device),
                                torch.tensor(oh_t, dtype=torch.float32, device=device)).cpu().numpy()
        native = xhat * sd_f + mu_f
        raw_after = {d: [] for d in defect_pos}   # 无约束纯平移对照（缺陷投影前的解码值）
        for row, si in enumerate(sidx):
            x_after_vec = native[row].copy()
            for d, pos in defect_pos.items():
                xb = Xv[si, pos]
                if not np.isfinite(xb):
                    xb = float(col_med_all[pos])
                raw_val = float(x_after_vec[pos])      # 无约束纯平移的缺陷取值（对照）
                raw_after[d].append(raw_val)
                # 严格不恶化：迁移后缺陷既不得高于源款原值 xb，也不高于目标典型安全值 m_t，取严
                cap = min(xb, m_t[d])
                if P.USE_ABS_THRESHOLD:
                    pass  # 可换算时此处并入 τ 上界（本题单位不可比，默认关闭）
                # 缺陷列逐样本投影回安全区（式13，np.minimum 下截断）
                xa = float(np.minimum(raw_val, cap))
                x_after_vec[pos] = xa
                before[d].append(float(xb)); after[d].append(xa); cap_rec[d].append(cap)
            records.append({"style": f"{src}->{tgt}", "sample_type": "transfer",
                            "src_beer_row": int(si), "_native": x_after_vec})
        print(f"[Q3] 迁移 {src}->{tgt}: {len(sidx)} 条")
    # 合规率（式13：x_after <= min(xb, m_t)；同时统计无约束纯平移会升高多少）
    n_tot = n_ok = 0
    n_rise_raw = n_rise_constrained = 0
    per_defect = {}
    for d in defect_pos:
        bf = np.array(before[d]); af = np.array(after[d]); cp = np.array(cap_rec[d])
        raw = np.array(raw_after[d])
        ok = int((af <= cp + 1e-9).sum())
        rise_raw = int((raw > bf + 1e-9).sum())   # 无约束时缺陷升高的样本数
        rise_c = int((af > bf + 1e-9).sum())      # 严格约束后缺陷升高数（应为 0）
        n_tot += len(af); n_ok += ok
        n_rise_raw += rise_raw; n_rise_constrained += rise_c
        per_defect[d] = {"n": len(af), "n_compliant": ok,
                         "before_mean": round(float(bf.mean()), 4),
                         "after_mean": round(float(af.mean()), 4),
                         "raw_after_mean": round(float(raw.mean()), 4),
                         "m_t": round(m_t[d], 4),
                         "delta_mean": round(float((af - bf).mean()), 4),
                         "delta_raw_mean": round(float((raw - bf).mean()), 4),
                         "n_rise_unconstrained": rise_raw,
                         "n_rise_constrained": rise_c}
    rate = n_ok / n_tot if n_tot else 1.0
    info = {"compliance_rate": round(rate, 6), "n_checks": n_tot, "n_compliant": n_ok,
            "per_defect": per_defect, "defect_cols": list(P.DEFECT_COL_MAP.values()),
            "defect_no_chem": P.DEFECT_NO_CHEM, "m_t": {k: round(v, 4) for k, v in m_t.items()}}
    print(f"[Q3] 缺陷合规率={rate:.4f}（{n_ok}/{n_tot}）")
    return records, info

def _sensory_profile(native_rows, feat_cols):

def _eval_metrics(Xv, styles, feat_cols, gen_native, gen_records, transfer_info):
    """分布距离(KS)、PCA 重叠坐标、闭环酯香等级。"""
    from sklearn.decomposition import PCA
    col_med = np.nanmedian(Xv, axis=0)
    Xfill = np.where(np.isnan(Xv), col_med, Xv)
    ks_per_style = {}
    for style in P.GEN_STYLES:
        real_idx = np.where(styles == style)[0]
        gen_idx = [i for i, r in enumerate(gen_records) if r["style"] == style]
        if len(real_idx) < 2 or not gen_idx:
            continue
        real = Xfill[real_idx]; gen = gen_native[gen_idx]
        ks = [ks_2samp(real[:, p], gen[:, p]).statistic for p in range(Xv.shape[1])]
        ks_per_style[style] = round(float(np.mean(ks)), 4)
    # PCA（在真实全量上拟合，投影真实+生成）
    mu_f = Xfill.mean(axis=0); sd_f = Xfill.std(axis=0) + 1e-8
    pca = PCA(n_components=2, random_state=P.SEED).fit((Xfill - mu_f) / sd_f)
    real_2d = pca.transform((Xfill - mu_f) / sd_f)
    gen_2d = pca.transform((gen_native - mu_f) / sd_f)
    pca_data = {
        "real": [{"x": round(float(real_2d[i, 0]), 3), "y": round(float(real_2d[i, 1]), 3),
                  "style": str(styles[i])} for i in range(len(styles))
                 if styles[i] in P.GEN_STYLES or styles[i] in P.TRANSFER_SOURCES],
        "gen": [{"x": round(float(gen_2d[i, 0]), 3), "y": round(float(gen_2d[i, 1]), 3),
                 "style": gen_records[i]["style"]} for i in range(len(gen_records))],
        "explained_var": [round(float(v), 4) for v in pca.explained_variance_ratio_],
    }
    return {"ks_distance_by_style": ks_per_style, "pca": pca_data}

errors, warnings, suspicious = [], [], []

def check_value(name, val):
    if isinstance(val, float):
        if math.isnan(val):
            errors.append(f"FAIL {name} = NaN")
        elif math.isinf(val):
            errors.append(f"FAIL {name} = Inf")
        elif abs(val) > 1e15:
            warnings.append(f"WARN {name} = {val} 异常大")

def check_unrealistic(name, val):
    if not isinstance(val, (int, float)) or isinstance(val, bool):
        return
    key = re.sub(r"\[\d+\]", "", name.rsplit(".", 1)[-1]).lower()
    if key in {"qwk", "mean_qwk_main", "jaccard", "mean_cross_method_jaccard"}:
        if val > 1 + 1e-9 or val < -1 - 1e-9:
            errors.append(f"FAIL {name}: QWK/Jaccard 越界")
    if "compliance_rate" in key:
        if val > 1 + 1e-9 or val < 0:
            errors.append(f"FAIL {name}: 合规率越界[0,1]")
    if key in {"select_freq", "bootstrap_select_freq"}:
        if val > 1 + 1e-9 or val < 0:
            errors.append(f"FAIL {name}: 频率越界[0,1]")

def walk(obj, path=""):
    if isinstance(obj, dict):
        for k, v in obj.items():
            walk(v, f"{path}.{k}")
    elif isinstance(obj, list):
        for i, v in enumerate(obj):
            walk(v, f"{path}[{i}]")
    elif isinstance(obj, (int, float)):
        check_value(path, obj)
        check_unrealistic(path, obj)

for fname, data in results.items():
    walk(data, fname)
